# Ghost Tool 4.3.3 用户指南

Ghost Tool 在 Bforartists 中显示网格残影、运动路径和可编辑的运动标记。网格残影也称为洋葱皮，用于显示目标在其他动画时刻的形态。运动路径显示目标的移动。运动标记是这些路径上可编辑的点。本指南介绍版本 4.3.3。

截图展示了所提供的 Bforartists 5.2.3 构建中的 Ghost Tool 4.3.3。原生设置面板的标题栏可能显示 Tear Off Panel。

版本 4.3.2 增加了时间线折叠功能，并在两个残影图标之间加入间隔。版本 4.3.3 可在 Anim Assist 的时间线指针空闲时生成预览。正在进行的编辑操作仍会暂停采样。

[Ghost Tool 4.3.3 安装 ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.3/b4_ghost_tool_v4.3.3.zip) 用于安装独立插件。[4.3.3 发行说明](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/RELEASE-NOTES.md)和[软件包记录](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/package-receipt.json)包含发行验证记录和校验和。

<a id="install-and-find-ghost-tool"></a>

## 安装并找到 Ghost Tool

所提供的定制／原生测试构建包含 Ghost Tool 4.3.3。其出厂偏好设置已启用该插件。此构建无需另行安装 ZIP 或手动启用插件。下面介绍的视图工具栏、工具架、侧栏和偏好设置位置也适用于此构建。

独立安装步骤：

1. 下载 `b4_ghost_tool_v4.3.3.zip`。

2. 打开“编辑 > 偏好设置 > 插件 > 从磁盘安装”。

3. 选择 ZIP。

4. 启用 Ghost Tool。

5. 替换已安装的版本后，重新启动 Bforartists。

6. 检查偏好设置显示的版本是否为 4.3.3。

仓库中的更改不会自动更新已安装的插件。旧 ZIP 会安装其原有版本。

这些步骤用于安装独立插件。提议中的内置版本依赖 Bforartists PR [7067](https://github.com/Bforartists/Bforartists/pull/7067)。截至 2026-11-19，该 PR 尚未合并。已发行的官方 Bforartists 构建尚未包含这项提议中的集成。

Ghost Tool 默认显示在原生 3D 视图“工具设置”行中的“顶部工具栏”。原生标题栏位于顶部时，此行处于视图主标题栏下方。此行跟随原生标题栏的对齐方式。

偏好设置还提供“右侧栏（N）”和“左侧工具架（T）”。Ghost Tool 会将旧设置中保存的 Top Header 选项改为“顶部工具栏”。

![Ghost Tool 4.3.3 偏好设置](images/zh/4.3.3-preferences.png)

*图 1. 所提供的构建已启用 Ghost Tool 4.3.3。“显示位置”为“顶部工具栏”。*

原生工具和模式控件仍可使用。在较窄或拆分的视图中，Ghost 工具栏的所有控件仍保持相同顺序。

1. 用鼠标中键横向拖动原生控件行，找到可见宽度以外的控件。

2. 如果 Ghost 控件已隐藏，选择“视图 > 显示残影工具栏”。

3. 保存偏好设置，以保留显示选项。

<a id="set-the-interface-language"></a>

## 设置界面语言

Ghost Tool 的本地化候选版本支持英语、日语、韩语、简体中文、葡萄牙语、西班牙语和法语。这些语言设置步骤适用于该候选版本。
Bforartists 的语言控件需要支持翻译的构建。

1. 打开“编辑 > 偏好设置 > 界面”。

2. 在“语言”中选择所需语言。

3. 使用非英语语言时，启用“翻译”下的“界面”“工具提示”和“报告”。

4. 打开 Ghost Tool 的插件偏好设置。

5. 将“语言”设为“界面语言”。

“界面语言”使 Ghost Tool 的自定义文本跟随应用程序的界面语言。
禁用“界面”后，自动选择语言的自定义文本会恢复为英语。
明确指定 Ghost Tool 的语言会改变自定义文本。原生控件和工具提示仍使用应用程序的语言。
要使整个界面使用同一种语言，请将两处语言设置保持一致。
已有的对象名称、骨骼名称和已保存数据的标识符保持原文。

<a id="quick-start-inspect-an-animated-target"></a>

## 快速开始：检查动画目标

1. 选择有动画的对象或姿态骨骼。

2. 启用第一个残影图标。

3. 单击“残影”，显示网格预览。

4. 分别设置“之前”和“之后”。

5. 选择“线框”或“实体”作为网格外观。

6. 长按“残影”，调整采样和外观。

7. 单击“路径”，显示运动路径。

8. 单击“添加选中项路径”，保留另一个选中目标。

9. 启用“标记显示”，在已添加的路径上显示可编辑点。

10. 单击“拖动”。

11. 在 3D 视图中选择一个标记。

12. 移动标记。

13. 确认移动。

14. 选择另一个标记，继续编辑。

15. 要退出拖动标记模式，再次单击“拖动”或按 Escape。

![带网格残影预览的动画立方体](images/zh/4.3.3-overview.png)

*图 2. 缓存的网格残影围绕着动画立方体。第一个残影图标用于启用 Ghost Tool。*

没有路径目标时，“路径”可以添加选中的动画目标。“跟随选择”显示当前选中项。通过“添加选中项路径”添加的目标会保留在路径列表中。

<a id="set-before-and-ahead-counts"></a>

## 设置“之前”和“之后”的数量

每种显示都有两个独立的数量设置。“之前”请求播放头之前时刻的采样。“之后”请求播放头之后时刻的采样。

1. 使用顶部工具栏中的数字字段或减号和加号按钮设置数量。

2. 将数量设为 0，禁用该侧的采样。

“洋葱皮选项”使用 After 表示工具栏中的 Ahead 数量。简体中文中两者都显示为“之后”。

![设置网格数量和采样的洋葱皮选项](images/zh/4.3.3-skin-options.png)

*图 4. “洋葱皮选项”显示网格数量、采样、不透明度和“实时更新洋葱皮”。*

数量指定要请求多少个采样。采样设置指定它们的位置。

本例按以下步骤设置：

1. 将播放头设为第 20 帧。

2. 将“残影”的“之前”设为 3。

3. 将“之后”设为 2。

4. 将帧步长设为 2。

较早的采样请求第 18、16 和 14 帧。较晚的采样请求第 22 和 24 帧。可用动画和范围限制可能约束这些请求。当前姿态不计入“之前”或“之后”的采样。

“按关键帧”使用动画关键帧，而非等间距的帧。其间隔设置可以跳过部分关键帧。更改“路径”的数量字段时，会根据这些数量选择播放头周围的区间。高级范围模式使用各自的规则。

<a id="hold-a-tool-for-its-settings"></a>

## 长按工具打开设置

支持长按的按钮有两种操作：

1. 单击按钮，执行主要操作。

2. 长按按钮，打开参数菜单。

“弧线样式”和“设置”通过普通单击打开。

| 长按的控件 | 可用设置 |
| --- | --- |
| Ghost Tool | 拖动播放头时更新网格、拖动播放头时更新标记、暂停更新 |
| 残影 | 采样、间隔（帧）、关键帧间隔、不透明度、最前显示、淡出 |
| 路径 | 采样和间隔、线条样式、帧号、贝塞尔控制柄 |
| 标记显示 | 与“路径”共用的采样、关键帧圆点、标记帧号 |
| 拖动 | 松开时、曲线形状或平滑相邻关键帧、邻近帧影响范围、衰减 |
| 固定 | 固定说明、解除固定所有标记 |
| 跟随选择 | 高亮活动路径 |
| 间距短线 | 加速度指示器 |

按帧步长采样使用“间隔（帧）”。值为 1 时采样每一帧。关键帧采样使用关键帧间隔控件。部分控件可设置自定义间隔。

标记和运动路径共用采样。通过“标记显示”更改采样，也会更改“路径”的采样。

“设置 > 洋葱皮选项”打开图 4 的网格控件。“设置 > 运动路径”打开图 7 的目标和控制柄控件。

<a id="drag-markers-repeatedly"></a>

## 重复拖动标记

1. 启用 Ghost Tool。

2. 为动画目标启用可编辑标记。

3. 单击“拖动”。

4. 在 3D 视图中单击一个可见标记。

5. 移动标记。

6. 确认移动。

单击空白处时，选择器会继续等待。确认移动后，“拖动”仍保持启用，可继续下一次编辑。所有拖动标记按钮共用此模式。

停止操作：

1. 再次单击“拖动”或按 Escape。

移动过程中按 Escape 会取消本次移动。Ghost Tool 会恢复本次移动前的原始曲线和标记位置。此前已确认的移动仍作为单独的编辑保留。

1. 要撤回此前已确认的移动，使用“撤销”。

禁用 Ghost Tool 会结束编辑。目标丢失、文件变化、历史记录变化或插件关闭，也会结束或取消受影响的会话。

路径控制柄拖动也支持重复选择。

![运动路径的目标和控制柄控件](images/zh/4.3.3-path-targets.png)

*图 7. “运动路径”将动画立方体保留为目标。本例启用了“标记”和“控制柄”。*

1. 在“路径”设置中启用“贝塞尔控制柄”。

2. 启动控制柄拖动操作。

3. 选择一个可见控制柄。

4. 移动控制柄。

5. 确认移动。

6. 选择另一个控制柄，继续操作。

Shift+G 仍可使用。拖动控制柄时，Alt 可切换控制柄的对齐行为。Escape 会取消正在进行的控制柄移动并退出模式。

<a id="choose-smooth-or-sharp-motion-edits"></a>

## 选择平滑或锐利的运动编辑

1. 长按“拖动”。

2. 查看“松开时”。

3. 选择“调整控制柄形状”或“插入关键帧”。

“调整控制柄形状”更改现有贝塞尔控制柄，使曲线经过移动后的采样点。它不会添加关键帧。

“曲线形状”提供三种选择：

| 选项 | 效果 |
| --- | --- |
| 自由 | 控制柄不受角度限制地调整。 |
| 已锁定 | 控制柄角度保持不变。控制柄长度可以改变。 |
| 平滑 | 将控制柄的影响重新分配到整个区段。 |

“设置 > 编辑运动”包含与“拖动”长按菜单相同的松开动作和曲线形状选项。

![编辑运动中的调整控制柄形状设置](images/zh/4.3.3-reshape-options.png)

*图 8. “编辑运动”显示“调整控制柄形状”，曲线处理为“自由”。“影响范围”控制对邻近帧的影响。*

“插入关键帧”在标记所在帧写入关键帧。插入后，“平滑相邻关键帧”可以平滑邻近关键帧的控制柄。“邻近帧影响范围”和“衰减”控制对周围帧的影响。

![编辑运动中的关键帧编辑和固定控件](images/zh/4.3.3-edit-motion.png)

*图 9. “编辑运动”显示“插入关键帧”“平滑相邻关键帧”、缓动和固定控件。“绘制关键帧”需要标注笔画。*

采样之间的距离也会影响显示的线条。采样间距过大时，即使动画曲线平滑，显示的线条仍会粗略。

1. 要检查结果，选择更小的帧步长。

增加显示采样不会改变动画插值或控制柄形状。

<a id="pin-markers-and-manage-path-targets"></a>

## 固定标记并管理路径目标

1. 单击“固定”。

2. 单击一个可见标记，切换其固定状态。

3. 要选择另一个标记，再次单击“固定”。

“固定”每次选择一个标记。它不会像“拖动”一样保持启用。多个标记可以同时保持固定。

调整形状时，已固定的标记保持原位。刷新会保留匹配的已固定标记记录。

解除所有标记的固定：

1. 长按“固定”。

2. 选择“解除固定所有标记”。

添加的路径目标会将对象或骨骼保留在路径列表中。这不会将所有动画采样保持在某一时刻的状态。“跟随选择”会改变所选项的预览。通过“添加选中项路径”添加的目标会保留在路径列表中。

“设置”中的路径列表包含目标控件。“标记显示”沿已添加的路径显示可编辑点。“关键帧圆点”是单独的显示辅助功能。

图 7 显示路径列表。图 9 显示“编辑运动”中的固定和全部解除固定控件。

<a id="live-updates-and-native-animation-editing"></a>

## 实时更新与原生动画编辑

“实时更新标记”和“实时更新洋葱皮”默认关闭。现有场景保留已保存的值。关闭这些选项时，拖动播放头期间会保留上次刷新的预览。

1. 长按总残影图标，打开“拖动播放头时更新标记”和“拖动播放头时更新网格”。

这些控件使用相同的标记和网格更新设置。“暂停更新”会暂停自动更新。

“设置 > 标记选项”包含相同的标记更新控件。图 4 显示“洋葱皮选项”中的“实时更新洋葱皮”。

![带实时更新控件的标记选项](images/zh/4.3.3-marker-options.png)

*图 10. “标记选项”包含“实时更新标记”“暂停更新”和更新延迟。*

进行原生移动、旋转、缩放和操纵器操作时，Ghost Tool 会保留上次预览。它不会在这些操作期间逐帧移动动画。确认或取消后，它会等待编辑稳定，再刷新现有残影。

可以保持启用自动插帧。不使用自动插帧时：

1. 确认姿态。

2. 插入所需关键帧。

高级标记控件中的“生成”会在请求时重新生成预览。

在 4.3.3 中，Anim Assist 的时间线指针空闲时，Ghost Tool 可以生成标记和洋葱皮。此例外仅适用于该被动指针处理程序。

正在操作的 Anim Assist 滑块、变换、操纵器、播放头拖动以及未知的模态操作仍会暂停采样。

1. 再次生成前，结束当前操作。

此修复不会改变预览更新默认值或源动画的行为。

高级控件仍包含“标记目标”、洋葱皮来源、范围、细分和外观设置。缓存标记和洋葱皮的可见性控件可显示或隐藏现有预览，而无需重新生成。

“清除全部残影”会移除标记和洋葱皮。

1. 要隐藏预览而不移除它们，使用可见性控件。

无法通过单击或框选选择已隐藏的标记。

<a id="save-compare-and-restore-snapshots"></a>

## 保存、比较和恢复快照

1. 打开“设置”。

2. 打开“比较”。

3. 选择所需“范围”。

4. 确认显示的捕获目标。

5. 为选中目标启用标记。

6. 单击“保存快照”。

![保存了 Motion 参考快照的比较面板](images/zh/4.3.3-compare.png)

*图 11. “比较”包含已保存的 Motion 参考快照，以及它的“隐藏”“恢复”“保存变体”和“删除”控件。*

“范围”提供“活动对象 / 选中的骨骼”“所选路径”“所选标记通道”和“场景中的全部标记”。

快照保留采样在捕获时的状态，以及捕获的关键帧和控制柄。保存并重新打开场景后，快照仍会保留。禁用再重新启用插件也会保留快照。

“隐藏”或“显示”只改变快照叠加显示，不改变动画。“保存变体”会创建独立的备选快照，并记录其来源。删除父快照后，变体仍会保留。

场景可以保留 10 个快照。

1. 达到上限时，先删除不需要的记录，再保存其他快照。

捕获、变体创建、绑定、可见性切换、删除和恢复均支持原生“撤销”和“重做”。

写入前，“恢复”会验证场景、对象、动作、槽、骨骼和通道的身份。它会恢复快照范围内捕获的曲线和标记记录。即使实时更新已关闭或暂停，它也会刷新显示。

“恢复”不会更改无关对象或任意动作修改器。对于仅含采样的旧参考，当 Ghost Tool 能够调整曲线形状时，会恢复适用的采样值。

目标被替换后需要明确绑定。绑定将参考与其目标关联。共用动作槽时无法绑定。

1. 绑定前，使用“使其独立化”将动画设为单用户数据。

“绑定到活动目标”支持每个参考对应一个原始对象及其具名骨骼通道。包含多个对象的导入参考仍可查看，但保持未绑定。Ghost Tool 无法将这些对象绑定到同一个目标。

绑定会跟随骨骼重命名。保存并重新打开后，会根据通道身份识别曲线。取消后，回滚会恢复原始曲线值。操作期间，Ghost Tool 不会将原始曲线的回滚值写入替换后的曲线。

1. 要传输比较数据，将快照导出为 JSON。

“导入”会验证并合并记录。如果 ID 与现有记录相同，“导入”会分配新 ID。它会拒绝不支持的版本或超出容量的记录。被拒绝的导入不会添加部分记录。

导入的参考和旧版参考仍可查看。由于 JSON 无法证明原始对象的身份，恢复前需要明确绑定。导入失败时，会保留无法读取的现有场景记录。

<a id="troubleshooting-and-version-evidence"></a>

## 故障排除和版本验证记录

| 问题 | 检查或操作 |
| --- | --- |
| 没有显示预览 | 启用 Ghost Tool。检查目标动画、显示可见性，以及数量是否非零。 |
| 缺少可编辑点 | 将目标添加到“路径”。启用“标记显示”。 |
| 采样过于稀疏 | 减小帧步长或更改关键帧间隔。 |
| 时间线只显示一个残影图标 | 启用该图标，展开工具条。 |
| 工具栏已隐藏 | 在偏好设置中选择“顶部工具栏”。选择“视图 > 显示残影工具栏”。 |
| 控件超出拆分后的视图宽度 | 用鼠标中键横向拖动原生控件行。 |
| 编辑期间采样处于等待状态 | 确认或取消当前编辑操作。 |
| Anim Assist 空闲时生成仍受阻 | 安装 Ghost Tool 4.3.3。重新启动 Bforartists。 |
