# Ghost Tool 4.3.3 ユーザーガイド

Ghost Tool は、Bforartists にゴーストメッシュ、モーションパス、編集可能なモーションマーカーを表示します。オニオンスキンとも呼ぶゴーストメッシュは、別のアニメーション時刻での対象の姿を示します。モーションパスは対象の動きを示します。モーションマーカーは、パス上で編集できる点です。このガイドはバージョン4.3.3を説明します。

スクリーンショットは、付属の Bforartists 5.2.3 ビルドで動作する Ghost Tool 4.3.3 を示します。標準の設定パネルでは、タイトルバーに Tear Off Panel と表示されることがあります。

バージョン4.3.2では、タイムラインでの折りたたみと、2つのゴーストアイコンの間隔を追加しました。バージョン4.3.3では、Anim Assist のタイムラインポインターが待機中でもプレビューを生成できます。編集中の操作は、引き続きサンプリングを一時停止します。

[Ghost Tool 4.3.3 インストール用 ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.3/b4_ghost_tool_v4.3.3.zip) は、単体アドオンをインストールします。[4.3.3 リリースノート](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/RELEASE-NOTES.md)と[パッケージ記録](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/package-receipt.json)には、リリースの検証記録とチェックサムがあります。

<a id="install-and-find-ghost-tool"></a>

## Ghost Tool をインストールして見つける

付属のカスタム／ネイティブテストビルドには、Ghost Tool 4.3.3 が含まれています。初期設定でアドオンが有効になります。このビルドでは、ZIP の別途インストールや手動での有効化は不要です。以下のビューポートツールバー、ツールシェルフ、サイドバー、プリファレンスの場所は、このビルドにも当てはまります。

単体アドオンをインストールする場合:

1. `b4_ghost_tool_v4.3.3.zip` をダウンロードします。

2. 「編集 > プリファレンス > アドオン > ディスクからインストール」を開きます。

3. ZIP を選択します。

4. Ghost Tool を有効にします。

5. インストール済みのバージョンを置き換えた場合は、Bforartists を再起動します。

6. プリファレンスにバージョン4.3.3と表示されることを確認します。

リポジトリの変更は、インストール済みのアドオンを自動更新しません。古い ZIP は、その ZIP 本来のバージョンをインストールします。

この手順は単体アドオンをインストールします。提案中の組み込み版は、Bforartists PR [7067](https://github.com/Bforartists/Bforartists/pull/7067) に依存します。この PR は、2026-11-19時点ではマージされていません。公開済みの公式 Bforartists ビルドには、この提案中の統合はまだ含まれていません。

Ghost Tool の既定の表示位置は、標準の3Dビューポートのツール設定行にある「上部ツールバー」です。標準ヘッダーが上部にある場合、この行はビューポートのメインヘッダーの下にあります。この行は、標準ヘッダーの配置に従います。

プリファレンスでは「右サイドバー (N)」と「左ツールシェルフ (T)」も選べます。Ghost Tool は、古い保存設定の Top Header を「上部ツールバー」に変更します。

![Ghost Tool 4.3.3 のプリファレンス](images/ja/4.3.3-preferences.png)

*図1. 付属ビルドでは Ghost Tool 4.3.3 が有効になります。「表示位置」は「上部ツールバー」です。*

標準のツールとモードの操作も使用できます。幅の狭いビューポートや分割したビューポートでも、Ghost ツールバーの操作項目は同じ順序で並びます。

1. 表示幅の外にある操作項目へ移動するには、標準の行をマウス中ボタンで左右にドラッグします。

2. Ghost の操作項目が非表示の場合は、「ビュー > ゴーストツールバーを表示」を選択します。

3. 表示設定を保持するには、プリファレンスを保存します。

## インターフェイスの言語を設定する

Ghost Tool のローカライズ候補版は、英語、日本語、韓国語、簡体字中国語、ポルトガル語、スペイン語、フランス語に対応しています。この言語設定の手順は、その候補版に適用されます。
Bforartists の言語設定には、翻訳機能を備えたビルドが必要です。

1. 「編集 > プリファレンス > インターフェイス」を開きます。

2. 「言語」で必要な言語を選択します。

3. 英語以外の言語では、「翻訳」の「インターフェイス」「ツールチップ」「報告」を有効にします。

4. Ghost Tool のアドオンプリファレンスを開きます。

5. 「言語」を「インターフェイス言語」に設定します。

「インターフェイス言語」にすると、Ghost Tool の独自テキストはアプリケーションのインターフェイス言語に従います。
「インターフェイス」を無効にすると、自動設定の独自テキストは英語に戻ります。
Ghost Tool で言語を明示的に指定すると、独自テキストが変わります。標準の操作項目とツールチップは、引き続きアプリケーションの言語を使用します。
インターフェイス全体の言語をそろえるには、両方を同じ言語に設定します。
既存のオブジェクト名、ボーン名、保存データの識別子は、元の文字列を保持します。

<a id="quick-start-inspect-an-animated-target"></a>

## クイックスタート: アニメーション対象を確認する

1. アニメーションのあるオブジェクトまたはポーズボーンを選択します。

2. 最初のゴーストアイコンを有効にします。

3. 「ゴースト」をクリックしてメッシュのプレビューを表示します。

4. 「前」と「後」を個別に設定します。

5. メッシュの外観として「ワイヤー」または「ソリッド」を選択します。

6. 「ゴースト」を長押しして、サンプリングと外観を調整します。

7. 「パス」をクリックしてモーションパスを表示します。

8. 「選択パスを追加」をクリックして、別の選択対象を保持します。

9. 「マーカー表示」を有効にして、追加したパス上に編集可能な点を表示します。

10. 「ドラッグ」をクリックします。

11. 3Dビューポートでマーカーを選択します。

12. マーカーを移動します。

13. 移動を確定します。

14. 別のマーカーを選択して編集を続けます。

15. マーカーをドラッグするモードを終了するには、「ドラッグ」をもう一度クリックするか Escape を押します。

![ゴーストメッシュのプレビューを伴うアニメーション中の立方体](images/ja/4.3.3-overview.png)

*図2. キャッシュしたゴーストメッシュが、アニメーション中の立方体を囲んでいます。最初のゴーストアイコンで Ghost Tool を有効にします。*

パスの対象がない場合、「パス」は選択中のアニメーション対象を追加できます。「選択に追従」は現在の選択対象を表示します。「選択パスを追加」で追加した対象は、パス一覧に残ります。

最初のゴーストアイコンは、ツール全体を操作します。「ゴースト」は、メッシュの表示を個別に操作します。ツール全体を無効にすると、マーカーとハンドルの編集も無効になります。

メッシュを非表示にしても、選択したスタイルは保持されます。「ワイヤー」または「ソリッド」はスタイルを選択します。「ゴースト」はメッシュを表示するかどうかを操作します。

「設定」には、マーカーの生成、対象、範囲、編集、比較、物理、外観の設定があります。「生成」と「消去」専用のアイコンは、上部の行にはありません。

<a id="set-before-and-ahead-counts"></a>

## 「前」と「後」の個数を設定する

各表示には、独立した2つの個数設定があります。「前」は再生ヘッドより前の時刻のサンプルを要求します。「後」は再生ヘッドより後の時刻のサンプルを要求します。

1. 上部ツールバーの数値欄、またはマイナスとプラスのボタンで個数を設定します。

2. 片側のサンプルを無効にするには、その個数を0に設定します。

「オニオンスキンのオプション」の After は、ツールバーの Ahead と同じ個数を示します。日本語では、どちらも「後」です。

![メッシュの個数とサンプリングを設定するオニオンスキンのオプション](images/ja/4.3.3-skin-options.png)

*図4. 「オニオンスキンのオプション」には、メッシュの個数、サンプリング、不透明度、「スキンをライブ更新」があります。*

個数は、要求するサンプルの数を指定します。サンプリングは、その位置を指定します。

この例では、次のように設定します。

1. 再生ヘッドをフレーム20に設定します。

2. 「ゴースト」の「前」を3に設定します。

3. 「後」を2に設定します。

4. フレームステップを2に設定します。

前のサンプルはフレーム18、16、14を要求します。後のサンプルはフレーム22、24を要求します。利用可能なアニメーションと範囲の制限により、要求が制限されることがあります。現在のポーズは、「前」または「後」のサンプルには含まれません。

「キーフレーム別」は、等間隔のフレームの代わりにアニメーションキーを使用します。その間隔設定でキーを間引けます。「パス」の個数欄を変更すると、その個数に基づいて再生ヘッド周辺の範囲を選択します。詳細な範囲モードは、それぞれの規則を使用します。

<a id="hold-a-tool-for-its-settings"></a>

## ツールを長押しして設定を開く

対応するボタンには、2つの操作があります。

1. 主な操作には、ボタンをクリックします。

2. パラメーターメニューを開くには、ボタンを長押しします。

「軌跡のスタイル」と「設定」は、通常のクリックで開きます。

| 長押しする操作項目 | 使用できる設定 |
| --- | --- |
| Ghost Tool | スクラブ中にメッシュを更新、スクラブ中にマーカーを更新、更新を停止 |
| ゴースト | サンプリング、間隔（フレーム）、キーフレーム間隔、不透明度、最前面、フェード |
| パス | サンプリングと間隔、線のスタイル、フレーム番号、ベジェハンドル |
| マーカー表示 | 「パス」と共通のサンプリング、キーフレームの点、マーカーのフレーム番号 |
| ドラッグ | 離したとき、カーブ形状または周辺を滑らかに、周辺フレームへの影響範囲、減衰 |
| 固定 | 固定の説明、すべてのマーカーの固定を解除 |
| 選択に追従 | アクティブパスを強調 |
| 間隔目盛り | 加速度インジケーター |

フレームステップによるサンプリングは、「間隔（フレーム）」を使用します。値が1なら、すべてのフレームをサンプリングします。キーフレームのサンプリングは、キーフレーム間隔の操作項目を使用します。独自の間隔を指定できる操作項目もあります。

マーカーとモーションパスは、サンプリング設定を共有します。「マーカー表示」でサンプリングを変更すると、「パス」のサンプリングも変わります。

「設定 > オニオンスキンのオプション」は、図4のメッシュの操作項目を開きます。「設定 > モーションパス」は、図7の対象とハンドルの操作項目を開きます。

## 下部のタイムラインツールバーを使用する

コンパクトな操作列は、標準のタイムラインボタンの横の、同じ行にあります。タイムラインツールバーの下に行は追加しません。

1. 左のゴーストアイコンを有効にして、残りの操作項目を表示します。

2. そのアイコンを無効にして、操作列を折りたたみます。

Ghost Tool が有効なときは、全体のオン／オフアイコンと、メッシュ用の「ゴースト」アイコンの間に隙間が表示されます。これらの動作は4.3.2から導入されました。

![展開した Ghost Tool のタイムライン操作列](images/ja/4.3.3-timeline-enabled.png)

*図5. 有効なタイムライン操作列には、メッシュの個数、表示スタイル、マーカーの編集、パスの操作項目があります。*

![折りたたんだ Ghost Tool のタイムライン操作列](images/ja/4.3.3-timeline-collapsed.png)

*図6. Ghost Tool が無効なときは、標準のタイムライン操作項目の横に、全体を操作するゴーストアイコンだけが残ります。*

有効な操作列は、左から右に次の順序で並びます。

1. Ghost Tool 全体のオン／オフ。

2. メッシュ用の「ゴースト」表示。

3. メッシュの「前」と「後」の個数。

4. メッシュの「ワイヤー」と「ソリッド」のスタイル。

5. マーカーのドラッグ。

6. 編集可能なマーカーのひし形。

7. 「パス」表示。

8. パスの「前」と「後」の個数。

各個数の組は、上部ツールバーと同じく、時間的に前／後の順です。タイムラインでは、コンパクトな標準の数値欄を使用します。

1. サンプリングと表示を設定するには、タイムラインの「ゴースト」または「パス」を長押しします。

メニューには「フレーム単位」「キーフレーム別」とサンプリング間隔があります。「ゴーストの詳細設定」は、すべてのオプションを開きます。

下部のひし形は、編集可能なマーカーを表示または非表示にします。専用の長押しメニューは、上部ツールバーの「マーカー表示」ボタンにあります。スナップショットの操作項目は、詳細設定の「比較」にあります。

Ghost Tool が有効な場合は、グラフエディターのヘッダーにも、全体の切替とモーションパスの操作部分が表示されます。

<a id="drag-markers-repeatedly"></a>

## マーカーを繰り返しドラッグする

1. Ghost Tool を有効にします。

2. アニメーション対象の編集可能なマーカーを有効にします。

3. 「ドラッグ」をクリックします。

4. 3Dビューポートで、表示中のマーカーをクリックします。

5. マーカーを移動します。

6. 移動を確定します。

何もない場所をクリックすると、選択待ちが続きます。移動を確定した後も「ドラッグ」は有効なままで、次の編集ができます。すべてのマーカードラッグボタンが、このモードを共有します。

終了するには:

1. 「ドラッグ」をもう一度クリックするか、Escape を押します。

移動中の Escape は、その移動をキャンセルします。Ghost Tool は、その移動の前のカーブとマーカーの位置を復元します。それ以前に確定した移動は、別の編集として保持されます。

1. それ以前に確定した移動を戻すには、「元に戻す」を使用します。

Ghost Tool を無効にすると編集が終了します。対象の消失、ファイルの変更、履歴の変更、アドオンの終了によっても、関係するセッションは終了またはキャンセルされます。

パスハンドルのドラッグでも、続けて選択できます。

![モーションパスの対象とハンドルの操作項目](images/ja/4.3.3-path-targets.png)

*図7. 「モーションパス」は、アニメーション中の立方体を対象として保持しています。この例では「マーカー」と「ハンドル」が有効です。*

1. 「パス」の設定で「ベジェハンドル」を有効にします。

2. ハンドルをドラッグする操作を開始します。

3. 表示中のハンドルを選択します。

4. ハンドルを移動します。

5. 移動を確定します。

6. 別のハンドルを選択して続けます。

Shift+G も引き続き使用できます。ハンドルのドラッグ中は、Alt でハンドルの整列動作を切り替えます。Escape は、操作中のハンドル移動をキャンセルしてモードを終了します。

<a id="choose-smooth-or-sharp-motion-edits"></a>

## 滑らかな動き、または鋭い動きに編集する

1. 「ドラッグ」を長押しします。

2. 「離したとき」を確認します。

3. 「ハンドルを変形」または「キーフレームを挿入」を選択します。

「ハンドルを変形」は、移動したサンプルをカーブが通るように、既存のベジェハンドルを変更します。キーフレームは追加しません。

「カーブ形状」には、3つの選択肢があります。

| 選択肢 | 効果 |
| --- | --- |
| フリー | 角度を制限せずにハンドルを調整します。 |
| ロック | ハンドルの角度を固定します。ハンドルの長さは変更できます。 |
| スムーズ | ハンドルの影響を区間全体に再配分します。 |

「設定 > 動きを編集」には、「ドラッグ」の長押しメニューと同じ、離したときの動作とカーブ形状の選択肢があります。

![「動きを編集」の「ハンドルを変形」設定](images/ja/4.3.3-reshape-options.png)

*図8. 「動きを編集」では「ハンドルを変形」と「フリー」のカーブ処理が選択されています。影響範囲は、近くのフレームへの影響を操作します。*

「キーフレームを挿入」は、マーカーのフレームにキーを書き込みます。挿入後に「周辺を滑らかに」で、隣接するキーのハンドルを滑らかにできます。「周辺フレームへの影響範囲」と「減衰」は、周囲のフレームへの影響を操作します。

![「動きを編集」のキーフレーム編集と固定の操作項目](images/ja/4.3.3-edit-motion.png)

*図9. 「動きを編集」には、「キーフレームを挿入」「周辺を滑らかに」、イージング、固定の操作項目があります。「描画からキー作成」には、アノテーションのストロークが必要です。*

サンプル同士の間隔も、表示する線に影響します。サンプルの間隔が広いと、アニメーションカーブが滑らかでも、表示する線は粗くなります。

1. 結果を確認するには、フレームステップを小さくします。

表示サンプルを追加しても、アニメーションの補間やハンドルの形状は変わりません。

<a id="pin-markers-and-manage-path-targets"></a>

## マーカーを固定してパスの対象を管理する

1. 「固定」をクリックします。

2. 表示中のマーカーをクリックして、固定状態を切り替えます。

3. 別のマーカーを選択するには、「固定」をもう一度クリックします。

「固定」は、一度に1つのマーカーを選択します。「ドラッグ」のように有効なままにはなりません。複数のマーカーを同時に固定しておくことはできます。

固定したマーカーは、変形中も位置を保持します。更新時には、一致する固定マーカーの記録を保持します。

すべてのマーカーの固定を解除するには:

1. 「固定」を長押しします。

2. 「すべてのマーカーの固定を解除」を選択します。

追加したパスの対象は、オブジェクトまたはボーンをパス一覧に保持します。すべてのアニメーションサンプルをその時点の状態で保持するものではありません。「選択に追従」は、選択対象のプレビューを変更します。「選択パスを追加」で追加した対象は、パス一覧に残ります。

「設定」のパス一覧には、対象の操作項目があります。「マーカー表示」は、追加したパスに沿って編集可能な点を表示します。「キーフレームの点」は、別の表示補助です。

図7はパス一覧を示します。図9は「動きを編集」の固定と全固定解除を示します。

<a id="live-updates-and-native-animation-editing"></a>

## ライブ更新と標準のアニメーション編集

「マーカーをライブ更新」と「スキンをライブ更新」は、既定ではオフです。既存のシーンは保存済みの値を保持します。これらのオプションがオフの場合、スクラブ中も最後に更新したプレビューが残ります。

1. 「スクラブ中にマーカーを更新」と「スクラブ中にメッシュを更新」を開くには、全体を操作するゴーストアイコンを長押しします。

これらの操作項目は、同じマーカーとメッシュの更新設定を使用します。「更新を停止」は、自動更新を一時停止します。

「設定 > マーカーのオプション」には、同じマーカー更新の操作項目があります。図4は、「オニオンスキンのオプション」の「スキンをライブ更新」を示します。

![ライブ更新の操作項目があるマーカーのオプション](images/ja/4.3.3-marker-options.png)

*図10. 「マーカーのオプション」には、「マーカーをライブ更新」「更新を停止」と更新の遅延時間があります。*

標準の移動、回転、スケール、ギズモの操作中は、Ghost Tool は最後のプレビューを保持します。これらの操作中に、アニメーションのフレームを順に移動しません。確定またはキャンセルの後は、編集が落ち着くまで待ちます。その後、既存のゴーストを更新します。

自動キー挿入は、有効なままで使用できます。自動キー挿入を使わない場合:

1. ポーズを確定します。

2. 意図したキーを挿入します。

詳細なマーカー操作項目の「生成」は、指示したときにプレビューを再生成します。

4.3.3では、Anim Assist のタイムラインポインターが待機中でも、Ghost Tool はマーカーとオニオンスキンを生成できます。この例外は、その待機状態のポインターハンドラーだけに適用されます。

操作中の Anim Assist のスライダー、トランスフォーム、ギズモ、フレームのスクラブ、不明なモーダル操作は、引き続きサンプリングを一時停止します。

1. 再び生成する前に、操作中のジェスチャーを終了します。

この修正は、プレビュー更新の既定値や元のアニメーションの動作を変更しません。

詳細な操作項目には、引き続き「マーカーの対象」、オニオンスキンのソース、範囲、細分化、外観の設定があります。キャッシュしたマーカーとスキンの表示設定は、再生成せずに既存のプレビューを表示または非表示にします。

「すべてのゴーストを消去」は、マーカーとオニオンスキンを除去します。

1. プレビューを除去せずに隠すには、表示の操作項目を使用します。

非表示のマーカーは、クリックやボックス選択では選択できません。

<a id="save-compare-and-restore-snapshots"></a>

## スナップショットを保存、比較、復元する

1. 「設定」を開きます。

2. 「比較」を開きます。

3. 意図した「範囲」を選択します。

4. 表示されたキャプチャー対象を確認します。

5. 選択対象のマーカーを有効にします。

6. 「スナップショットを保存」をクリックします。

![Motion 参照スナップショットを保存した「比較」](images/ja/4.3.3-compare.png)

*図11. 「比較」には、保存した Motion 参照スナップショットと、その「非表示」「復元」「派生版を保存」「削除」の操作項目があります。*

「範囲」には、「アクティブオブジェクト / 選択ボーン」「選択パス」「選択マーカーのチャンネル」「シーンの全マーカー」があります。

スナップショットは、その時点の状態で保持したサンプルと、キャプチャーしたキーフレームおよびハンドルを保持します。シーンを保存して開き直した後も、スナップショットは残ります。アドオンを無効にして再び有効にしても保持されます。

「非表示」または「表示」は、アニメーションを変えずにスナップショットのオーバーレイを切り替えます。「派生版を保存」は、独立した別のスナップショットを作り、その派生元を記録します。親のスナップショットを削除しても、派生版は残ります。

シーンには、スナップショットを10個保持できます。

1. 上限に達した場合は、不要な記録を削除してから、別のスナップショットを保存します。

キャプチャー、派生版の作成、関連付け、表示切替、削除、復元は、標準の「元に戻す」と「やり直す」に対応します。

「復元」は、書き込む前に、シーン、オブジェクト、アクション、スロット、ボーン、チャンネルの同一性を検証します。スナップショットの範囲内で、キャプチャーしたカーブとマーカーの記録を復元します。ライブ更新がオフまたは停止中でも、表示を更新します。

「復元」は、無関係なオブジェクトや任意のアクションモディファイアーを変更しません。サンプルのみを保存した古い参照では、Ghost Tool がカーブを変形できる場合、適切なサンプル値を復元します。

置き換えた対象には、明示的な関連付けが必要です。関連付けは、参照とその対象を結び付けます。アクションスロットを共有している場合は、関連付けできません。

1. 関連付ける前に、アニメーションをシングルユーザーにします。

「アクティブ対象に関連付け」は、参照ごとに、元のオブジェクト1つと、その名前付きボーンチャンネルに対応します。複数のオブジェクトを含むインポート済みの参照は、未関連付けのまま表示できます。Ghost Tool は、それらのオブジェクトを1つの対象に関連付けできません。

関連付けは、ボーン名の変更に追従します。保存して開き直した後は、チャンネルの同一性でカーブを識別します。キャンセル後のロールバックは、元のカーブ値を復元します。ジェスチャー中に、Ghost Tool は元のカーブ用のロールバック値を、置き換えられたカーブに書き込みません。

<a id="transfer-snapshots-and-use-advanced-tools"></a>

## スナップショットを転送して詳細ツールを使用する

1. 比較データを転送するには、スナップショットを JSON にエクスポートします。

インポートは、記録を検証して統合します。ID が既存の記録と一致する場合、インポートは新しい ID を割り当てます。未対応のバージョンや、保存上限を超える記録は拒否します。拒否したインポートは、一部の記録だけを追加することはありません。

インポートした参照や旧形式の参照は、引き続き表示できます。JSON では元のオブジェクトの同一性を証明できないため、復元には明示的な関連付けが必要です。インポートに失敗しても、読み取れない既存のシーン記録は保持されます。

![Ghost Tool の JSON エクスポートとインポートの設定](images/ja/4.3.3-transfer-settings.png)

*図12. 「設定」には、Ghost Tool の JSON データ用の「エクスポート」と「インポート」があります。*

「動きを編集」には、イージングプリセットとカスタムイージングの操作項目があります。イージングは、動きの速度がどう変化するかを操作します。「描画からキー作成」は、最長のアノテーションストロークを位置のパスに変換します。交差する短線がキーを示します。「描画からキー作成」のダイアログは、選択した対象を保持します。

「設定」、サイドバー、シェルフには、「物理的な動き」「外観」「比較」などの詳細ツールがあります。

図9は、「動きを編集」のイージングと「描画からキー作成」を示します。

![物理プレビューとキー書き込みの操作項目](images/ja/4.3.3-physics.png)

*図13. 「物理」には、投げたときの軌道プレビューと、物理的な動きの操作項目があります。「キーに書き込み」は、プレビューをアニメーションキーに書き込みます。*

## トラブルシューティングとバージョンの検証記録

| 問題 | 確認または操作 |
| --- | --- |
| プレビューが表示されない | Ghost Tool を有効にします。対象のアニメーション、表示状態、個数が0より大きいことを確認します。 |
| 編集可能な点がない | 対象を「パス」に追加します。「マーカー表示」を有効にします。 |
| サンプルがまばらすぎる | フレームステップを小さくするか、キーフレーム間隔を変更します。 |

| ツールバーが非表示になっている | プリファレンスで「上部ツールバー」を選択します。「ビュー > ゴーストツールバーを表示」を選択します。 |
| 操作項目が分割したビューポートからはみ出す | 標準の行をマウス中ボタンで左右にドラッグします。 |
| 編集中にサンプリングが待機する | 操作中の編集ジェスチャーを確定またはキャンセルします。 |
| Anim Assist の待機中も生成が妨げられる | Ghost Tool 4.3.3 をインストールします。Bforartists を再起動します。 |
