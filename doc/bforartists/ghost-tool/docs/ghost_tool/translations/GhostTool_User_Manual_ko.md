# Ghost Tool 4.3.3 사용 안내서

Ghost Tool은 Bforartists에서 고스트 메시, 동작 경로, 편집 가능한 동작 마커를 표시합니다. 어니언 스킨이라고도 하는 고스트 메시는 다른 애니메이션 시점의 대상을 보여 줍니다. 동작 경로는 대상의 움직임을 보여 줍니다. 동작 마커는 이 경로에서 편집할 수 있는 점입니다. 이 안내서는 버전 4.3.3을 설명합니다.

스크린샷은 제공된 Bforartists 5.2.3 빌드의 Ghost Tool 4.3.3을 보여 줍니다. 기본 제공 설정 패널의 제목 표시줄에는 Tear Off Panel이 표시될 수 있습니다.

버전 4.3.2에서는 타임라인 접기와 두 고스트 아이콘 사이의 간격을 추가했습니다. 버전 4.3.3에서는 Anim Assist의 타임라인 포인터가 대기 중이어도 미리보기를 생성할 수 있습니다. 진행 중인 편집 동작은 여전히 샘플링을 일시 정지합니다.

[Ghost Tool 4.3.3 설치 ZIP](https://github.com/Axleonex/B4Artists_Toolkit/releases/download/ghost-v4.3.3/b4_ghost_tool_v4.3.3.zip)은 독립형 애드온을 설치합니다. [4.3.3 릴리스 노트](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/RELEASE-NOTES.md)와 [패키지 기록](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/package-receipt.json)에는 릴리스 검증 기록과 체크섬이 있습니다.

## Ghost Tool 설치 및 위치 확인

제공된 사용자 정의/네이티브 테스트 빌드에는 Ghost Tool 4.3.3이 포함되어 있습니다. 초기 환경 설정에서 애드온이 활성화되어 있습니다. 이 빌드에서는 ZIP을 따로 설치하거나 직접 활성화할 필요가 없습니다. 아래에 설명하는 뷰포트 도구 모음, 도구 선반, 사이드바, 환경 설정의 위치는 이 빌드에도 적용됩니다.

독립형으로 설치하려면:

1. `b4_ghost_tool_v4.3.3.zip`을 다운로드하세요.

2. 편집 > 환경 설정 > 애드온 > 디스크에서 설치를 여세요.

3. ZIP을 선택하세요.

4. Ghost Tool을 활성화하세요.

5. 설치된 버전을 교체했다면 Bforartists를 다시 시작하세요.

6. 환경 설정에 버전 4.3.3이 표시되는지 확인하세요.

저장소를 변경해도 설치된 애드온은 자동으로 갱신되지 않습니다. 오래된 ZIP을 설치하면 그 ZIP에 담긴 원래 버전이 설치됩니다.

이 절차는 독립형 애드온을 설치합니다. 제안된 내장 버전은 Bforartists PR [7067](https://github.com/Bforartists/Bforartists/pull/7067)에 달려 있습니다. 이 PR은 2026-11-19 현재 병합되지 않았습니다. 출시된 공식 Bforartists 빌드에는 제안된 이 통합이 아직 포함되어 있지 않습니다.

Ghost Tool의 기본 표시 위치는 기본 3D 뷰포트 도구 설정 행의 상단 도구 모음입니다. 기본 헤더가 위에 있으면 이 행은 뷰포트 주 헤더 아래에 있습니다. 이 행은 기본 헤더의 정렬을 따릅니다.

환경 설정에서는 오른쪽 사이드바(N)와 왼쪽 도구 선반(T)도 선택할 수 있습니다. Ghost Tool은 이전에 저장된 Top Header 선택을 상단 도구 모음으로 바꿉니다.

![Ghost Tool 4.3.3 환경 설정](images/ko/4.3.3-preferences.png)

*그림 1. 제공된 빌드는 Ghost Tool 4.3.3을 활성화합니다. 표시 위치는 상단 도구 모음입니다.*

기본 도구와 모드 조작 기능도 계속 사용할 수 있습니다. 뷰포트가 좁거나 분할되어 있어도 Ghost 도구 모음의 모든 조작 항목은 같은 순서를 유지합니다.

1. 보이는 너비 밖의 조작 항목에 접근하려면 기본 행을 마우스 가운데 버튼으로 가로로 드래그하세요.

2. Ghost 조작 항목이 숨겨져 있으면 뷰 > 고스트 도구 모음 표시를 선택하세요.

3. 표시 선택을 유지하려면 환경 설정을 저장하세요.

## 인터페이스 언어 설정

Ghost Tool의 현지화 후보 버전은 영어, 일본어, 한국어, 중국어 간체, 포르투갈어, 스페인어, 프랑스어를 지원합니다. 이 언어 설정 절차는 해당 후보 버전에 적용됩니다.
Bforartists의 언어 설정에는 번역을 지원하는 빌드가 필요합니다.

1. 편집 > 환경 설정 > 인터페이스를 여세요.

2. 언어에서 필요한 언어를 선택하세요.

3. 영어 이외의 언어를 사용하려면 번역 아래의 인터페이스, 도움말, 보고서를 활성화하세요.

4. Ghost Tool의 애드온 환경 설정을 여세요.

5. 언어를 인터페이스 언어로 설정하세요.

인터페이스 언어를 선택하면 Ghost Tool의 자체 텍스트가 애플리케이션의 인터페이스 언어를 따릅니다.
인터페이스를 비활성화하면 자동 언어 설정의 자체 텍스트가 영어로 돌아갑니다.
Ghost Tool에서 언어를 직접 지정하면 자체 텍스트가 바뀝니다. 기본 조작 항목과 도움말은 계속 애플리케이션의 언어를 사용합니다.
전체 인터페이스의 언어를 맞추려면 두 언어 설정을 일치시키세요.
기존 오브젝트 이름, 본 이름, 저장된 데이터 식별자는 원래 텍스트를 유지합니다.

## 빠른 시작: 애니메이션 대상 확인

1. 애니메이션이 있는 오브젝트나 포즈 본을 선택하세요.

2. 첫 번째 고스트 아이콘을 활성화하세요.

3. 고스트를 클릭하여 메시 미리보기를 표시하세요.

4. 이전과 이후를 각각 설정하세요.

5. 메시 모양으로 와이어 또는 솔리드를 선택하세요.

6. 고스트를 길게 눌러 샘플링과 모양을 조정하세요.

7. 경로를 클릭하여 동작 경로를 표시하세요.

8. 선택 경로 추가를 클릭하여 다른 선택 대상도 유지하세요.

9. 마커 표시를 활성화하여 추가한 경로에 편집 가능한 점을 표시하세요.

10. 드래그를 클릭하세요.

11. 3D 뷰포트에서 마커를 선택하세요.

12. 마커를 이동하세요.

13. 이동을 확정하세요.

14. 다른 마커를 선택하여 편집을 계속하세요.

15. 마커 드래그 모드를 종료하려면 드래그를 다시 클릭하거나 Escape를 누르세요.

![고스트 메시 미리보기가 있는 애니메이션 큐브](images/ko/4.3.3-overview.png)

*그림 2. 캐시에 저장된 고스트 메시가 애니메이션 큐브를 둘러싸고 있습니다. 첫 번째 고스트 아이콘은 Ghost Tool을 활성화합니다.*

경로 대상이 없으면 경로가 선택된 애니메이션 대상을 추가할 수 있습니다. 선택 항목 추적은 현재 선택 항목을 표시합니다. 선택 경로 추가로 추가한 대상은 경로 목록에 남습니다.

| 드래그 | 반복 편집을 위한 마커 드래그 모드를 활성화합니다. 길게 누르면 동작 편집 설정을 엽니다. |
| 고정 | 고정하거나 고정 해제할 마커를 선택합니다. 길게 누르면 모든 마커 고정 해제를 엽니다. |
| 마커 표시 | 편집 가능한 경로 마커를 표시하거나 숨깁니다. 길게 누르면 샘플링과 레이블을 설정합니다. |
| 궤적 스타일 | 솔리드, 속도 색상, 페이드 선택 항목을 엽니다. |

| 설정 | 고급 조작 항목을 엽니다. |

첫 번째 고스트 아이콘은 도구 전체를 제어합니다. 고스트는 메시 표시 여부를 별도로 제어합니다. 도구 전체를 비활성화하면 마커와 핸들 편집도 비활성화됩니다.

메시를 숨겨도 선택한 스타일은 유지됩니다. 와이어 또는 솔리드는 스타일을 선택합니다. 고스트는 메시를 표시할지를 제어합니다.

마커 표시는 고정 바로 오른쪽의 마름모입니다. 조작 항목 위에 포인터를 놓으면 레이블이 나타납니다.

궤적 스타일은 고스트 동작 궤적을 제어합니다. 와이어/솔리드는 메시 표시를 제어합니다. 경로의 선 스타일 설정은 경로 표시를 제어합니다.

설정에는 마커 생성, 대상, 범위, 편집, 비교, 물리, 모양 옵션이 있습니다. 생성과 지우기에는 별도의 상단 행 아이콘이 없습니다.

## 이전 및 이후 개수 설정

각 표시에는 독립적인 두 개수 설정이 있습니다. 이전은 재생 헤드보다 이른 시점의 샘플을 요청합니다. 이후는 재생 헤드보다 늦은 시점의 샘플을 요청합니다.

1. 상단 도구 모음의 숫자 필드나 빼기와 더하기 버튼으로 개수를 설정하세요.

2. 한쪽 샘플을 비활성화하려면 해당 개수를 0으로 설정하세요.

어니언 스킨 옵션의 After는 도구 모음의 Ahead 개수입니다. 한국어에서는 둘 다 이후로 표시합니다.

![메시 개수와 샘플링을 위한 어니언 스킨 옵션](images/ko/4.3.3-skin-options.png)

*그림 4. 어니언 스킨 옵션에는 메시 개수, 샘플링, 불투명도, 스킨 실시간 갱신이 있습니다.*

개수는 요청할 샘플 수를 지정합니다. 샘플링은 샘플의 위치를 지정합니다.

이 예제에서는:

1. 재생 헤드를 프레임 20으로 설정하세요.

2. 고스트의 이전을 3으로 설정하세요.

3. 이후를 2로 설정하세요.

4. 프레임 간격을 2로 설정하세요.

이전 샘플은 프레임 18, 16, 14를 요청합니다. 이후 샘플은 프레임 22, 24를 요청합니다. 사용 가능한 애니메이션과 범위 한계에 따라 이 요청이 제한될 수 있습니다. 현재 포즈는 이전이나 이후 샘플에 포함되지 않습니다.

키프레임별은 일정한 프레임 간격 대신 애니메이션 키를 사용합니다. 간격 설정으로 일부 키를 건너뛸 수 있습니다. 경로의 개수 필드를 바꾸면 해당 개수에 따라 재생 헤드 주위의 구간을 선택합니다. 고급 범위 모드는 각자의 규칙을 사용합니다.

## 도구를 길게 눌러 설정 열기

지원되는 버튼에는 두 가지 동작이 있습니다.

1. 기본 동작을 실행하려면 버튼을 클릭하세요.

2. 매개변수 메뉴를 열려면 버튼을 길게 누르세요.

궤적 스타일과 설정은 일반 클릭으로 엽니다.

| 길게 누를 조작 항목 | 사용 가능한 설정 |
| --- | --- |
| Ghost Tool | 재생 위치를 훑을 때 메시 갱신, 재생 위치를 훑을 때 마커 갱신, 갱신 일시 정지 |
| 고스트 | 샘플링, 간격(프레임), 키프레임 간격, 불투명도, 앞에 표시, 페이드 |
| 경로 | 샘플링과 간격, 선 스타일, 프레임 번호, 베지어 핸들 |
| 마커 표시 | 경로와 공유하는 샘플링, 키프레임 점, 마커 프레임 번호 |
| 드래그 | 놓을 때, 곡선 모양 또는 이웃 키 부드럽게, 주변 프레임 영향 범위, 감쇠 |
| 고정 | 고정 안내, 모든 마커 고정 해제 |
| 선택 항목 추적 | 활성 경로 강조 |
| 간격 눈금 | 가속도 표시 |

프레임 간격 샘플링은 간격(프레임)을 사용합니다. 값이 1이면 모든 프레임을 샘플링합니다. 키프레임 샘플링은 키프레임 간격 조작 항목을 사용합니다. 일부 조작 항목에서는 사용자 지정 간격을 설정할 수 있습니다.

마커와 동작 경로는 샘플링을 공유합니다. 마커 표시에서 샘플링을 변경하면 경로 샘플링도 바뀝니다.

설정 > 어니언 스킨 옵션은 그림 4의 메시 조작 항목을 엽니다. 설정 > 동작 경로는 그림 7의 대상과 핸들 조작 항목을 엽니다.

## 아래쪽 타임라인 도구 모음 사용

작은 도구 모음은 기본 타임라인 버튼 옆의 같은 행에 있습니다. 타임라인 도구 모음 아래에 행을 추가하지 않습니다.

1. 왼쪽 고스트 아이콘을 활성화하여 나머지 조작 항목을 표시하세요.

2. 해당 아이콘을 비활성화하여 도구 모음을 접으세요.

Ghost Tool이 활성화되면 전체 켜기/끄기 아이콘과 메시용 고스트 아이콘 사이에 간격이 표시됩니다. 이 동작은 4.3.2부터 적용되었습니다.

![펼친 Ghost Tool 타임라인 도구 모음](images/ko/4.3.3-timeline-enabled.png)

*그림 5. 활성화된 타임라인 도구 모음에는 메시 개수, 표시 스타일, 마커 편집, 경로 조작 항목이 있습니다.*

![접힌 Ghost Tool 타임라인 도구 모음](images/ko/4.3.3-timeline-collapsed.png)

*그림 6. Ghost Tool을 비활성화하면 기본 타임라인 조작 항목 옆에 전체 고스트 아이콘만 남습니다.*

활성화된 도구 모음은 왼쪽부터 다음 순서입니다.

1. Ghost Tool 전체 켜기/끄기.

2. 메시용 고스트 표시.

3. 메시의 이전 및 이후 개수.

4. 메시의 와이어 및 솔리드 스타일.

5. 마커 드래그.

6. 편집 가능한 마커의 마름모.

7. 경로 표시.

8. 경로의 이전 및 이후 개수.

각 개수 쌍은 상단 도구 모음과 같은 이전/이후 시간 순서를 따릅니다. 타임라인은 작은 기본 숫자 필드를 사용합니다.

1. 샘플링과 표시를 설정하려면 타임라인의 고스트 또는 경로를 길게 누르세요.

메뉴에는 프레임별, 키프레임별, 샘플링 간격이 있습니다. 추가 고스트 설정은 전체 옵션을 엽니다.

아래쪽 마름모는 편집 가능한 마커를 표시하거나 숨깁니다. 별도의 길게 누르기 메뉴는 상단 도구 모음의 마커 표시 버튼에 있습니다. 스냅샷 조작 항목은 고급 설정의 비교에 있습니다.

Ghost Tool이 활성화되면 그래프 에디터 헤더에도 전체 전환 버튼과 동작 경로 조작 영역이 표시됩니다.

## 마커를 반복해서 드래그

1. Ghost Tool을 활성화하세요.

2. 애니메이션 대상의 편집 가능한 마커를 활성화하세요.

3. 드래그를 클릭하세요.

4. 3D 뷰포트에서 보이는 마커를 클릭하세요.

5. 마커를 이동하세요.

6. 이동을 확정하세요.

빈 공간을 클릭하면 선택 대기가 계속됩니다. 이동을 확정한 뒤에도 드래그는 활성 상태를 유지하여 다음 편집을 할 수 있습니다. 모든 마커 드래그 버튼은 이 모드를 공유합니다.

종료하려면:

1. 드래그를 다시 클릭하거나 Escape를 누르세요.

이동 중에 Escape를 누르면 해당 이동을 취소합니다. Ghost Tool은 해당 이동의 원래 곡선과 마커 위치를 복원합니다. 앞서 확정한 이동은 별도의 편집으로 남습니다.

1. 앞서 확정한 이동을 되돌리려면 실행 취소를 사용하세요.

Ghost Tool을 비활성화하면 편집이 종료됩니다. 대상 소실, 파일 변경, 이력 변경, 애드온 종료도 관련 세션을 종료하거나 취소합니다.

경로 핸들 드래그도 반복 선택을 지원합니다.

*그림 7. 동작 경로가 애니메이션 큐브를 대상으로 유지합니다. 이 예제에서는 마커와 핸들을 활성화했습니다.*

1. 경로 설정에서 베지어 핸들을 활성화하세요.

2. 핸들 드래그 동작을 시작하세요.

3. 보이는 핸들을 선택하세요.

4. 핸들을 이동하세요.

5. 이동을 확정하세요.

6. 다른 핸들을 선택하여 계속하세요.

Shift+G도 계속 사용할 수 있습니다. 핸들을 드래그하는 동안 Alt는 핸들 정렬 동작을 켜거나 끕니다. Escape는 진행 중인 핸들 이동을 취소하고 모드를 종료합니다.

## 부드럽거나 날카로운 동작 편집 선택

1. 드래그를 길게 누르세요.

2. 놓을 때를 확인하세요.

3. 핸들로 모양 변경 또는 키프레임 삽입을 선택하세요.

핸들로 모양 변경은 이동한 샘플을 곡선이 지나도록 기존 베지어 핸들을 바꿉니다. 키프레임을 추가하지 않습니다.

곡선 모양에는 세 가지 선택 항목이 있습니다.

| 선택 항목 | 효과 |
| --- | --- |
| 자유 | 각도 제한 없이 핸들을 조정합니다. |
| 잠김 | 핸들 각도를 고정합니다. 핸들 길이는 바뀔 수 있습니다. |
| 부드러움 | 핸들의 영향을 구간 전체에 재분배합니다. |

설정 > 동작 편집에는 드래그의 길게 누르기 메뉴와 같은 놓을 때 및 곡선 모양 선택 항목이 있습니다.

![동작 편집의 핸들로 모양 변경 설정](images/ko/4.3.3-reshape-options.png)

*그림 8. 동작 편집은 핸들로 모양 변경과 자유 곡선 처리를 보여 줍니다. 영향 범위는 가까운 프레임에 미치는 영향을 제어합니다.*

키프레임 삽입은 마커의 프레임에 키를 기록합니다. 삽입 후에는 이웃 키 부드럽게로 인접한 키의 핸들을 부드럽게 할 수 있습니다. 주변 프레임 영향 범위와 감쇠는 주변 프레임에 미치는 영향을 제어합니다.

![동작 편집의 키프레임 편집과 고정 조작 항목](images/ko/4.3.3-edit-motion.png)

*그림 9. 동작 편집에는 키프레임 삽입, 이웃 키 부드럽게, 이징, 고정 조작 항목이 있습니다. 그려서 키 생성에는 주석 스트로크가 필요합니다.*

샘플 사이의 간격도 표시되는 선에 영향을 줍니다. 샘플 간격이 넓으면 애니메이션 곡선이 부드러워도 선이 거칠게 표시됩니다.

1. 결과를 확인하려면 프레임 간격을 더 작게 설정하세요.

표시 샘플을 늘려도 애니메이션 보간이나 핸들 모양은 바뀌지 않습니다.

## 마커 고정 및 경로 대상 관리

1. 고정을 클릭하세요.

2. 보이는 마커를 클릭하여 고정 상태를 전환하세요.

3. 다른 마커를 선택하려면 고정을 다시 클릭하세요.

고정은 한 번에 마커 하나를 선택합니다. 드래그처럼 활성 상태를 유지하지 않습니다. 여러 마커를 동시에 고정해 둘 수는 있습니다.

고정한 마커는 모양을 바꾸는 동안 위치를 유지합니다. 새로 고칠 때는 일치하는 고정 마커 기록을 유지합니다.

모든 마커의 고정을 해제하려면:

1. 고정을 길게 누르세요.

2. 모든 마커 고정 해제를 선택하세요.

추가한 경로 대상은 오브젝트나 본을 경로 목록에 유지합니다. 모든 애니메이션 샘플을 특정 시점의 상태로 고정하는 것은 아닙니다. 선택 항목 추적은 선택 미리보기를 바꿉니다. 선택 경로 추가로 추가한 대상은 경로 목록에 남습니다.

설정의 경로 목록에는 대상 조작 항목이 있습니다. 마커 표시는 추가한 경로에 편집 가능한 점을 표시합니다. 키프레임 점은 별도의 표시 보조 기능입니다.

그림 7은 경로 목록을 보여 줍니다. 그림 9는 동작 편집의 고정 및 전체 고정 해제를 보여 줍니다.

## 실시간 갱신 및 기본 애니메이션 편집

마커 실시간 갱신과 스킨 실시간 갱신은 기본적으로 꺼져 있습니다. 기존 장면은 저장된 값을 유지합니다. 이 옵션을 끄면 재생 위치를 훑는 동안 마지막으로 갱신한 미리보기가 유지됩니다.

1. 재생 위치를 훑을 때 마커 갱신 및 재생 위치를 훑을 때 메시 갱신을 열려면 전체 고스트 아이콘을 길게 누르세요.

이 조작 항목은 같은 마커 및 메시 갱신 설정을 사용합니다. 갱신 일시 정지는 자동 갱신을 일시 정지합니다.

설정 > 마커 옵션에는 같은 마커 갱신 조작 항목이 있습니다. 그림 4는 어니언 스킨 옵션의 스킨 실시간 갱신을 보여 줍니다.

![실시간 갱신 조작 항목이 있는 마커 옵션](images/ko/4.3.3-marker-options.png)

*그림 10. 마커 옵션에는 마커 실시간 갱신, 갱신 일시 정지, 갱신 지연이 있습니다.*

기본 이동, 회전, 스케일, 기즈모 동작 중에는 Ghost Tool이 마지막 미리보기를 유지합니다. 이 동작 중에는 애니메이션 프레임을 차례로 이동하지 않습니다. 확정하거나 취소한 뒤에는 편집이 안정될 때까지 기다립니다. 그런 다음 기존 고스트를 새로 고칩니다.

자동 키잉은 켜 둔 채 사용할 수 있습니다. 자동 키잉을 사용하지 않는 경우:

1. 포즈를 확정하세요.

2. 의도한 키를 삽입하세요.

고급 마커 조작 항목의 생성은 요청 시 미리보기를 다시 생성합니다.

4.3.3에서는 Anim Assist의 타임라인 포인터가 대기 중이어도 Ghost Tool이 마커와 어니언 스킨을 생성할 수 있습니다. 이 예외는 해당 대기 상태의 포인터 처리기에만 적용됩니다.

사용 중인 Anim Assist 슬라이더, 변환, 기즈모, 프레임 훑기, 알 수 없는 모달 작업은 여전히 샘플링을 일시 정지합니다.

1. 다시 생성하기 전에 진행 중인 동작을 마치세요.

이 수정은 미리보기 갱신의 기본값이나 원본 애니메이션의 동작을 바꾸지 않습니다.

고급 조작 항목에는 마커 대상, 어니언 스킨 소스, 범위, 세분화, 모양 설정이 계속 있습니다. 캐시된 마커와 스킨의 표시 조작 항목은 다시 생성하지 않고 기존 미리보기를 숨기거나 표시합니다.

모든 고스트 지우기는 마커와 어니언 스킨을 제거합니다.

1. 미리보기를 제거하지 않고 숨기려면 표시 조작 항목을 사용하세요.

숨긴 마커는 클릭이나 박스 선택으로 선택할 수 없습니다.

## 스냅샷 저장, 비교 및 복원

1. 설정을 여세요.

2. 비교를 여세요.

3. 의도한 범위를 선택하세요.

4. 표시된 캡처 대상을 확인하세요.

5. 선택 대상의 마커를 활성화하세요.

6. 스냅샷 저장을 클릭하세요.

![Motion 참조 스냅샷이 저장된 비교](images/ko/4.3.3-compare.png)

*그림 11. 비교에는 저장된 Motion 참조 스냅샷과 해당 스냅샷의 숨기기, 복원, 변형본 저장, 삭제 조작 항목이 있습니다.*

범위에는 활성 오브젝트 / 선택한 본, 선택한 경로, 선택한 마커 채널, 장면의 모든 마커가 있습니다.

스냅샷은 캡처 시점의 상태를 유지하는 샘플과 캡처한 키프레임 및 핸들을 보관합니다. 장면을 저장하고 다시 열어도 스냅샷은 남습니다. 애드온을 비활성화한 뒤 다시 활성화해도 유지됩니다.

숨기기 또는 표시는 애니메이션을 바꾸지 않고 스냅샷 오버레이를 전환합니다. 변형본 저장은 독립적인 대체 스냅샷을 만들고 원본을 기록합니다. 부모 스냅샷을 삭제해도 변형본은 남습니다.

장면에는 스냅샷을 10개까지 보관할 수 있습니다.

1. 한도에 도달하면 원하지 않는 기록을 삭제한 뒤 다른 스냅샷을 저장하세요.

캡처, 변형본 생성, 연결, 표시 전환, 삭제, 복원은 기본 실행 취소와 다시 실행을 지원합니다.

복원은 기록하기 전에 장면, 오브젝트, 액션, 슬롯, 본, 채널의 동일성을 검증합니다. 스냅샷 범위에 해당하는 캡처된 곡선과 마커 기록을 복원합니다. 실시간 갱신이 꺼져 있거나 일시 정지되어 있어도 표시를 새로 고칩니다.

복원은 관련 없는 오브젝트나 임의의 액션 모디파이어를 바꾸지 않습니다. 샘플만 있는 이전 참조는 Ghost Tool이 곡선 모양을 바꿀 수 있을 때 적절한 샘플 값을 복원합니다.

교체된 대상은 명시적인 연결이 필요합니다. 연결은 참조를 해당 대상과 연결합니다. 액션 슬롯을 공유하면 연결할 수 없습니다.

1. 연결하기 전에 싱글 유저를 만들기로 애니메이션을 단일 사용자 데이터로 만드세요.

활성 대상에 연결은 참조마다 원래 오브젝트 하나와 그 오브젝트의 이름이 지정된 본 채널을 지원합니다. 여러 오브젝트가 포함된 가져온 참조는 연결되지 않은 상태로 계속 볼 수 있습니다. Ghost Tool은 해당 오브젝트들을 하나의 대상에 연결할 수 없습니다.

연결은 본 이름 변경을 따릅니다. 저장하고 다시 연 뒤에는 채널 동일성으로 곡선을 식별합니다. 취소 후 롤백은 원래 곡선 값을 복원합니다. 동작 중에 Ghost Tool은 원래 곡선의 롤백 값을 교체된 곡선에 기록하지 않습니다.

<a id="transfer-snapshots-and-use-advanced-tools"></a>

## 스냅샷 전송 및 고급 도구 사용

1. 비교 데이터를 전송하려면 스냅샷을 JSON으로 내보내세요.

가져오기는 기록을 검증하고 병합합니다. ID가 기존 기록과 일치하면 새 ID를 할당합니다. 지원하지 않는 버전이나 한도를 초과하는 기록은 거부합니다. 가져오기가 거부되면 일부 기록만 추가되는 일은 없습니다.

가져온 참조와 이전 형식의 참조는 계속 볼 수 있습니다. JSON은 원래 오브젝트의 동일성을 증명할 수 없으므로 복원에는 명시적인 연결이 필요합니다. 가져오기에 실패해도 읽을 수 없는 기존 장면 기록은 유지됩니다.

*그림 12. 설정에는 Ghost Tool JSON 데이터의 내보내기와 가져오기가 있습니다.*

동작 편집에는 이징 프리셋과 사용자 지정 이징 조작 항목이 있습니다. 이징은 움직임의 속도가 변하는 방식을 제어합니다. 그려서 키 생성은 가장 긴 주석 스트로크를 위치 경로로 변환합니다. 교차하는 짧은 선은 키를 나타냅니다. 그려서 키 생성 대화 상자는 선택 대상을 유지합니다.

설정, 사이드바, 선반에는 물리감, 모양, 비교 등의 고급 도구가 있습니다.

## 문제 해결 및 버전 검증 기록

| 문제 | 확인 또는 조치 |
| --- | --- |
| 미리보기가 나타나지 않음 | Ghost Tool을 활성화하세요. 대상 애니메이션, 표시 여부, 0보다 큰 개수를 확인하세요. |
| 편집 가능한 점이 없음 | 대상을 경로에 추가하세요. 마커 표시를 활성화하세요. |
| 샘플이 너무 드문드문 표시됨 | 프레임 간격을 줄이거나 키프레임 간격을 바꾸세요. |
| 타임라인에 고스트 아이콘 하나만 표시됨 | 해당 아이콘을 활성화하여 도구 모음을 펼치세요. |
| 도구 모음이 숨겨짐 | 환경 설정에서 상단 도구 모음을 선택하세요. 뷰 > 고스트 도구 모음 표시를 선택하세요. |
| 조작 항목이 분할된 뷰포트 밖으로 나감 | 기본 행을 마우스 가운데 버튼으로 가로로 드래그하세요. |
| 편집 중에 샘플링이 대기함 | 진행 중인 편집 동작을 확정하거나 취소하세요. |
| Anim Assist가 대기 중이어도 생성이 막힘 | Ghost Tool 4.3.3을 설치하세요. Bforartists를 다시 시작하세요. |

그림 1은 Ghost Tool 환경 설정을 보여 줍니다. 그림 5와 6은 타임라인 도구 모음을 펼친 상태와 접은 상태를 보여 줍니다.

마커 샘플링은 경로 샘플링을 따릅니다. 왼쪽 선반 너비 환경 설정도 계속 사용할 수 있습니다. 4.2.11에서는 너비와 배율의 전체 검증이 완료되지 않았습니다. 이 안내서는 선반 너비를 새로 수정했다고 주장하지 않습니다.

이전의 도구 모음 직접 구현에서는 특정 항목을 대상으로 한 백그라운드 검사 188개를 수행했습니다. 그 결과는 해당 구현에 적용됩니다. 이 매뉴얼을 위해 새로 실행한 테스트의 결과가 아닙니다.

[4.3.3 릴리스 노트](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/ghost_tool/releases/4.3.3/RELEASE-NOTES.md)는 공식 Bforartists 5.2.3에서 수행한 특정 항목을 대상으로 한 회귀 및 GUI 검사를 기록합니다. GUI 검사는 Anim Assist 12.11.0과 격리된 사용자 리소스를 사용했습니다. 마커 9개와 메시 미리보기 3개를 검증했습니다. 원본 키와 재생 헤드는 바뀌지 않았습니다.
