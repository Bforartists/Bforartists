# CATS パイプライン {#the-cats-pipeline}

[← 目次](index.md)

**CATS のツールを初めて使う前に、この章を読んでください。**

CATS のツールは、準備作業の推奨手順を提供します。この順番で各フェーズを確認し、アバターに不要なフェーズは省略してください。メッシュやリグのデータを変更する前に、ファイルをチェックポイントとして保存します。各操作の結果を確認してください。前のフェーズが未完了でも、ツールは使用できます。

---

## 6つのフェーズとその順番 {#the-six-phases-in-order}

CATS タブの Pipeline Status には各フェーズが並び、完了したフェーズにチェックが付きます。

1. **Fix Model** — 重複の除去や法線の修正など、クリーンアップのオプションを確認します。操作後はメッシュを確認します。

2. **Material Atlas** — アバターのマテリアルを1枚のテクスチャシートにまとめます（パフォーマンス改善用の任意操作）。

    1. 結果を確認するまで、**Preserve Backup Duplicate** を有効にしておきます。

    2. **Analyze Materials** を選択します。

    3. 対象のソースを選択します。

    4. **Bake Checked Sources** を選択します。

    5. 結果を確認します。

    6. 次のベイクの前に、Accept または Revert を実行します。

    [Material Atlas Combiner](09-cats.md#material-atlas-combiner)を参照してください。

3. **Visemes** — 3つの基本の形（A、O、CH）から、VRChat のリップシンク用の口形を15個生成します。

4. **Eye Tracking** — アバターの目のボーンを使って、VRChat の目の動きを設定します。

5. **Pose to Shape Key** — メッシュの現在のシェイプキーの混合状態を、新しいキーとして記録します。このボタンは、アーマチュアのボーンによる変形をベイクしません。その作業には、[標準機能でボーンのポーズを保存する手順](09-cats.md#save-a-bone-deformed-pose)を参照してください。

6. **Apply All Transforms** — メッシュとアーマチュアに、位置、回転、スケールを適用します。書き出す前に、結果を比較してください。

---

## Pipeline Status と Operation Ledger {#pipeline-status-and-the-operation-ledger}

Pipeline Status は、フェーズごとに1行を表示します。フェーズが完了すると、その行にチェックマークが付きます。この状態はシーン内に保存され、ファイルに残ります。

Operation Ledger は、CATS の各操作を、時刻と結果とともに一覧表示します。新しい操作は最後に並びます。Changed はモデルが変更されたこと、Clean は変更が不要だったこと、Failed は操作が失敗したことを示します。**Copy** は、サポートへの問い合わせに使えるよう、操作履歴をクリップボードにコピーします。**Clear** は、履歴を空にします。

この順序は推奨です。前のフェーズが未完了でも、「Run Fix Model first for best results」のような警告を表示して、ツールは動作します。続ける前に、その警告を確認してください。

## この順番である理由 {#why-this-order}

この順序なら、一度に1種類の変更を確認しやすくなります。

- **最初にクリーンアップを確認します。** Fix Model は、オプションによって、形状の変更やデータの削除を行うことがあります。データをさらに生成する前に、メッシュと既存のシェイプキーを確認します。

- **口形を確認してから、目を確認します。** 生成または対応付けしたビジームをテストします。目の Auto-Detect は、ボーン名を検索します。Left Eye と Right Eye の割り当ては、ボーンの向きやコンストレイントとは別に確認してください。

- **次に表情の記録を確認します。** Pose to Shape Key が記録するのは、シェイプキーの混合状態であり、ボーンによる変形ではありません。

    1. 元のキーの値を0に戻します。

    2. 新しいキーを1にしてテストします。

    ボーンで変形したポーズを保存するには、上記のリンク先にある標準機能の手順を使います。

- **書き出す前にトランスフォームを確認します。** トランスフォームの適用は、オブジェクトのデータを変更し、トランスフォームのチャンネルをリセットします。前のツールも、引き続き使用できます。結果と書き出し設定を比較してください。以前の状態に戻すには、元に戻す操作か、保存済みのチェックポイントを使います。

## フェーズを省略する前に {#before-skipping-a-phase}

**Fix Model を省略する場合：**
読み込んだ形状、法線、ウェイト、モディファイアー、既存のシェイプキーを確認します。アバターに必要なクリーンアップ操作を選択してください。口形と目の動きの問題は、別々に確認します。パイプラインのフェーズが未チェックであるという事実だけでは、その原因は分かりません。

**Visemes を省略する場合：**
ビジームを生成または対応付けしていない場合、アバターにはリップシンクがありません。ビジームのシェイプキーがすでにあるなら、VRChat Viseme Mapping（ガイド8）で対応付けます。不要な置き換えを生成しないでください。この場合、Pipeline Status の Visemes は未チェックのままですが、想定どおりです。

**Eye Tracking を省略する場合：**
VRChat でアバターの目が動かず、まっすぐ前を見ます。目のボーンがない場合は、それで構いません。

**Pose to Shape を省略する場合：**
任意の操作です。現在のシェイプキーの混合状態を保存する必要がなければ、省略します。別のキーを作成しなくても、既存の表情は確認して使用できます。
