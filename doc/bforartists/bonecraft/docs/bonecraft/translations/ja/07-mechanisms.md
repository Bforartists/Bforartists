# メカニズム {#mechanisms}

[← 目次](index.md)

## Mechanismsでできること {#what-mechanisms-does}

Mechanismsは、ハードサーフェスのパーツから機械式リグを作成します。ヒンジ、スライド、伸縮、ピストン、ギア、追従、および1本のスライダーで制御する一連の変形に対応します。生成されるのは通常のBlenderボーンとコンストレイントなので、すべてを確認、変更できます。リグはBlender内でスクリプトなしで動作します。ゲームエンジンに渡すのは`DEF-`ボーンです。メカニズムの動きをベイクしてエンジンへ出力する機能は今後の対応です（「このバージョンの制限」を参照）。

BoneCraftがツールを提供します。武器のパーツは自分で用意します。

記述された手順と英語原本の画像説明を含む完全な作例は、[チュートリアル：MechanismsでCrescent Roseを作る](12-crescent-rose.md)を参照してください。

パネルと本章で使う用語：

| 用語 | 意味 |
|---|---|
| *Part* | 一体の固い塊として動く部品。オブジェクト、または1つのメッシュ内の分離した部分です。別のパーツに乗せて動かせます。 |
| *Joint* | パーツの動き方。Hinge（回転）、Slide（移動）、Telescope（入れ子の節の伸縮）があります。 |
| *Link* | パーツを連動させる仕組み。Piston、Gear Link、Followがあります。 |
| *Handle* | ビューポートでドラッグするボーン。各ジョイントに1つあり、パネルでもスライダーとして値を操作できます。 |
| *Sequence* | 複数のステップから構成され、1本のスライダーで再生する変形です。 |
| *Form* | 「Stowed」や「Rifle」などの名前で保存した、ハンドルとSequenceの値の組み合わせです。 |

## 場所 {#where-it-is}

- 3Dビューポートの **BoneCraftタブ → Mechanisms** 。環境設定で右サイドバー（ **N** ）へ移していなければ、BoneCraftタブは左のツールシェルフ（ **T** ）にあります。SkinとReviewの間です。リグを作り始めるためのメッシュ、またはメカニズムを持つアーマチュアがアクティブなときに表示されます。それ以外では、選択する対象を説明します。
-  **Propertiesエディター → Sceneタブ → Mechanisms** 。Rig Builderの直後です。Preferences → Tabs → Scene Properties → Showがオンの間は表示されます。有効な対象を選んでいない場合は「Select a mesh to start, or an armature with mechanisms.」（開始するメッシュ、またはメカニズムを持つアーマチュアを選択）と表示します。ビューポートのBoneCraftタブをオフにしても消えません。Scene Propertiesのスイッチで隠れるのはScene側だけです。 **Preferences → Add-ons → BoneCraft → Tools** の`mechanisms`スイッチは、すべての場所からこのツールを取り除きます。Sceneタブのセクションは初めは折りたたまれているため、 **Mechanisms** をクリックして展開してください。
-  **Objectメニュー → Mechanisms** 。パーツ、ジョイント、リンクの追加や動作テストへのショートカットがあります。
-  **ビューポートのツールバー → Build Mechanism** 。Object ModeまたはPose Modeでパーツをクリックし、案内に沿ってジョイントやリンクを作成します。

Build Mechanismの準備：

1. パーツを追加します。
2. メカニズムのリグ、またはそのパーツを選択します。
3. ツールヘッダーで種類を選択します。

Mechanismsには **1. Parts** 、 **2. Joints & Links** 、 **3. Sequences** 、 **4. Controls** の4つのサブセクションがあります。リグにパーツを追加すると表示されます。それまでは **Add Parts from Selection** だけが表示されます。

各ボタンの操作は1回の取り消しで戻せます。生成に失敗した場合、BoneCraftはその生成で変更したものをすべて元に戻し、パネルに理由を表示します。

## パーツ {#parts}

1. Object Modeでパーツのオブジェクト（または分離した部分からなる1つのメッシュ）を選択します。
2.  **Add Parts from Selection** をクリックします。
    - 複数のオブジェクト：各オブジェクトが1つのパーツになります。各オブジェクトはパーツのボーンの子になり、現在の位置を保ちます。
    - 分離した部分を持つ1つのメッシュ：各部分が1つのパーツになります。各部分にボーン用の頂点グループ、メッシュにArmatureモディファイアーが追加されます。
    - 初回はBoneCraftがリグ（アーマチュア）を作成します。
3. リストでパーツを選択して編集します。

パーツごとの設定：

-  **Rides on:**  一緒に動く相手のパーツを選択します。子パーツは親パーツに追従します。「the rig」はリグのルートに乗せることを意味します。
-  **Size** はボーンの長さ、つまりハンドルの大きさを設定します。
-  **Edit Pivot** はパーツ上にマーカーを置きます。 **Apply Pivot** でパーツのボーンをマーカーへ移動します。オブジェクト自体は移動しません。
-  **Apply Transforms** は、オブジェクトパーツの回転またはスケールが未適用の場合に表示されます。未適用のトランスフォームは軸を傾けるため、表示されたら **Apply Transforms** をクリックしてください。
-  **X** ボタンはパーツを削除します。ジョイント、リンク、別のパーツが使用中の場合は拒否し、その使用者を示します。
-  **Merge for VRChat** には2つ以上のオブジェクトパーツが必要です。このメカニズムリグだけにリギングされたパーツに使い、最後に実行してください。オブジェクトパーツを1つのメッシュに結合し、元のオブジェクトごとに頂点グループを作成し、結合メッシュにArmatureモディファイアーを追加します。結合したパーツは、この1つのメッシュ内の分離したパーツになります。結合時には、このアーマチュアのボーンと同名の頂点グループを削除しますが、パーツ自身の`DEF-`ボーンのグループは残します。

パーツのピボットを変更するには：

1.  **Edit Pivot** を選択します。
2. パーツの回転またはスライドの起点にしたい位置へマーカーをドラッグします。
3.  **Apply Pivot** をクリックします。

パーツのオブジェクトは名前を変更できます。パーツはオブジェクトのタグから対象を再発見します。オブジェクトの複製（Shift+D）が元のパーツを引き継ぐことはありません。オブジェクトを削除した場合は「Part '&lt;name&gt;' is missing」（パーツが見つからない）と **Reassign** 、 **Delete** を表示します。他のメカニズムは動作を続けます。

-  **Reassign** は現在選択しているメッシュを使います。メッシュ以外や、別のオブジェクトパーツが使用中のオブジェクトは拒否します。1つのメッシュ内の分離したパーツは、同じメッシュを共有できます。
-  **Delete** はパーツを削除します（拒否される場合については後述の編集の節を参照）。

## ジョイントとリンクの作例 {#joints-and-links-one-example-each}

 **Add Joint** は案内付きのジョイント生成、 **Add Link** は案内付きのリンク生成を開始します。ビューポートタブとPropertiesエディターのSceneタブのどちらからも使えます。Sceneタブから開始すると、画面内で最も大きい3Dビューポートで案内します。

ツールバーを使う方法：

1. ビューポートのツールバーでBuild Mechanismを有効にします。
2. ツールヘッダーでジョイントまたはリンクの種類を選択します。
3. 最初のパーツをクリックします。

このクリックは同じ案内を開始し、最初の選択も済ませます。その後はビューポートの指示に従ってパーツや軸を選びます。Add JointとAdd Linkのメニューも引き続き使えます。

 **Align to Selection** は斜めのヒンジに対応します。 **A** を押す時点で、パーツのメッシュをEdit Modeにし、辺または面を1つ選択しておく必要があります。案内中は **Tab** を無視します。 **Align to Selection** の準備：

1. パーツのメッシュをEdit Modeにします。
2. 辺または面を1つ選択します。
3. Edit Modeのまま **Add Joint → Hinge** を開始します。
4. パーツをクリックします。
5.  **A** を押します。

使える選択がなければ案内にメッセージが表示されます。その後、別のキーを押せます。

すべての案内付き生成に共通する操作：

- ビューポートでパーツをクリックします。クリックしたパーツに輪郭と番号が付きます。
- 軸が必要なステップでは **X** 、 **Y** 、 **Z** を押します。
- 上述の **Align to Selection** の準備ができていれば、 **A** で選択に合わせます。
- 最後のステップではメカニズムの動きをループでプレビューします。 **Enter** で確定し、 **Esc** で削除します。
- ヘッダーとステータスバーは各ステップを完全な文で案内します。Show Helpersがオフの場合は短いラベルになります。

Joints & Linksリストの各行には、 **Test** （再生の三角形）、 **Edit** （鉛筆、設定を表示）、 **Detach** （切れた鎖）、 **Delete** （X）の4つのアイコンボタンがあります。

生成後、リストで選択した項目には、その種類に必要な設定だけが表示されます。

### Hinge {#hinge}

Blade Hinge、0°…90°：

1. BladeパーツにAdd Parts from Selectionを使います。
2.  **Add Joint → Hinge** を選択します。
3. Bladeをクリックします。
4.  **X** を押します。
5.  **Enter** を押します。

半円形のハンドル`CTRL-Blade`と、リスト内の*Blade Hinge*が作成されます。

6.  **Min** を0にします。
7.  **Max** を90にします（Hingeの単位は°）。
8. 半円形のハンドルをドラッグしてヒンジをテストします。

ハンドルは90°で止まります。 **Set Min** と **Set Max** は、ハンドルの現在のポーズを制限値へコピーします。

1回転未満の制限は−180°…180°内に収める必要があります。170°…190°などの指定はメッセージとともに拒否します。1回転以上の範囲（例：−180°…180°）では、制限なしで自由に回転します。

### Slide {#slide}

Barrel Slide、0…0.3：

1.  **Add Joint → Slide** を選択します。
2. Barrelパーツをクリックします。
3.  **Y** を押します。
4.  **Enter** を押します。

矢印形のハンドルが作成されます。

5.  **Min** を0にします。
6.  **Max** を0.3にします（シーン単位）。
7. 矢印をドラッグしてスライドをテストします。

銃身はスライドし、0.3で止まります。

### Telescope {#telescope}

3つの節を持つマスト：

1. 基部と3つの節をパーツにします。
2.  **Add Joint → Telescope** を選択します。
3. 基部をクリックします。
4. 基部から外側へ順に各節をクリックします。
5.  **Enter** を押します。
6. 軸のキーを押します。
7.  **Enter** で生成を確定します。

基部に矢印形のハンドルが1つ作成されます。 **Length** は移動の合計距離です。 **Shares (empty = even)** で各節へ移動距離を配分します。

独自の配分をテストするには：

1.  **Length** を1にします。
2.  **Shares (empty = even)** へ`0.5, 0.25, 0.25`と入力します。
3. 矢印形のハンドルをドラッグします。

3つの節が各配分の距離だけ伸びます。先端が全長分移動するよう、配分の合計はLengthに一致させます。`0.5, abc`などの無効な文字列にはメッセージを表示します。各節に数値を1つずつ指定し、その合計をLengthに合わせてください。 **Set Max** はハンドルのポーズからLengthを設定します。

### Piston {#piston}

リフト：フレーム側にシリンダー、アーム側にロッドを配置します。

1. アームにHingeを設定します。
2. アームのRides onをフレームに設定します。
3.  **Add Link → Piston** を選択します。
4. フレーム側のシリンダーパーツをクリックします。
5. アーム側のロッドパーツをクリックします。

ハンドルのないPistonが作成されます。各パーツは相手の取り付け位置を向きます。任意の **Stretch** は、ばねやケーブル用にロッドを伸縮させます。

6. アームのハンドルを動かしてPistonをテストします。

ピストンが追従します。まだPistonを動かすものがなければ生成は成功しますが、プレビューはありません。 **Test** がその状態を報告します。

### Gear Link {#gear-link}

ギア比20:40：

両方のパーツにジョイントが必要です。駆動側はHingeにします。GearとBeltの従動側にはHinge、Rackの従動側にはSlideが必要です。

1.  **Add Link → Gear Link** を選択します。
2. 駆動側のパーツをクリックします。
3. 従動側のパーツをクリックします。

歯数を使う方法：

1. リンク設定で **Source Teeth** を20にします。
2.  **Target Teeth** を40にします。

代わりに **Ratio** を直接入力することもできます。 **Kind** はGear、Belt、Rackから選びます。 **Reverse** は方向を反転します。駆動側を回してリンクをテストします。

 **Kind** がGearの場合、従動側は−0.5×の角度だけ回ります（Beltでは+0.5×）。Gearは逆方向、Beltは同じ方向に回転します。Rackは回転を直線移動に変換します。1ラジアン当たりの移動距離は **Ratio**  ×  **Pinion Radius** です。

生成方法は駆動側Hingeの範囲に依存します。

- 1回転未満：Transformコンストレイントを使います。Sequenceを含め、駆動側を動かすすべてに追従します。
- 1回転以上：Pythonが不要なドライバーを使います。従動側は駆動側に合わせて無限に回転します。追従するのはハンドルとギアだけです。SequenceまたはFollowが失われる場合、Rig Validatorが警告します。

英語原本の画像説明（画像は省略）：20:40の作例を入力する前のGear Link操作。画像の比率は1.00、両方の歯数は0です。

*BoneCraft 9.2.19候補版のネイティブテストビルドのポップオーバー。Bforartists 5.2.3、Blender 5.4 Alpha。20:40の作例を入力する前のGear Link操作。画像の比率は1.00、両方の歯数は0です。*

### Follow {#follow}

Bladeの0–90°の動きで、Coverを0–40°持ち上げます。

両方にHingeまたはSlideが必要です。駆動側Hingeの制限は1回転未満にします。自由回転する駆動側は拒否します。

1.  **Add Link → Follow** を選択します。
2. 先行するパーツ（Blade）をクリックします。
3. 追従するパーツ（Cover）をクリックします。

初期の各マッピング範囲は、それぞれのジョイントの全範囲です。

4.  **Source Range** を0…90にします。
5.  **Target Range** を0…40にします。
6. Bladeのハンドルを動かしてFollowをテストします。

Coverが追従します。範囲の端を超えると、従動側はその値を保ちます。Graph Editorでマッピングを変形するには **Curve** を有効にします。BoneCraftは自分で編集したカーブを上書きしません（後述の編集の節を参照）。

### Sequence {#sequence}

武器を折りたたむステップを記録します。

1.  **3. Sequences** で **Add Sequence** をクリックします。

`CTRL-SEQ-<name>`という名前のスライダーハンドルを作成します。

2.  **Move Slider to End** をクリックします。

スライダーは終端（1）へ移動します。ボタンはRecord Stepと次のステップ番号に変わります。

3. 最初のステップのポーズになるようジョイントのハンドルを動かします。
4. Record Step 1をクリックします。

動かした各ハンドルが、目標値を持つステップになります。ハンドルはゼロへ戻ります。

追加の記録ごとに：

1.  **Move Slider to End** をクリックします。
2. 次のステップのポーズになるようジョイントのハンドルを動かします。
3. 現在の番号のRecord Stepボタンをクリックします。

初期状態では、新しいステップはスライダーの次の4分の1を使います。記録した各ステップで：

1.  **Target** を設定します。
2. Linear、Ease In、Ease Out、Ease In Out、Snapからイージングを選びます。
3.  **Start** を設定します。
4.  **End** を設定します。

割り当てた区間の外では、ステップは終端の値を保ちます。複数のSequenceを重ねられます。 **Test** をクリックすると、スライダーが0 → 1 → 0と動きます。

選択したSequenceには、記録ボタンと **Test** の隣に **Detach** （切れた鎖）と **Delete** （X）があります。保留中のSequence（ステップのカーブを自分で変形した場合など）はメッセージと **Restore** を表示します。Restoreは記録からステップを再生成します。SequenceにはKeep mineはありません。

## テスト {#test}

 **Test** （リストと3. Sequencesの再生ボタン）は、1つのメカニズムを全範囲にわたって往復させます。キーは作成せず、終了時にポーズを戻します。途中で止めるには **Esc** を押します。この場合もポーズを戻します。Gear LinkとFollowでは駆動側、Pistonではそれを動かすジョイントを往復させます。BoneCraftは衝突を検出しません。パーツの干渉を目で確認してください。

## フォーム {#forms}

 **4. Controls** 内：

- 各ジョイントとSequenceにスライダーが1つあります。ハンドル自体のチャンネルなので、ハンドルのドラッグとスライダー操作は同じです。
-  **Save Form** は、すべてのハンドルとSequenceの値を名前付きで記録します。リストで名前を変更できます。
-  **Go to Form** は、すべてのコントロールを保存した値へ設定します。
-  **Go and Key** は同じ設定に加え、現在のフレームにキーを挿入します。
- リスト横の **X** はフォームを削除します。

 **以前に保存したファイル：** BoneCraft 9.2.18は、それ以前のバージョンで記録したフォームを読み込み、適用できます。フォームを開く操作や適用する操作では再保存しません。 **Save Form** は現在の形式で現在のコントロール値を記録します。既存のフォーム名で保存すると、そのフォームの記録値を置き換えます。

操作場所は **Mechanisms → 4. Controls** のままです。互換性修正によってリグのハンドル、Sequenceのスライダー、パネルの場所が変わることはありません。

## BoneCraftが生成するもの {#what-bonecraft-builds}

パーツごとのボーン：

| ボーン | 役割 | 表示 |
|---|---|---|
| `CTRL-<part>` | ハンドル。値がパネルのスライダーに対応します。Hinge、Slide、Telescopeだけが作成します。 | 表示 |
| `MCH-<part>` | ハンドルと各リンクの寄与を加算し、最後に制限を適用します。 | 非表示 |
| `DEF-<part>` | `MCH-<part>`をコピーします。メッシュをバインドする対象で、エンジンへ渡すボーンです。 | 非表示 |

ボーンは`Mechanism Controls`、`Mechanism MCH`、`Mechanism DEF`コレクションに入ります。ジョイントのないパーツには`MCH-`と`DEF-`だけがあります。Telescopeのハンドルは`CTRL-<telescope name>`、Sequenceは`CTRL-SEQ-<name>`です。Pistonは2つのパーツそれぞれに`MCH-<part>-aim`と`MCH-<part>-target`を追加します。

`MCH-<part>`のコンストレイントの順序は常に同じです。ハンドルからのCopy Transforms、各リンクの寄与、最後にジョイントのLimit RotationまたはLimit Locationです。`DEF-<part>`には`MCH-<part>`からのCopy Transformsが1つあります。

BoneCraftが生成するものには、記録に対応するタグが付きます。コンストレイント名は`BC·<id>·<role>`で始まり、ボーンには`bc_mech_id`と`bc_mech_role`プロパティがあります。名前ではなくタグでボーンを探すため、どのボーンも名前を変更できます。再生成時も同じものを見つけ、重複を作りません。

Show Helpersがオンの場合、各ジョイントとリンクに **How this works** の説明があります。コンストレイントを名前で列挙して役割を説明し、 **Select** （矢印アイコン）で対象ボーンを選んで確認できます。

自分で追加したコンストレイント、ドライバー、ボーンは変更しません。MCHボーンに自分で追加したコンストレイントは、再生成後もBoneCraftのコンストレイントの下に残ります。

## 編集と手動変更 {#editing-and-hand-edits}

-  **値の編集** （制限、比率、範囲、タイミング、イージング、ハンドルの外観）は、既存のコンストレイントをその場で更新します。再生成は行いません。
-  **構造の編集** （Gear Linkの **Kind** 、Followの **Curve** 、Pistonの **Stretch** ）は、そのメカニズムのコンストレイントを置き換え、そのメカニズムだけを再生成します。
-  **手動で変更した場合。**  LimitなどのBoneCraftコンストレイントを編集すると、メカニズムのメッセージ末尾に「(changed by hand)」と表示します。無断で上書きはしません。次のどちらかを選びます。
    -  **Keep mine** は編集値を記録へコピーします。読み戻せないものは拒否し、RestoreまたはDetachを使うよう案内します。
    -  **Restore** は手動変更を破棄し、記録から再生成します。
- 保留中のメカニズムがあると、それが解決するまで、そのボーンを使うメカニズムもすべて保留します。
- 変形したカーブにも同じ保護が適用されます。 **Curve** が有効なら、Graph EditorでFollowのカーブを変形できます。後からTarget Rangeなどを変えるとカーブの置き換えが必要になるため、Followのメッセージ末尾に「(changed by hand)」と表示します。 **Keep mine** は自分のカーブを保ち、 **Restore** は再生成します。
- 保留中のSequenceは **3. Sequences** でメッセージと **Restore** を表示し、横に **Detach** と **Delete** があります。SequenceにはKeep mineはありません。
-  **Detach** （切れた鎖）は記録とタグを削除しますが、ボーンとコンストレイントは自作のリグとして残します。DetachとDeleteは、他の記録が使用しているものを拒否し、その使用者を示します。
-  **Delete** （X）は記録と、そのためにBoneCraftが生成したものすべてを削除します。
- リンクのループは生成前に拒否し、例えば「Blade Hinge → Cover Follow → Blade Hinge would loop.」のように経路を示します。

Rig ValidatorとTask Boardは次を報告します。

- リンクのループ。
- 見つからないパーツ。
- メカニズムの外部から動かされたDEFボーン。
- Pythonを必要とするドライバー。
- SequenceまたはFollowを失うGear Link。

検証の命名チェックはハイフン（`CTRL-`、`MCH-`、`DEF-`）を許可します。ドライバーのチェックはPythonが必要な式だけに警告します。正常なMechanismsリグには検証エラーはありません。「このバージョンの制限」で述べる`root`ボーンの警告だけが表示されます。

## Show Helpers {#show-helpers}

 **Show Helpers** はBoneCraft全体に共通する環境設定です。 **Preferences → Add-ons → BoneCraft → Helpers** にあります。オフにすると、用途や使用時期の説明、 **How this works** 、案内中の完全な文（短いラベルに変わる）など、すべての場所で学習用の説明を隠します。手順そのもの、リスト、Test、警告、Blenderのマウスオーバーツールチップは常に残ります。

VRChatの **Compact Mode** ボタンはそのショートカットです。Compact ModeがオンならShow Helpersがオフです。

## このバージョンの制限 {#limits-of-this-version}

- Click Turn、Track、Linkageメカニズムは今後の対応です。
- メカニズムの動きをベイクしてエンジンへ出力する機能は、デスクトップでの手動確認後の対応です。それまでは`DEF-`ボーンを出力します。
- BoneCraftは衝突を検出しません。衝突の確認は：
    1. Testを使います。
    2. パーツの動きを目で確認します。
- 自由回転するGear Linkが追従するのは、ハンドルとギアだけです。
- リグの`root`ボーンはどのボーンコレクションにも入っていません。そのためRig Validatorのコレクションチェックが警告し、Task Boardには「Rig validation warnings (1)」と表示します。
