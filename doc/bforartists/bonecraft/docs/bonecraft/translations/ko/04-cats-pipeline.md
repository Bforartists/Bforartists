# CATS 파이프라인 {#the-cats-pipeline}

[← 목차](index.md)

**CATS 도구를 처음 사용하기 전에 읽으세요.**

CATS 도구는 권장 준비 작업 흐름을 제공합니다. 다음 순서로 단계를 검토하세요. 아바타에 필요하지 않은 단계는 건너뛰세요. 메시나 리그 데이터를 변경하기 전에 파일 체크포인트를 저장하고 각 결과를 확인하세요. 앞 단계가 완료되지 않아도 도구는 계속 사용할 수 있습니다.

---

## 여섯 단계의 순서 {#the-six-phases-in-order}

CATS 탭의 Pipeline Status는 단계를 나열하고 완료된 단계에 확인 표시를 합니다.

1. **Fix Model** — 중복 제거와 노멀 수정 같은 정리 옵션을 검토하세요. 작업 후 메시를 확인하세요.

2. **Material Atlas** — 아바타 머티리얼을 하나의 텍스처 시트로 합칩니다(성능을 위한 선택 사항).

    1. 결과를 검토할 때까지 **Preserve Backup Duplicate**를 켜 두세요.

    2. **Analyze Materials**를 선택하세요.

    3. 소스를 선택하세요.

    4. **Bake Checked Sources**를 선택하세요.

    5. 결과를 검토하세요.

    6. 다시 베이크하기 전에 Accept 또는 Revert를 선택하세요.

    [머티리얼 아틀라스 결합기](09-cats.md#material-atlas-combiner)를 참고하세요.

3. **Visemes** — 기본 입 모양 세 개(A, O, CH)에서 VRChat 립싱크 입 모양 15개를 생성합니다.

4. **Eye Tracking** — 아바타의 눈 본으로 VRChat의 눈 움직임을 설정합니다.

5. **Pose to Shape Key** — 메시의 현재 셰이프 키 혼합을 새 키로 저장합니다. 이 버튼은 아마츄어 본 변형을 베이크하지 않습니다. 본 변형을 저장하려면 [기본 본 포즈 작업 흐름](09-cats.md#save-a-bone-deformed-pose)을 참고하세요.

6. **Apply All Transforms** — 메시와 아마츄어의 위치, 회전 및 스케일을 적용합니다. 내보내기 전에 결과를 비교하세요.

---

## Pipeline Status와 Operation Ledger {#pipeline-status-and-the-operation-ledger}

Pipeline Status는 단계마다 한 줄을 표시합니다. 단계가 끝나면 해당 줄에 확인 표시가 나타납니다. 이 상태는 파일의 장면에 저장됩니다.

Operation Ledger는 각 CATS 작업을 시간과 결과와 함께 나열하며 최신 항목은 마지막에 표시됩니다. Changed는 작업이 모델을 변경했다는 뜻입니다. Clean은 변경할 필요가 없었다는 뜻입니다. Failed는 작업이 실패했다는 뜻입니다. **Copy**는 지원 요청에 사용할 수 있도록 기록을 클립보드에 복사합니다. **Clear**는 기록을 비웁니다.

이 순서는 권장 사항입니다. 앞 단계가 완료되지 않아도 “Run Fix Model first for best results” 같은 경고와 함께 도구가 실행됩니다. 계속하기 전에 경고를 검토하세요.

영문 원본 이미지 설명(이미지 생략): Pipeline Status가 여섯 단계를 권장 순서로 나열합니다.

*기본 패널 팝오버, BoneCraft 9.2.18. Pipeline Status가 여섯 단계를 권장 순서로 나열합니다.*

영문 원본 이미지 설명(이미지 생략): 항목이 없는 Operation Ledger. Copy와 Clear는 기록된 항목에 적용됩니다.

*기본 패널 팝오버, BoneCraft 9.2.18. 항목이 없는 Operation Ledger. Copy와 Clear는 기록된 항목에 적용됩니다.*

## 이 순서를 사용하는 이유 {#why-this-order}

이 순서를 따르면 한 번에 한 종류의 변경을 검토하기 쉽습니다.

- **먼저 정리를 검토하세요.** Fix Model은 옵션에 따라 지오메트리를 변경하거나 데이터를 제거할 수 있습니다. 추가 데이터를 생성하기 전에 메시와 기존 셰이프 키를 확인하세요.

- **입 모양을 검토한 뒤 눈을 검토하세요.** 생성하거나 매핑한 비짐을 테스트하세요. Eye Auto-Detect는 본 이름을 검색합니다. 본 방향과 컨스트레인트와는 별도로 Left Eye와 Right Eye 할당을 확인하세요.

- **다음은 표정 저장을 검토하세요.** Pose to Shape Key는 본 변형이 아니라 셰이프 키 혼합을 저장합니다.

    1. 원래 키 값을 0으로 되돌리세요.

    2. 새 키를 1로 설정하여 테스트하세요.

    본으로 변형한 포즈를 저장하려면 위에 링크된 기본 작업 흐름을 사용하세요.

- **내보내기 전에 변환을 검토하세요.** 변환을 적용하면 오브젝트 데이터가 변경되고 변환 채널이 초기화됩니다. 앞의 도구는 계속 사용할 수 있습니다. 결과와 내보내기 설정을 비교하세요. 이전 상태로 돌아가려면 실행 취소나 저장된 체크포인트를 사용하세요.

## 단계를 건너뛰기 전에 {#before-skipping-a-phase}

**Fix Model을 건너뛰는 경우:**
가져온 지오메트리, 노멀, 웨이트, 모디파이어 및 기존 셰이프 키를 확인하세요. 아바타에 필요한 정리 작업을 선택하세요. 입 모양과 눈 움직임 문제는 따로 확인하세요. 파이프라인 단계가 미완료라는 사실만으로 문제의 원인을 알 수는 없습니다.

**Visemes를 건너뛰는 경우:**
생성하거나 매핑한 비짐이 없으면 아바타에 립싱크가 없습니다. 비짐 셰이프 키가 이미 있다면 VRChat Viseme Mapping(가이드 8)에서 매핑하세요. 불필요하게 새로 생성하지 마세요. 이 경우 Pipeline Status의 Visemes는 미완료로 남으며 이는 정상입니다.

**Eye Tracking을 건너뛰는 경우:**
VRChat에서 아바타가 눈을 움직이지 않고 정면을 봅니다. 눈 본이 없다면 그대로 두어도 됩니다.

**Pose to Shape를 건너뛰는 경우:**
현재 셰이프 키 혼합을 저장할 필요가 없다면 생략해도 됩니다. 새 키를 만들지 않고도 기존 표정을 검토하고 사용할 수 있습니다.
