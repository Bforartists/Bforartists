# 메커니즘 {#mechanisms}

[← 목차](index.md)

## Mechanisms의 기능 {#what-mechanisms-does}

Mechanisms는 하드 서피스 부품으로 기계 리그를 만듭니다. 힌지, 슬라이드, 텔레스코프, 피스톤, 기어, 추종 및 슬라이더 하나로 제어하는 전체 변형을 지원합니다. 일반 Blender 본과 컨스트레인트를 만들므로 생성된 모든 요소를 확인하고 변경할 수 있습니다. 리그는 스크립트 없이 Blender에서 작동합니다. 엔진에는 `DEF-` 본을 전달합니다. 베이크한 메커니즘 모션의 엔진 내보내기는 나중에 제공됩니다(이 버전의 한계 참고).

BoneCraft는 도구를 제공하며 무기 부품은 사용자가 준비합니다.

서면 단계와 영문 원본 이미지 설명을 유지한 완전한 실습 예제는 [튜토리얼: Mechanisms로 Crescent Rose 만들기](12-crescent-rose.md)입니다.

패널과 이 페이지에서 사용하는 용어:

| 용어 | 뜻 |
|---|---|
| *Part(부품)* | 하나의 단단한 덩어리로 움직이는 오브젝트 또는 메시의 분리된 조각입니다. 다른 부품에 얹혀 움직일 수 있습니다. |
| *Joint(관절)* | 부품의 허용 움직임입니다. Hinge는 회전, Slide는 이동, Telescope는 중첩 구간 확장입니다. |
| *Link(링크)* | 부품을 대신 움직이는 Piston, Gear Link, Follow입니다. |
| *Handle(핸들)* | 뷰포트에서 드래그하는 본입니다. 관절마다 하나씩 있으며 값은 패널의 슬라이더로도 표시됩니다. |
| *Sequence(시퀀스)* | 여러 단계로 구성되며 슬라이더 하나로 재생하는 변형입니다. |
| *Form(폼)* | “Stowed”나 “Rifle”처럼 저장된 핸들과 시퀀스 값의 집합입니다. |

## 위치 {#where-it-is}

- 3D 뷰포트의 **BoneCraft 탭 → Mechanisms**. 환경설정에서 오른쪽 사이드바(**N**)로 옮기지 않았다면 왼쪽 툴 셸프(**T**)에 있습니다. Skin과 Review 사이에 있으며, 시작할 메시나 메커니즘이 있는 아마츄어가 활성화되면 표시됩니다. 그 외에는 선택할 대상을 안내합니다.
- **프로퍼티스 에디터 → Scene 탭 → Mechanisms**, Rig Builder 바로 뒤. Preferences → Tabs → Scene Properties → Show가 켜져 있을 때 표시됩니다. 사용할 수 있는 선택이 없으면 “Select a mesh to start, or an armature with mechanisms.”라는 한 줄을 표시합니다. BoneCraft 뷰포트 탭을 꺼도 제거되지 않습니다. Scene Properties 스위치는 Scene 사본만 숨깁니다. **Preferences → Add-ons → BoneCraft → Tools**의 `mechanisms` 스위치는 모든 위치에서 도구를 제거합니다. Scene 탭 섹션은 처음에 접혀 있으므로 **Mechanisms**를 클릭해 펼치세요.
- **Object 메뉴 → Mechanisms**에는 부품, 관절, 링크 추가 및 모션 테스트 단축 경로가 있습니다.
- **뷰포트 도구 모음 → Build Mechanism**은 오브젝트 또는 포즈 모드에서 부품을 클릭하여 관절이나 링크 생성 안내를 시작합니다.

Build Mechanism 준비:

1. 부품을 추가하세요.
2. 메커니즘 리그나 부품 하나를 선택하세요.
3. 도구 헤더에서 유형을 선택하세요.

Mechanisms에는 **1. Parts**, **2. Joints & Links**, **3. Sequences**, **4. Controls**의 네 하위 섹션이 있습니다. 리그에 부품이 생기면 나타나며 그 전에는 **Add Parts from Selection**만 보입니다.

버튼 하나는 실행 취소 한 단계입니다. 빌드가 실패하면 BoneCraft는 그 빌드의 변경을 모두 복원하고 패널에 이유를 표시합니다.

영문 원본 이미지 설명(이미지 생략): BoneCraft 탭의 Mechanisms.

*과거 워크숍 캡처. BoneCraft 탭의 Mechanisms.*

## 부품 {#parts}

1. 오브젝트 모드에서 부품 오브젝트들 또는 분리된 조각으로 된 메시 하나를 선택하세요.
2. **Add Parts from Selection**을 클릭하세요.
    - 여러 오브젝트: 오브젝트당 부품 하나입니다. 각 오브젝트는 해당 부품 본에 부모 연결되며 위치를 유지합니다.
    - 분리된 조각으로 된 메시 하나: 조각당 부품 하나입니다. 각 조각은 본용 버텍스 그룹을 받고 메시는 Armature 모디파이어를 받습니다.
    - 처음에는 BoneCraft가 리그(아마츄어)를 만듭니다.
3. 편집할 부품을 목록에서 선택하세요.

각 부품의 설정:

- **Rides on:** 함께 움직일 부품을 선택합니다. 자식 부품은 부모 부품을 따릅니다. “the rig”는 리그 루트에 얹힌다는 뜻입니다.
- **Size**는 본 길이를 정하며 핸들 크기도 결정합니다.
- **Edit Pivot**은 부품에 마커를 놓습니다. **Apply Pivot**은 부품 본을 마커로 이동하며 오브젝트는 제자리에 둡니다.
- **Apply Transforms**는 오브젝트 부품에 적용하지 않은 회전이나 스케일이 있을 때 나타납니다. 미적용 변환은 축을 기울입니다. 버튼이 나타나면 **Apply Transforms**를 클릭하세요.
- **X**는 부품을 제거합니다. 관절, 링크 또는 다른 부품이 사용 중이면 거부하고 사용자를 나열합니다.
- **Merge for VRChat**에는 오브젝트 부품이 두 개 이상 필요합니다. 메커니즘 리그 하나에만 리깅된 부품을 마지막에 병합하세요. 각 이전 오브젝트의 버텍스 그룹과 Armature 모디파이어가 있는 메시 하나로 합칩니다. 부품들은 그 메시의 분리된 조각이 됩니다. 부품 자신의 `DEF-` 본을 제외하고 이 아마츄어의 본 이름과 같은 버텍스 그룹을 제거합니다.

부품 피벗 변경:

1. **Edit Pivot**을 선택하세요.
2. 회전이나 슬라이드가 시작될 위치로 마커를 드래그하세요.
3. **Apply Pivot**을 클릭하세요.

오브젝트에 태그가 있으므로 부품 오브젝트의 이름을 바꿔도 다시 찾습니다. Shift+D로 복사한 오브젝트는 부품을 인계받지 않습니다. 오브젝트를 삭제하면 “Part '&lt;name&gt;' is missing”과 **Reassign**, **Delete**를 표시하며 다른 메커니즘은 계속 작동합니다.

- **Reassign**은 선택한 메시를 사용합니다. 메시가 아니거나 다른 오브젝트 부품이 사용 중인 오브젝트면 거부합니다. 메시 하나의 분리된 부품들은 같은 메시를 공유할 수 있습니다.
- **Delete**는 부품을 제거합니다(거부 조건은 아래 편집 참고).

영문 원본 이미지 설명(이미지 생략): 추가된 부품과 선택한 부품의 피벗 컨트롤.

영문 원본 이미지 설명(이미지 생략): 추가된 부품과 선택한 부품의 피벗 컨트롤.

*과거 워크숍 캡처. 추가된 부품과 선택한 부품의 피벗 컨트롤.*

## 관절과 링크의 개별 예제 {#joints-and-links-one-example-each}

**Add Joint**는 관절 생성 안내를, **Add Link**는 링크 생성 안내를 시작합니다. 뷰포트 탭과 프로퍼티스 에디터의 Scene 탭에서 모두 작동합니다. Scene 탭에서 시작하면 화면에서 가장 큰 3D 뷰포트를 사용합니다.

또는 도구 모음을 사용하세요.

1. 뷰포트 도구 모음에서 Build Mechanism을 활성화하세요.
2. 도구 헤더에서 관절 또는 링크 유형을 선택하세요.
3. 첫 부품을 클릭하세요.

같은 안내가 시작되며 첫 선택으로 그 부품을 전달합니다. 이후 뷰포트에서 요청하는 부품과 축을 선택하세요. Add Joint와 Add Link 메뉴도 계속 사용할 수 있습니다.

**Align to Selection**은 기울어진 힌지를 지원합니다. **A**를 누를 때 부품 메시가 편집 모드이고 에지나 면 하나가 선택되어 있어야 합니다. 안내 중 **Tab**은 무시합니다. 사용 전에 메시를 준비하세요.

1. 부품 메시에서 편집 모드로 들어가세요.
2. 에지나 면 하나를 선택하세요.
3. 편집 모드를 유지한 채 **Add Joint → Hinge**를 시작하세요.
4. 부품을 클릭하세요.
5. **A**를 누르세요.

사용 가능한 선택이 없으면 메시지를 표시하며 다른 키를 누를 수 있습니다.

모든 생성 안내의 간단한 규칙:

- 뷰포트에서 부품을 클릭하세요. 클릭한 부품에는 윤곽선과 번호가 표시됩니다.
- 축이 필요하면 **X**, **Y** 또는 **Z**를 누르세요.
- 위와 같이 **Align to Selection**을 준비했다면 **A**로 선택에 맞추세요.
- 마지막 단계는 움직임을 반복 미리보기합니다. **Enter**는 유지하고 **Esc**는 제거합니다.
- 헤더와 상태 표시줄은 각 단계를 완전한 문장으로 안내합니다. Show Helpers가 꺼져 있으면 짧은 이름을 표시합니다.

Joints & Links 목록의 각 행에는 **Test**(재생 삼각형), **Edit**(설정을 여는 연필), **Detach**(끊어진 사슬), **Delete**(X)의 네 아이콘이 있습니다.

생성 후 목록에서 선택한 항목은 해당 유형에 필요한 설정만 표시합니다.

### 힌지 {#hinge}

Blade Hinge, 0°…90°:

1. Blade 부품에 Add Parts from Selection을 사용하세요.
2. **Add Joint → Hinge**를 선택하세요.
3. Blade를 클릭하세요.
4. **X**를 누르세요.
5. **Enter**를 누르세요.

반원 핸들 `CTRL-Blade`와 목록의 *Blade Hinge*가 생성됩니다.

6. **Min**을 0으로 설정하세요.
7. **Max**를 90으로 설정하세요(Hinge는 ° 단위).
8. 반원 핸들을 드래그하여 힌지를 테스트하세요.

핸들은 90°에서 멈춥니다. **Set Min**과 **Set Max**는 현재 핸들 포즈를 한계값으로 복사합니다.

한 바퀴 미만의 한계는 −180°…180° 안에 있어야 합니다. 170°…190° 같은 한계는 메시지와 함께 거부합니다. 한 바퀴 이상(예: −180°…180°)의 범위는 제한 없이 회전합니다.

영문 원본 이미지 설명(이미지 생략): 힌지 한계와 핸들 컨트롤.

*과거 워크숍 캡처. 힌지 한계와 핸들 컨트롤.*

### 슬라이드 {#slide}

Barrel Slide, 0…0.3:

1. **Add Joint → Slide**를 선택하세요.
2. Barrel 부품을 클릭하세요.
3. **Y**를 누르세요.
4. **Enter**를 누르세요.

화살표 핸들이 생성됩니다.

5. **Min**을 0으로 설정하세요.
6. **Max**를 0.3으로 설정하세요(장면 단위).
7. 화살표를 드래그하여 슬라이드를 테스트하세요.

총열은 슬라이드하여 0.3에서 멈춥니다.

영문 원본 이미지 설명(이미지 생략): 선택한 부품의 슬라이드 이동 한계.

*과거 워크숍 캡처. 선택한 부품의 슬라이드 이동 한계.*

### 텔레스코프 {#telescope}

세 구간이 있는 Mast:

1. 베이스와 구간 부품 세 개를 만드세요.
2. **Add Joint → Telescope**를 선택하세요.
3. 베이스를 클릭하세요.
4. 베이스에서 바깥쪽 순서로 각 구간을 클릭하세요.
5. **Enter**를 누르세요.
6. 축 키를 누르세요.
7. 생성을 유지하려면 **Enter**를 누르세요.

베이스에 화살표 핸들 하나가 생깁니다. **Length**는 총 이동 거리이며 <strong>Shares (empty = even)</strong>은 구간별 이동을 나눕니다.

사용자 분배 테스트:

1. **Length**를 1로 설정하세요.
2. <strong>Shares (empty = even)</strong>에 `0.5, 0.25, 0.25`를 입력하세요.
3. 화살표 핸들을 드래그하세요.

세 구간이 각 분배값만큼 늘어납니다. 합계가 Length여야 끝이 전체 길이를 이동합니다. `0.5, abc` 같은 잘못된 입력은 메시지를 표시합니다. 구간마다 숫자 하나가 필요하며 합계는 Length여야 합니다. **Set Max**는 핸들 포즈에서 Length를 정합니다.

영문 원본 이미지 설명(이미지 생략): 텔레스코프 길이와 구간별 분배값.

*과거 워크숍 캡처. 텔레스코프 길이와 구간별 분배값.*

### 피스톤 {#piston}

리프트: 프레임의 실린더, 암의 로드.

1. 암에 Hinge를 만드세요.
2. 암이 프레임을 따라가도록 Rides on을 설정하세요.
3. **Add Link → Piston**을 선택하세요.
4. 프레임의 실린더 부품을 클릭하세요.
5. 암의 로드 부품을 클릭하세요.

핸들 없는 Piston이 생성됩니다. 각 부품은 상대의 부착점을 향합니다. 선택 옵션 **Stretch**는 스프링과 케이블용으로 로드를 늘립니다.

6. 암의 핸들을 움직여 Piston을 테스트하세요.

피스톤이 따라옵니다. 아직 피스톤을 움직이는 요소가 없으면 빌드는 작동하지만 미리보기가 없습니다. **Test**가 이 상태를 알립니다.

영문 원본 이미지 설명(이미지 생략): 연결된 부품의 피스톤 설정.

*과거 워크숍 캡처. 연결된 부품의 피스톤 설정.*

### 기어 링크 {#gear-link}

기어 20:40:

두 부품 모두 먼저 관절이 필요합니다. 구동 부품에는 Hinge가 필요합니다. Gear와 Belt의 피구동 부품은 Hinge, Rack의 피구동 부품은 Slide가 필요합니다.

1. **Add Link → Gear Link**를 선택하세요.
2. 구동 부품을 클릭하세요.
3. 피구동 부품을 클릭하세요.

톱니 수 방식:

1. 링크 설정의 **Source Teeth**를 20으로 설정하세요.
2. **Target Teeth**를 40으로 설정하세요.

또는 **Ratio**를 입력하세요. **Kind**는 Gear, Belt 또는 Rack이며 **Reverse**는 방향을 뒤집습니다. 소스를 돌려 링크를 테스트하세요.

**Kind**가 Gear이면 대상은 −0.5×만큼 회전합니다(Belt는 +0.5×). Gear는 반대 방향, Belt는 같은 방향입니다. Rack은 회전을 슬라이드로 바꾸며 라디안당 이동 거리는 **Ratio** × **Pinion Radius**입니다.

생성 방식은 소스 Hinge 범위에 따라 다릅니다.

- 한 바퀴 미만: Transform 컨스트레인트입니다. Sequence를 포함하여 소스를 움직이는 모든 요소를 따릅니다.
- 한 바퀴 이상: Python이 필요 없는 드라이버입니다. 대상은 소스와 함께 계속 회전하며 핸들과 기어만 따릅니다. Sequence나 Follow가 무시될 때 Rig Validator가 경고합니다.

영문 원본 이미지 설명(이미지 생략): 20:40 예제를 입력하기 전의 Gear Link 컨트롤. 그림의 비율은 1.00이며 두 톱니 수는 모두 0입니다.

*기본 테스트 빌드 팝오버, BoneCraft 9.2.19 후보 버전. Bforartists 5.2.3, Blender 5.4 Alpha. 20:40 예제를 입력하기 전의 Gear Link 컨트롤. 그림의 비율은 1.00이며 두 톱니 수는 모두 0입니다.*

### 추종 {#follow}

Blade 0–90°가 Cover 0–40°를 들어 올리는 예제:

두 부품 모두 Hinge나 Slide가 필요합니다. 소스 Hinge는 한 바퀴 미만의 한계가 필요하며 자유 회전 소스는 거부합니다.

1. **Add Link → Follow**를 선택하세요.
2. 이끄는 부품(Blade)을 클릭하세요.
3. 따라가는 부품(Cover)을 클릭하세요.

처음에는 각 매핑 범위가 관절의 전체 범위를 포함합니다.

4. **Source Range**를 0…90으로 설정하세요.
5. **Target Range**를 0…40으로 설정하세요.
6. Blade 핸들을 움직여 Follow를 테스트하세요.

Cover가 따라갑니다. 범위 끝을 넘어가면 대상은 그 값을 유지합니다. 그래프 에디터에서 매핑 모양을 바꾸려면 **Curve**를 켜세요. BoneCraft는 사용자 커브를 덮어쓰지 않습니다(아래 편집 참고).

영문 원본 이미지 설명(이미지 생략): Follow의 소스 및 대상 범위.

*과거 워크숍 캡처. Follow의 소스 및 대상 범위.*

### 시퀀스 {#sequence}

무기를 접는 단계를 기록합니다.

1. **3. Sequences**에서 **Add Sequence**를 클릭하세요.

`CTRL-SEQ-<name>`이라는 슬라이더 핸들이 생성됩니다.

2. **Move Slider to End**를 클릭하세요.

슬라이더가 끝(1)으로 이동하고 버튼은 다음 단계 번호가 붙은 Record Step으로 바뀝니다.

3. 첫 단계의 관절 핸들 포즈를 만드세요.
4. Record Step 1을 클릭하세요.

움직인 각 핸들이 대상 값과 함께 단계로 기록되며 핸들은 0으로 돌아갑니다.

추가 기록마다:

1. **Move Slider to End**를 클릭하세요.
2. 다음 단계의 관절 핸들 포즈를 만드세요.
3. 현재 번호의 Record Step 버튼을 클릭하세요.

기본적으로 새 단계는 슬라이더의 다음 4분의 1을 사용합니다. 기록한 각 단계에서:

1. **Target**을 설정하세요.
2. Linear, Ease In, Ease Out, Ease In Out 또는 Snap을 선택하세요.
3. **Start**를 설정하세요.
4. **End**를 설정하세요.

자신의 구간 밖에서는 단계가 끝 값을 유지합니다. 여러 Sequence를 중첩할 수 있습니다. **Test**를 클릭하면 슬라이더가 0 → 1 → 0으로 재생됩니다.

선택한 Sequence는 기록 버튼과 **Test** 옆에 **Detach**(끊어진 사슬)와 **Delete**(X)가 있습니다. 예를 들어 단계 커브를 편집하여 보류된 Sequence는 메시지와 **Restore**를 표시합니다. Restore는 기록에서 단계를 재생성합니다. Sequence에는 Keep mine이 없습니다.

영문 원본 이미지 설명(이미지 생략): 시퀀스 생성, 기록된 단계 및 타이밍.

영문 원본 이미지 설명(이미지 생략): 시퀀스 생성, 기록된 단계 및 타이밍.

*과거 워크숍 캡처. 시퀀스 생성, 기록된 단계 및 타이밍.*

## 테스트 {#test}

목록과 3. Sequences의 재생 버튼 **Test**는 메커니즘 하나를 전체 범위로 왕복시킵니다. 키를 쓰지 않으며 끝나면 포즈를 복원합니다. **Esc**로 일찍 중지해도 포즈를 복원합니다. Gear Link나 Follow는 소스를, Piston은 그것을 움직이는 관절을 왕복시킵니다. BoneCraft는 충돌을 감지하지 않으므로 부품끼리 부딪치는지 직접 보세요.

영문 원본 이미지 설명(이미지 생략): 선택한 메커니즘을 움직임 범위 전체에서 테스트합니다.

*과거 워크숍 캡처. 선택한 메커니즘을 움직임 범위 전체에서 테스트합니다.*

## 폼 {#forms}

**4. Controls**에서:

- 모든 관절과 Sequence에 슬라이더가 하나씩 있습니다. 핸들 자체 채널이므로 핸들 드래그와 슬라이더는 같은 동작입니다.
- **Save Form**은 모든 핸들과 Sequence 슬라이더 값을 이름 아래 저장합니다. 목록에서 이름을 바꾸세요.
- **Go to Form**은 모든 컨트롤을 저장된 값으로 설정합니다.
- **Go and Key**는 같은 설정을 하고 현재 프레임에 키도 삽입합니다.
- 목록 옆 **X**는 폼을 제거합니다.

**이전 저장 파일:** BoneCraft 9.2.18은 이전 버전에서 저장한 폼을 읽고 적용합니다. 열거나 적용해도 다시 저장하지 않습니다. **Save Form**은 현재 컨트롤 값을 현재 형식으로 저장합니다. 기존 폼 이름으로 저장하면 그 폼의 저장 값을 대체합니다.

컨트롤은 **Mechanisms → 4. Controls**에 그대로 있습니다. 호환성 수정은 리그 핸들, Sequence 슬라이더 및 패널 위치를 바꾸지 않습니다.

영문 원본 이미지 설명(이미지 생략): 슬라이더, Save Form, Go to Form 및 Go and Key가 보이는 Forms 컨트롤.

*과거 워크숍 캡처. 슬라이더, Save Form, Go to Form 및 Go and Key가 보이는 Forms 컨트롤.*

## BoneCraft가 만드는 요소 {#what-bonecraft-builds}

부품마다:

| 본 | 역할 | 표시 |
|---|---|---|
| `CTRL-<part>` | 핸들. 패널 슬라이더가 그 값입니다. Hinge, Slide, Telescope만 만듭니다. | 표시 |
| `MCH-<part>` | 핸들과 모든 링크를 합한 뒤 한계를 적용합니다. | 숨김 |
| `DEF-<part>` | `MCH-<part>`를 복사하며 메시가 연결됩니다. 엔진에 전달할 본입니다. | 숨김 |

본은 `Mechanism Controls`, `Mechanism MCH` 및 `Mechanism DEF` 컬렉션에 있습니다. 관절 없는 부품에는 `MCH-`와 `DEF-` 본만 있습니다. Telescope의 핸들은 `CTRL-<telescope name>`, Sequence의 핸들은 `CTRL-SEQ-<name>`입니다. Piston은 두 부품 각각에 `MCH-<part>-aim`과 `MCH-<part>-target` 본을 추가합니다.

`MCH-<part>`의 컨스트레인트 순서는 항상 같습니다. 핸들에서 Copy Transforms, 각 링크의 기여, 관절의 Limit Rotation 또는 Limit Location 순서입니다. `DEF-<part>`에는 `MCH-<part>`에서 오는 Copy Transforms 하나가 있습니다.

생성한 모든 요소에는 기록 태그가 있습니다. 컨스트레인트 이름은 `BC·<id>·<role>`로 시작하고 본에는 `bc_mech_id`와 `bc_mech_role` 속성이 있습니다. 이름이 아니라 태그로 찾으므로 본 이름을 자유롭게 바꿀 수 있습니다. 다시 빌드해도 찾아내며 중복 생성하지 않습니다.

Show Helpers를 켜면 각 관절과 링크에 **How this works** 설명이 있습니다. 컨스트레인트 이름과 역할을 나열하며 본을 확인하는 **Select** 화살표 버튼이 있습니다.

사용자의 컨스트레인트, 드라이버 및 본은 건드리지 않습니다. MCH 본에 추가한 컨스트레인트는 다시 빌드한 후에도 BoneCraft 컨스트레인트 아래에 남습니다.

## 편집과 수동 수정 {#editing-and-hand-edits}

- **값 편집**(한계, 비율, 범위, 타이밍, 이징, 핸들 모양)은 기존 컨스트레인트를 제자리에서 갱신하며 다시 빌드하지 않습니다.
- **구조 편집**(Gear Link의 **Kind**, Follow의 **Curve**, Piston의 **Stretch**)은 해당 메커니즘의 컨스트레인트를 대체하고 그 메커니즘만 다시 빌드합니다.
- **Changed by hand.** Limit 같은 BoneCraft 컨스트레인트를 수정하면 메시지 끝에 “(changed by hand)”가 붙습니다. 조용히 덮어쓰지 않으므로 다음 중 하나를 선택하세요.
    - **Keep mine**은 사용자 값을 기록에 복사합니다. 읽어낼 수 없는 값은 거부하며 Restore나 Detach를 사용하라는 메시지를 표시합니다.
    - **Restore**는 수동 편집을 버리고 기록에서 다시 빌드합니다.
- 보류된 메커니즘은 문제를 해결할 때까지 해당 본을 사용하는 모든 메커니즘도 보류합니다.
- 모양을 수정한 커브도 보호합니다. **Curve**를 켜면 그래프 에디터에서 Follow 커브를 편집할 수 있습니다. 이후 Target Range 같은 설정을 바꾸면 커브가 대체되므로 Follow 메시지에 “(changed by hand)”가 붙습니다. **Keep mine**은 사용자 커브를 유지하고 **Restore**는 재생성합니다.
- 보류된 Sequence는 **3. Sequences**에 메시지와 **Restore**, 옆에 **Detach**와 **Delete**를 표시합니다. Sequence에는 Keep mine이 없습니다.
- **Detach**(끊어진 사슬)는 기록과 태그를 삭제하지만 본과 컨스트레인트를 사용자 리그로 남깁니다. Detach와 Delete는 다른 기록에서 사용하는 기록을 거부하고 사용자를 나열합니다.
- **Delete**(X)는 기록과 그에 대해 BoneCraft가 만든 모든 요소를 제거합니다.
- 링크 순환은 생성 전에 거부하고 “Blade Hinge → Cover Follow → Blade Hinge would loop.”처럼 경로를 알립니다.

Rig Validator와 Task Board는 다음을 보고합니다.

- 링크 순환.
- 누락된 부품.
- 메커니즘 밖에서 이동한 DEF 본.
- Python이 필요한 드라이버.
- Sequence나 Follow가 무시되는 Gear Link.

검증기의 이름 검사는 하이픈(`CTRL-`, `MCH-`, `DEF-`)을 허용합니다. 드라이버 검사는 Python이 필요한 표현식만 경고합니다. 정상 메커니즘 리그에는 검증 오류가 없으며 아래 버전 한계에 설명한 `root` 본 경고만 있습니다.

## Show Helpers {#show-helpers}

**Show Helpers**는 BoneCraft 전체에 적용되는 환경설정으로 **Preferences → Add-ons → BoneCraft → Helpers**에 있습니다. 끄면 무엇/언제 문구, **How this works** 설명 및 단계별 전체 문장을 숨깁니다(짧은 이름으로 바뀜). 단계 자체, 목록, Test, 경고 및 Blender의 마우스 오버 툴팁은 항상 남습니다.

VRChat의 **Compact Mode**는 이 스위치의 단축 경로입니다. Compact Mode 켜짐은 Show Helpers 꺼짐입니다.

## 이 버전의 한계 {#limits-of-this-version}

- Click Turn, Track 및 Linkage 메커니즘은 나중에 제공됩니다.
- 베이크한 메커니즘 모션의 엔진 내보내기는 데스크톱 수동 검사 후에 제공됩니다. 그 전에는 `DEF-` 본을 내보내세요.
- BoneCraft는 충돌을 감지하지 않습니다. 충돌 확인:
    1. Test를 사용하세요.
    2. 부품을 관찰하세요.
- 자유 회전 Gear Link는 핸들과 기어만 따릅니다.
- 리그의 `root` 본은 본 컬렉션에 속하지 않아 Rig Validator의 컬렉션 검사가 경고하고 Task Board에 “Rig validation warnings (1)”이 표시됩니다.
