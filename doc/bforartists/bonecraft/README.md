# BoneCraft

This proposal includes BoneCraft 9.2.19 candidate and its manuals.

1. Build Bforartists with this branch.
2. Open Preferences > Add-ons.
3. Search for BoneCraft.
4. Enable BoneCraft.

This branch does not change factory preferences or enable tools automatically.

- [English manual](bonecraft/docs/manual/en/index.md)
- [English PDF](bonecraft/docs/manual/en/BoneCraft_User_Manual.pdf)
- [Six translated manuals and PDFs](docs/bonecraft/translations/README.md)

Languages: French, Japanese, Korean, Portuguese, Spanish and Simplified Chinese.

The translated BoneCraft manuals contain no screenshots.

The runtime is copied from Toolkit commit `b4b8b721cae8`.
The existing module name, settings and license are preserved.
Unfinished interface translation work is excluded. Translated manuals do not imply that every interface control is translated.

The manuals retain their original capture versions and test limits. Relative links to standalone release history open the Toolkit source.
This packaging check does not establish runtime compatibility with the current upstream build.
