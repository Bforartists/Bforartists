# Anim Assist 12.11.2 候选版用户指南

本指南介绍本地、尚未发布的 Anim Assist 12.11.2 候选版，其中包含修订 `7ec664d` 的声音片段设置修复。公开下载仍为 12.11.1。2026 年 11 月 20 日的审查涵盖源代码和文档。

发布信息见[当前更新日志](../../../../../../scripts/addons_core/B4_anim_assist/CHANGELOG.md)和[文档索引](../README.md)。

每张截图都放在对应说明旁。图注列出截图版本或已记录的验证日期。旧截图用于辨认控件，不代表进行了新的验收测试。

英文原手册中的面板图大多展示基于 Blender 5.4 Alpha 的随附 Bforartists 5.2.3 构建中的 Anim Assist 12.11.1，另有一张口型同步图展示基于 Blender 5.3 Alpha 的官方 Bforartists 5.2.3 中的 12.11.2 候选版。本地化版本改用本地、尚未发布的 12.11.2 候选版新截取的原生界面截图，各图说明列明拍摄环境和证据适用范围。原生面板弹出窗口清楚展示已注册的控件。使用工具时，请按下文说明打开其所在编辑器的工具入口。

使用动画摄影表处理姿态和时间安排，使用曲线编辑器处理动作曲线或驱动器，使用 NLA Editor 处理片段和修正。帮助控件说明各工具的用法。英文原指南中的控件名称对应英文界面。

## 安装并找到工具

<a id="install-the-standalone-add-on"></a>

### 安装独立插件

1. 下载[已发布的 12.11.1 插件 ZIP](https://raw.githubusercontent.com/Axleonex/B4Artists_Toolkit/main/releases/b4_anim_assist_v12.11.1.zip)。

2. 在 Bforartists 中打开**编辑 > 偏好设置 > 插件 > 从磁盘安装**。

3. 选择 ZIP 文件。

4. 启用 **Anim Assist**。

5. 更新后重启 Bforartists。

独立安装包名为 `B4_anim_assist`。安装时请保留完整 ZIP，不要解压。

### 找到各编辑器入口

早期运行验证使用原版 Bforartists 5.2.0，基于 Blender 5.3.0 Alpha，构建号 `0a1ca45552db`，使用 OpenGL。此历史证据仅适用于该宿主版本。不支持标准 Blender。这些结果不能验证所有其他宿主构建。

- **时间线：**Anim Assist 工具行位于画布底部，见下方**时间线：底部工具行**。播放和关键帧控件仍在原生标题栏中。
- <strong>动画摄影表、曲线编辑器和 NLA Editor：</strong>侧栏含 **Anim Assist** 选项卡。它与原生选项卡的相对位置可能不同。标题栏的 **Anim Assist** 菜单也可打开这些工具。
- **驱动器：**曲线编辑器处于**驱动器**模式时，**Anim Assist** 侧栏选项卡和标题栏菜单会切换为驱动器工具。
- <strong>场景属性 > Anim Assist：</strong>此入口包含角色设置、较大范围的动画工具、宏、设置和帮助。3D 视图侧栏没有 Anim Assist 选项卡。

打开侧栏工具：

1. 将指针移入动画摄影表、曲线编辑器或 NLA Editor。

2. 按 N。

3. 选择 **Anim Assist** 选项卡。

处理驱动器时，将曲线编辑器切换为**驱动器**模式。

**场景属性 > Anim Assist > 设置（每个绑定一次）> 运行首次运行设置**会创建通用快捷工具架。设置还提供工作区。可选的 **Shift Alt D** 饼菜单默认禁用。要启用或重新绑定此菜单，请打开**设置**。

## 时间线：底部工具行

工具行位于时间线底部、原生水平滚动条上方。它不会添加标题栏、区域或工作区分割。播放和关键帧控件仍在原生标题栏中。使用**时间线 > 视图 > 显示 Anim Assist 工具行**显示或隐藏该行。

按钮始终保留完整高度，点击区域与按钮一致。调整大小时会在滚动条上方预留空间。如果松开分隔线时高度低于最低要求，时间线会恢复到足以显示工具行的高度。工具栏优先处理行内点击，然后才由原生播放头和关键帧选择控件处理。请在工具行上方保留足够高度，以便查看关键帧。

工具行从左至右包含：

| 控件 | 用途 |
|---|---|
| **阶段按钮**（例如带小箭头的**全部**） | 显示当前阶段并打开阶段列表。 |
| **类别按钮**（补间、节奏、曲线、关键帧、姿态、烘焙、运动） | 彩色类别名称可打开该类别的完整工具列表。工具位于各类别名称后方。 |
| **工具** | 按钮、图标和滑块用于运行工具。悬停文字说明各工具的用途。 |
| **+N** | 打开当前工具行放不下的 N 个工具列表。 |
| **查找**（放大镜） | 搜索或列出全部 96 个工具。每个结果都有运行和固定工具的控件。 |
| **设置** | 打开工具栏设置，配置各工具行。 |

1. 点击阶段按钮、类别按钮或 **+N**，打开其列表。

2. 点击列表项以使用该工具。

指针移动时，列表会保持打开，移到其他编辑器上方也一样。点击另一个类别按钮会将列表切换至该类别。

再次点击同一按钮、点击其他位置或按 **Esc**，可关闭列表。

### 选择阶段

每个阶段包含动画制作某一环节所需的工具：

- <strong>全部：</strong>汇集各类别工具的总览。
- <strong>粗略布局：</strong>用于确定主要姿态的补间和关键帧工具。

- <strong>曲线化：</strong>用于样条调整和检查弧线的曲线与运动工具。

- <strong>精修：</strong>用于调整间距与对称性的时间和姿态工具。

- <strong>交付：</strong>用于收尾和导出的烘焙工具。

切换阶段：

1. 点击工具行左侧的阶段按钮。

2. 点击其上方列表中的阶段。

选定阶段后列表会关闭。如果时间线高度较小，五个选项会在可用画布内排列成一行。

也可使用**时间线 > 视图 > Anim Assist 阶段**选择阶段。

使用滚轮切换阶段：

1. 将指针放在阶段按钮上，并按住 **Ctrl**。

2. 滚动滚轮。

每个工作区的阶段单独保存在文件中。

### 使用工具

点击按钮或图标即可运行工具。关键帧类型图标使用主题中的动画摄影表关键帧颜色。过渡帧菱形较小，极值帧菱形较大。控制柄图标使用曲线编辑器的控制柄颜色。

1. 将指针悬停在图标上，查看名称。

2. 如果工具呈灰色，悬停查看其使用条件，例如需要选中关键帧。

3. 点击可用的按钮或图标，运行工具。

**内嵌滑块**始终显示在工具行上。只点击而不拖动不会产生修改。

1. 拖动滑轨，预览修改。

2. 松开鼠标按钮，应用修改。

拖动时按 **Esc** 或点击右键可取消。取消会恢复原来的关键帧。

- 拖动时按住 **Shift** 可进行更精细的调整。
- 拖动时按住 **Ctrl** 可按工具的步长吸附。

拖动时输入精确数值：

1. 输入数字。

2. 按 **Enter** 应用。

**刻度**是滑轨上的预设值。拖动时会吸附到附近刻度。要应用预设的精确数值，点击其刻度。

内嵌滑块右侧的数字可打开精确数值输入框。按 **R** 可应用该工具的默认数值。

**弹出滑块**在工具行上显示名称。拖动名称和点击名称会打开不同的弹出模式。

临时打开弹出滑块：

1. 拖动名称，打开滑块。

2. 松开鼠标按钮，应用修改。

保持弹出滑块打开：

1. 点击名称一次。

2. 拖动滑轨，预览修改。

3. 双击或点击其他位置，应用修改。

按 **Esc** 可取消弹出滑块的修改。

右键点击工具可打开其**工具设置**。

十个数值滑块分别为过渡姿态、平滑、相邻值、到参考值、缓动、放大、时间缩放、时间偏移、波纹和精简。

- **过渡姿态**在前后姿态之间混合。低于 0% 或高于 100% 的值会超出这两个姿态。
- **时间缩放**改变关键帧间距。低于 100% 时，关键帧靠近，播放变快；高于 100% 时，关键帧远离，播放变慢。**时间偏移**沿时间方向移动活动对象的动作。
- **波纹**按所选帧数移动播放头之后的关键帧。向前面的帧移动时，最多移动到播放头后一帧。
- **精简**在曲线变化低于所选容差时移除关键帧。预览中关键帧会消失。按 **Esc** 可恢复。
- **到参考值**向参考帧混合。**设置参照**保存该帧。**放大**围绕此参考值缩放运动。

时间偏移等作用于整个动作的工具会影响选中关键帧之外的数据。修改整个动作前，请检查悬停文字和场景选项。

### 保存、加载和重置布局

一个布局包含所有工具行：全部及四个阶段。

| 控件 | 结果 |
|---|---|
| **另存为** | 为当前布局命名并保存。 |
| **加载** | 恢复已保存的布局。 |
| **更新已保存项** | 用当前工具行替换已保存的布局。 |
| **重命名**和**删除** | 重命名或删除已保存的布局。 |
| **推荐** | 标识固定的内置布局。 |
| **将 粗略布局 重置为默认值** | 恢复该阶段的默认工具集。控件名称随正在编辑的工具行变化。 |

### 过渡姿态锚点

当前帧为空时，前后关键帧作为混合锚点。例如，数值为 0 和 10 时，50% 得到 5。

应用过渡姿态前，请检查播放头、关键帧和遮罩。

## 曲线编辑器：调整曲线形状

**重塑曲线**默认展开，提供直接塑形、插值和控制柄操作。分组为**选择与通道、重塑曲线、重定时、清理、姿态与烘焙和快捷工具架**。**选择与通道**包含控制柄选择。**清理**包含关键帧管理和诊断。**姿态与烘焙**包含匹配、镜像、过渡姿态和烘焙，其中折叠的**过渡姿态选项**设置过渡姿态采样，不用于设置一般曲线插值。

1. 选择可见、可编辑的动作关键帧。

2. 执行塑形或插值操作。

3. 检查生成的曲线和视图。

动作选择辅助工具支持**对象动作**。如果作用范围为空，辅助工具不会改为从整个活动动作选择。它们排除脱离对象的固定动作和非对象来源。侧栏会说明这些排除项。使用作用于整个动作的工具前，请检查说明。

## 驱动器：检查和调整驱动响应

使用驱动器工具时，将曲线编辑器切换至**驱动器**模式。**Anim Assist** 侧栏和标题栏菜单会显示四个驱动器专用分区。切回动作曲线会恢复上述动作分组。驱动器模式使用驱动器通道，而不是动作关键帧工具。

<a id="driver-target"></a>

### 驱动器与目标

此分区统计选中且可见的驱动器。对于活动驱动器，还显示**所属对象**、**属性**和**当前值**，适用时显示**数组索引**。无法解析属性时会显示警告。

1. 在通道列表中选择一个可见的驱动器通道。

2. 在**驱动器与目标**中检查其所属对象和受驱动属性。

3. 点击**框显选中项**，使所选曲线完整显示在视图中。

4. 点击**框显全部**，查看整个驱动器视图。

**所有通道**和**无**改变通道选择。**选择所属对象**将驱动器所属对象设为活动对象，其他已选对象仍保持选中。所属对象必须位于当前视图层，并允许在可见状态下选择。其他数据块上的驱动器无法使用此对象选择操作。

如果所属对象可编辑，**已静音**和**已锁定**可修改活动驱动器的原生通道设置。只选中一个可见驱动器时，锁定后仍可检查。关闭**已锁定**即可解锁。如果多个选中通道导致活动驱动器不明确，请明确选择所需通道。

未选择任何项时，四个分区仍会显示并提供指引，但不会创建驱动器。

使用这些分区前：

1. 通过 Bforartists 原生驱动器工作流程创建驱动器。

2. 连接这些驱动器。

![选中的驱动器及响应控件侧栏。当前驱动器为 Empty 的 X 缩放通道，索引为 0，驱动器曲线未锁定；响应点未选中，因此插值和控制柄操作呈灰色。添加修改器选择器针对活动驱动器，中文文字及其原生换行保持原样；此图未编辑响应或添加修改器。2026-11-21（UTC）实际截图：Anim Assist 12.11.2；Bforartists 发行目录标记为 5.2.3，运行时 API 报告为 5.3.0 Alpha。](images/zh/12.11.0-selected-driver.png)

### 变量与表达式

此分区统计变量数量。脚本驱动器显示**表达式**，其他驱动器类型显示**类型**。原生**驱动器**选项卡包含完整、可编辑的变量和表达式设置。

3. 打开**变量与表达式**。

4. 点击**打开驱动器设置**。

### 响应曲线

横轴表示驱动器输入，纵轴表示受驱动的输出。响应点将输入映射为输出，与使用动画时间的动作关键帧不同。

1. 选择要编辑的可见驱动器通道。

2. 解锁这些通道。

3. 检查它们的所属对象是否可编辑。

4. 修改点时，选择响应点或控制柄的某一侧。

5. 在**响应曲线**中选择**插值**或**控制柄**。

6. 检查生成的响应和受驱动属性。

| 控件 | 作用范围和结果 |
|---|---|
| **插值** | 修改所选可见、可编辑驱动器通道中的选中响应点。可选常量、线性和贝塞尔。 |
| **控制柄** | 修改这些通道中选中的控制柄侧。如果选中控制点，则修改两侧控制柄。 |
| **外插** | 修改所选可见、可编辑驱动器通道在端点范围之外的行为。常量保持输出不变，线性延续端点斜率。 |
| **添加修改器（活动项）** | 仅为活动且可编辑的驱动器添加所选响应修改器，不影响所有选中通道。 |
| **打开修改器设置** | 打开活动驱动器的原生**修改器**选项卡。 |

点操作需要选中点或控制柄。外插需要选中可编辑通道。修改器操作需要活动、未锁定且所属对象可编辑的驱动器。打开原生设置还要求该可编辑驱动器是原生活动项。控件禁用时，将指针悬停其上查看使用条件。

插值、控制柄、外插和创建修改器支持原生**撤销**和**调整上一步操作**。这些操作仅影响指定驱动器，排除动作关键帧和无关驱动器。运行验证未逐一涵盖每一种原生修改器类型。

3. 点击**检查选中驱动器**。

4. 阅读结果弹出窗口。

5. 在对应原生设置中修正报告指出的目标、路径、骨骼或表达式。

## NLA：排列片段并混合修正

**排列与节奏**和**混合与修正**默认展开。**动作与轨道、烘焙并完成和快捷工具架**默认折叠。摘要显示所属对象、活动片段、源动作、选中片段数量、场景范围和源范围。场景帧表示片段的位置，源帧表示片段内部的动作区间。

<a id="arrange-clips"></a>

### 排列片段

1. 选择要修改的动作片段。

2. 点击参考片段的主体，将其设为活动片段。

3. 检查参考片段是否仍然选中。

4. 点击 **-1f/+1f** 微移，或点击**移动选中片段**进行原生移动。

5. 使用**对齐起点／终点**，将片段与选中的活动片段对齐。

6. 使用**顺序排列片段**，从参考片段起点开始连续放置片段。

7. 在**调整上一步操作**中修改步长或序列间隔。

8. 展开**节奏选项**，设置活动片段的缩放、重复、反转以及场景起止帧。

时间操作使用场景帧。遇到锁定或重叠的批次时，工具会拒绝整批修改，不会只修改其中一部分。编辑源动作时，排列操作暂停。这些工具不能编辑过渡片段、元片段或声音片段。

### 编辑源动作并管理共享

**编辑动作**进入原生 NLA 调整模式。**打开摄影表／打开曲线编辑器**会复用适合且未固定的编辑器，或切换当前区域。原生调整模式为已移动、缩放、重复和反转的片段映射源时间。

编辑后返回排列操作：

1. 在编辑器选择器中选择**非线性动画**，返回 NLA。

2. 点击**完成编辑**。

编辑共享动作可能影响其他片段。摘要会警告共享情况，并报告被排除的来源。静音和独显影响求值。

| 控件 | 结果 |
|---|---|
| **使选中片段单用户化** | 分离所选片段的源动作。 |
| **独立复制** | 复制动作。 |
| **关联复制** | 共享动作。 |
| **上移选中轨道／下移选中轨道** | 调整轨道顺序，不会将片段移到其他轨道。 |

**下推活动动作／暂存活动动作**作用于活动所属对象已分配的动作。下推要求启用 NLA 求值。未选中片段时，对于可编辑的活动对象，摘要提供**添加现有动作片段**。

### 添加变换修正

1. 选择一个受支持的源动作片段。

2. 点击**新建变换修正**。

3. 选择新的修正片段。

4. 点击**编辑修正**。

5. 在原生调整模式中编辑其变换关键帧。

6. 编辑后，点击**完成编辑**。

7. 保持未修改通道为中性值：位置为零、旋转为零或单位旋转、缩放为一。

8. 在播放头处点击 **0%、50% 或 100%**，为活动片段的影响力插入关键帧。

原生**合并**混合将修正应用到源运动之上。要使用其他影响力数值，请在**调整上一步操作**中输入。影响力为零时，修正不贡献运动。

创建时会添加独立的修正动作，并在源轨道上方添加轨道。修正支持对象和姿态骨骼变换。创建操作会阻止含约束或驱动器的绑定、无法解析的骨骼和非变换源通道，并说明原因。这些修正与场景属性中的通用动画层工具彼此独立。

混合和动画化影响力是原生片段设置。如果禁用动画化影响力，侧栏会标明自动混合包络。**混合选项**显示自动混合、淡入淡出和外插。影响力按钮创建原生影响力关键帧，不会在源动作中创建姿态关键帧。

### 保留源堆栈进行烘焙

1. 选择要烘焙的所属对象的一个片段。

2. 打开**烘焙并完成**。

3. 检查显示的所属对象和场景范围。

4. 点击**烘焙到新动作**。

5. 如有需要，在**调整上一步操作**中调整范围和步长。

6. 检查输出名称和范围。

7. 激活烘焙结果前，请静音或移除会再次作用的活动约束。

8. 选择**使用最新烘焙（关闭 NLA）**。

烘焙将求值后的对象或姿态变换写入新动作并保留。新动作起初**未分配**。原来的动作、片段、父级和约束均保留。激活烘焙结果是单独的操作。<strong>使用最新烘焙（关闭 NLA）</strong>分配结果，并禁用源堆栈求值。

保存源场景以供比较。重命名不会改变输出归属。其他对象即使使用旧名称也不能接收该输出。**移除空轨道**单独移除空轨道。

NLA 快捷工具架的快捷操作可使源动作独立、编辑活动源动作以及烘焙所属对象。它们不会对片段运行通用关键帧编辑宏。

当前帧、选中关键帧和帧范围是三种独立的偏移范围。帧范围衰减将偏移随时间分布。缓入和缓出衰减不会改变曲线切线。这些工具使用**各自的原点**轴心，不会围绕中点或游标旋转。

匹配提供世界、父级、目标、指定通道、视觉或求值以及局部矩阵操作。目标匹配通常需要选中两个对象。

执行目标匹配：

1. 先选择目标。

2. 再选择要修改的对象。

**将选中物体对齐至活动物体**以活动对象为参考。这些控件不会自动理解所有绑定。

使用带补偿的空间切换或 IK/FK 工作流程前：

1. 配置切换属性映射。

2. 配置骨骼链。

镜像工具要求骨架处于**姿态模式**。**选择对侧**只改变选择。按帧或范围执行的镜像也可能插入关键帧。

使用**镜像姿态**、**镜像选中项**或**交换**前：

1. 检查配对检测和命名例外。

2. 检查镜像空间和轴。

3. 检查通道筛选器。

4. 阅读工具说明。

### 动作偏移与运动轨迹

**整个动画**包含活动动作偏移和可选范围遮罩。这些偏移可能影响选中关键帧之外的数据。

启用作用于整个动作的编辑前：

1. 配置遮罩。

2. 配置范围。

使用运动轨迹：

1. 选择轨迹设置要作用的对象或姿态骨骼目标。

2. 打开**整个动画 > 轨迹叠加层**。

3. 选择显示模式。

4. 选择采样范围。

5. 设置采样步长。

6. 点击**启用叠加层**，或使用时间线的**轨迹**眼睛图标。

7. 修改后，按需要刷新轨迹。

8. 运行弧线诊断，标出需要检查的运动。

9. 检查被标记的运动。

轨迹选项包括帧或关键帧刻度、帧号、速度、切线、残影和颜色显示。当前帧附近范围和自定义范围用于限制采样。**采样上限**限制样本数量。弧线诊断只标出需要检查的运动，不认证动画质量，也不会自动解算绑定。

### 定位器、代理与烘焙会话

1. 打开**绑定 > 代理与烘焙**。

2. 选择所需对象。

3. 选择定位器，或平移、朝向、世界空间或父级空间代理。

4. 为所选烘焙命令设置烘焙范围。

5. 设置烘焙步长。

6. 选择烘焙通道。

7. 运行烘焙命令。

8. 检查烘焙后的运动。

9. 仅在检查烘焙结果后，才进行会话清理。

定位器控件可在目标、所选项平均位置或游标处创建定位器，也可在定位器与目标之间建立父级关系、添加约束、匹配和烘焙。使用成对控件前，请看清箭头方向。

**智能烘焙**结合变换烘焙与关键帧精简。**精简关键帧**按容差简化现有关键帧。可用范围包括场景、动作、自定义、选中关键帧和预览范围。这些通用烘焙命令与 NLA 中保留源数据的**烘焙到新动作**流程不同。

**一键代理与烘焙**先在独立代理会话中记录世界空间运动，再进行烘焙。**烘焙会话并移除代理**清理该会话。**移除所有代理会话**影响范围更大。现有验证不能认证所有带父级、带约束或生产绑定的情况。移除辅助对象前，请比较结果。

### 动画层

1. 打开**整个动画 > 动画层**。

2. 启用图层系统。

3. 点击**创建基础层**，为当前动画建立基础层。

4. 添加工作层。

5. 选择工作层。

6. 选择其混合模式。

7. 设置权重。

8. 配置其骨骼分配。

9. 插入关键帧前，选择所需工作层。

10. 使用图层的独显、静音和锁定控件进行预览。

分配列表为空时包含全部骨骼。在姿态模式中，可见面板提供**分配**、**移除**和**选择**来管理骨骼分配。每个图层行包含权重、独显、静音、锁定和自动关键帧。

此已注册面板不显示**仅编辑活动项**、**插帧时自动分配**或全部高级图层控件。原生操作搜索提供已注册操作，例如**按模式分配**、**向下合并**和**展平所有层**。合并或展平前，请检查堆栈。这些图层与 NLA 变换修正片段彼此独立。

<a id="lipsync"></a>

### 口型同步

1. 打开**面部 > 口型同步**。

2. 启用口型同步。

3. 使用 **+** 添加口型同步层。

4. 选择该层。

5. 在**音频**中绑定 **WAV** 文件。

6. 选择**形态键**、**骨骼**或**两侧**（同时驱动形态键和骨骼）作为目标。

7. 选择网格或骨架目标。

8. 根据所选视素库配置**形态键连接**或**骨骼绑定连接**。

9. 核对连接条目中的目标名称。

10. 检查预备量、帧偏移和分析后端。

11. 点击**烘焙**。

12. 检查嘴部运动。

执行**重新烘焙**前，使用**锁定选中关键帧**保留选中的手动编辑。

**实时预览／已烘焙**显示该层状态。形态键输出要求网格具有已连接的形态键。骨骼输出要求有效的动画层、骨架和连接设置。**自动填写**提供连接条目。**口型捕获 > 捕获**保存自定义姿态。

使用状态控件选择所需的预览或烘焙工作流程。

振幅分析不需要外部音素可执行程序。可选的 Rhubarb 分析需要配置 **Rhubarb 路径**。使用输出前，请阅读后端回退和缺失图层报告。如果存在扬声器片段，扬声器叠加会在动画摄影表或时间线中显示音频。

侧栏的**清除**移除自动输出并保留已标记的手动编辑。**重新烘焙**也保留手动覆盖。**高亮手动关键帧**显示受保护编辑。更换音频会将该层标为过时。再次烘焙前，请解决报告指出的 WAV、目标和图层问题。

## 故障排查与验证限制

如果关键帧操作没有效果：

1. 检查活动编辑器。

2. 检查已选中的可编辑关键帧和可见通道。

3. 检查锁定、所属对象和动作。

4. 检查动作数据和编辑器筛选器。

工具栏可见并不能证明操作已插入关键帧。原生插入关键帧仍是为网格或对象插帧的常规流程。

报告问题时，请提供插件版本、Bforartists 构建、确切命令及可复现问题的小型场景。

如果某项 NLA 操作不可用：

1. 检查轨道锁定及静音或独显排除项。

2. 检查是否缺少动作、NLA 求值是否禁用，或是否处于调整模式。

3. 排列片段前，点击**完成编辑**。

4. 创建修正时，请阅读不支持该绑定或通道的原因。

更改时间或烘焙后：

1. 检查运动。

2. 如有需要，使用原生撤销。

3. 保存场景。

4. 重新打开场景后，再依赖该结果。

驱动器设置不可用时，选择未锁定的驱动器通道，将其设为原生活动项。锁定的驱动器仍可显示，供检查和解锁。如果选中了多个驱动器但没有明确的活动目标，工具不会自行选取。点编辑操作要求选中响应点。
