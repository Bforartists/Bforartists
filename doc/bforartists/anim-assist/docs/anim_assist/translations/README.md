# Anim Assist 12.11.2 candidate translated guides

These six editions follow the current [English guide](../AnimAssist_User_Manual.md). Each preserves its 36 headings, 180 numbered steps, seven tables, code examples and 46 inline figures.

The guides cover the local, unpublished 12.11.2 candidate. The public standalone ZIP remains at 12.11.1; these documentation files do not publish or update that download.

The inline figures are genuine native captures from the localized candidate on official Bforartists 5.2.3, with a Blender 5.3 Alpha base. Captions state their actual dates, visible state and limits. Some auxiliary messages remain in English; the captions explain their meaning in the target language. A screenshot documents its stated example, not every production workflow.

Each PDF includes two historical reference images in an appendix. The corresponding links open those pages inside the PDF, without requiring unpublished web images. The Markdown links open the included original image files. Other release and qualification references retain their original destinations.

The [manifest](manifest.json) records the exact source, manual, PDF and figure hashes, page counts and review evidence. Code, keyboard shortcuts, object names and saved-data identifiers remain unchanged. Zoom narrow toolbar images to inspect their preserved pixels; the adjacent instructions explain the controls.
