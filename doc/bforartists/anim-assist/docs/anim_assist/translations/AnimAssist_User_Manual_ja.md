# Anim Assist 12.11.2 候補版ユーザーガイド

このガイドは、ローカルにある未公開の Anim Assist 12.11.2 候補版を説明します。リビジョン `7ec664d` のサウンドストリップ設定の修正を含みます。公開ダウンロードは、引き続き12.11.1です。2026年11月20日のレビューは、ソースとドキュメントを対象としました。

リリース情報は、[現在の変更履歴](../../../../../../scripts/addons_core/B4_anim_assist/CHANGELOG.md)と[ドキュメント一覧](../README.md)を参照してください。

各スクリーンショットは、対応する説明のそばに配置しています。各キャプションは、撮影時のバージョンまたは記録済みの検証日を示します。古いスクリーンショットは、操作項目の位置を示すものです。新たな受け入れテストの記録ではありません。

英語版の原本では、パネル図の多くに、Blender 5.4 Alpha ベースの付属 Bforartists 5.2.3 ビルド上の Anim Assist 12.11.1 のキャプチャーを使用しています。また、Blender 5.3 Alpha ベースの公式 Bforartists 5.2.3 上の12.11.2候補版で撮影したリップシンク図も使用しています。この日本語版では、ローカルにある未公開の12.11.2候補版をホスト上で新たに撮影したスクリーンショットを使用し、各図のキャプションに撮影環境と検証上の限界を示しています。標準のパネルポップオーバーで、登録済みの操作項目を見やすく表示しています。ツールを使うときは、以下の説明に従って、そのエディター内の配置場所を開いてください。

ポーズとタイミングにはドープシートを使います。アクションカーブやドライバーにはグラフエディターを使います。クリップと補正には NLAエディターを使います。各ツールの説明は、ヘルプの操作項目から確認できます。このガイドでは、日本語の操作名を使用します。現在も英語で表示されるラベルは、画面の表記どおりに残しています。

## インストールとツールの場所

<a id="install-the-standalone-add-on"></a>

### 単体アドオンをインストールする

1. [公開済みの12.11.1アドオン ZIP](https://raw.githubusercontent.com/Axleonex/B4Artists_Toolkit/main/releases/b4_anim_assist_v12.11.1.zip) をダウンロードします。

2. Bforartists で **編集 > プリファレンス > アドオン > ディスクからインストール** を開きます。

3. ZIP を選択します。

4. **Anim Assist** を有効にします。

5. 更新後は Bforartists を再起動します。

単体パッケージ名は `B4_anim_assist` です。インストール時は ZIP を展開せずに使用します。

次の図は、付属ビルドの組み込みアドオン項目を示します。単体版には、上記の ZIP インストール手順を使用してください。

### 提案中の組み込み版を使用する

付属のカスタム／ネイティブテストビルドには、Anim Assist が含まれています。初期プリファレンスでアドオンが有効になります。この提案中の組み込み版では、ZIP の別途インストールは不要です。この説明は、公式 Bforartists リリースに Anim Assist が含まれることを示すものではありません。

### 各エディター内の場所を見つける

以前の動作検証は、Blender 5.3.0 Alpha ベース、ビルド `0a1ca45552db`、OpenGL の標準 Bforartists 5.2.0 で実施しました。この過去の検証記録は、そのホストに適用されます。標準の Blender はサポート対象外です。これらの結果は、他のすべてのホストビルドを検証するものではありません。

- **タイムライン:** Anim Assist のツール列は、キャンバス下部に表示されます。以下の **タイムライン: 下部のツール列** を参照してください。再生とキー挿入の操作項目は、標準のヘッダーに残ります。
- **ドープシート、グラフエディター、NLAエディター:** サイドバーに **Anim Assist** タブがあります。標準タブとの位置関係は変わることがあります。ヘッダーの **Anim Assist** メニューからも開けます。
- **ドライバー:** グラフエディターの **ドライバー** モードでは、**Anim Assist** のサイドバータブとヘッダーメニューが、ドライバーの作業に切り替わります。
- **プロパティ > シーン > Anim Assist:** キャラクターのセットアップ、より広い範囲のアニメーションツール、マクロ、設定、ヘルプがあります。3Dビューポートのサイドバーに Anim Assist タブはありません。

サイドバーのツールを開くには:

1. ポインターをドープシート、グラフエディター、NLAエディターのいずれかに移動します。

2. N を押します。

3. **Anim Assist** タブを選択します。

ドライバーの作業には、グラフエディターを **ドライバー** モードに切り替えます。

**プロパティ > シーン > Anim Assist > セットアップ（リグごとに1回） > 初回セットアップを実行** は、共通のクイックシェルフを作成します。セットアップには、ワークスペースの追加もあります。任意の **Shift Alt D** パイメニューは、初期状態では無効です。有効化やキーの再割り当てには、**設定** を使用します。

## タイムライン: 下部のツール列

ツール列は、タイムライン下部の標準の横スクロールバーの上に表示されます。ヘッダー、領域、ワークスペースの分割は追加しません。再生とキー挿入の操作項目は、標準のヘッダーに残ります。列の表示を切り替えるには、**タイムライン > ビュー > Anim Assistのツール列を表示** を使用します。

ボタンは元の高さを保ち、クリック範囲もその高さに一致します。サイズ変更時は、スクロールバーの上にスペースを確保します。仕切りを最小の高さより下で離すと、タイムラインは列に必要な高さに戻ります。ツールバーは、標準の再生ヘッドやキー選択の操作より先に、列のクリックを処理します。キーを確認できるよう、列の上にも十分な高さを確保してください。

列は左から右へ、次のように並びます。

| 操作項目 | 動作 |
|---|---|
| **作業段階ボタン**（小さな矢印付きの **すべて** など） | 現在の作業段階を表示し、作業段階の一覧を開きます。 |
| **分類ボタン**（中割り、タイミング、カーブ、キー、ポーズ、ベイク、モーション） | 色付きの名前から、各分類の全ツール一覧を開きます。各分類名の後に、その分類のツールが並びます。 |
| **ツール** | ボタン、アイコン、スライダーでツールを実行します。マウスを重ねると各ツールの説明を表示します。 |
| **+N** | 列に収まらない N 個のツールの一覧を開きます。 |
| **検索**（虫眼鏡） | 全96ツールを検索または一覧表示します。各結果には、ツールの実行とピン留めの操作があります。 |
| **設定** | ツールバー設定を開き、各行を設定します。 |

1. 作業段階ボタン、分類ボタン、**+N** のいずれかをクリックして、一覧を開きます。

2. 項目をクリックして使用します。

ポインターを動かしても、別のエディターの上へ移動しても、一覧は開いたままです。別の分類ボタンをクリックすると、その分類の一覧に切り替わります。

一覧を閉じるには、同じボタンをもう一度クリックするか、他の場所をクリックするか、**Esc** を押します。

### ツールの分類

各分類は、機能別にコマンドをまとめています。各ツールのマウスを重ねたときの説明には、対象範囲と必要条件があります。

| 分類 | 作業内容 |
|---|---|
| **中割り** | ブレイクダウンの割合指定とドラッグ、中割り、分配、隣接ポーズへ寄せる操作やポーズを越える操作。 |
| **タイミング** | フレームの微調整、間隔プリセット、タイミングスライダー、リップル、時間の挿入と除去、分配、反転、丸め。 |
| **カーブ** | スプライン／ステップ補間、隣接キー／参照／イーズへのブレンド、増幅、平滑化、ハンドルタイプ、参照ブックマーク。 |
| **キー** | 表示キー、範囲、両端の選択、選択の拡張、キータイプ、ブレイクダウンの選択、コピー、貼り付け。 |
| **ポーズ** | ミラー反転、反対側の選択、入れ替え、整列、ワールド／親／対象への一致、設定済みリグプロパティの切り替え。 |
| **ベイク** | オブジェクト／プレビュー範囲のベイク、スマートベイク、削減、整数タイミング、プロキシの作成、セッションのベイクと後片付け。 |
| **モーション** | ワールド空間のモーショントレイル、更新、軌跡診断、アクティブアクションのオフセットと範囲マスク。 |

### 作業段階を選択する

作業段階は、アニメーション制作の各段階に使うツールをまとめています。

- **すべて:** 全分類のツールを含む一覧です。
- **ブロッキング:** ポーズを固めるための、中割りとキーのツールです。

- **スプライン:** スプライン化と軌跡の確認に使う、カーブとモーションのツールです。

- **仕上げ:** 間隔と対称性を調整する、タイミングとポーズのツールです。

- **納品:** 完成と書き出しに使う、ベイクのツールです。

作業段階を変更するには:

1. 列の左端にある作業段階ボタンをクリックします。

2. その上の一覧で作業段階をクリックします。

作業段階を選択すると、一覧は閉じます。タイムラインの高さが低い場合は、使用可能なキャンバス内の1行に5つの選択肢を表示します。

**タイムライン > ビュー > Anim Assist 作業段階** からも選択できます。

ホイールで作業段階を切り替えるには:

1. 作業段階ボタンの上で **Ctrl** を押したままにします。

2. ホイールを回します。

保存ファイルには、ワークスペースごとの作業段階が保持されます。

### ツールを使用する

ボタンとアイコンは、クリックするとツールを実行します。キータイプのアイコンは、使用中のテーマのドープシートのキー色を使います。ブレイクダウンのひし形は小さく、エクストリームのひし形は大きく表示します。ハンドルのアイコンは、グラフエディターのハンドル色を使います。

1. アイコンにマウスを重ねて、名前を確認します。

2. ツールが灰色の場合は、マウスを重ねて、キーの選択などの必要条件を確認します。

3. 使用可能なボタンまたはアイコンをクリックして、ツールを実行します。

**インラインスライダー** は、列の中に表示されます。ドラッグせずにクリックしただけでは、何も変更しません。

1. スライダーのトラックをドラッグして、変更をプレビューします。

2. ポインターのボタンを離して、変更を適用します。

ドラッグ中に **Esc** を押すか右クリックすると、キャンセルします。キャンセルすると、元のキーを復元します。

- 細かく動かすには、ドラッグ中に **Shift** を押したままにします。
- ツールのステップにスナップするには、ドラッグ中に **Ctrl** を押したままにします。

ドラッグ中に正確な値を指定するには:

1. 数値を入力します。

2. **Enter** を押して適用します。

**目盛り** は、スライダートラック上のプリセットです。ドラッグすると、近くの目盛りにスナップします。プリセットの正確な値を適用するには、その目盛りをクリックします。

インラインスライダーの右端の数値から、正確な値の入力欄を開けます。ツールの既定値を適用するには、**R** を押します。

**ポップアウトスライダー** は、列に名前を表示します。ドラッグとクリックでは、異なるポップアウトモードが開きます。

一時的にポップアウトを開くには:

1. 名前をドラッグしてスライダーを開きます。

2. ポインターのボタンを離して、変更を適用します。

ポップアウトを開いたままにするには:

1. 名前を1回クリックします。

2. トラックをドラッグして、変更をプレビューします。

3. ダブルクリックまたは他の場所のクリックで、変更を適用します。

ポップアウトでの変更をキャンセルするには、**Esc** を押します。

ツールの **アニメーションツール設定** を開くには、そのツールを右クリックします。

数値スライダーは、ブレイクダウン、滑らかにする、隣接要素、参照へ、イーズ、増幅、タイミング倍率、タイミングオフセット、リップル、削減の10個です。

- **ブレイクダウン** は、前と次のポーズの間をブレンドします。0%未満または100%を超える値では、そのポーズの範囲を越えます。
- **タイミング倍率** は、キーの間隔を変更します。100%未満ではキーが近づき、再生が速くなります。100%を超えるとキーが離れ、再生が遅くなります。**タイミングオフセット** は、アクティブオブジェクトのアクションを時間方向にずらします。
- **リップル** は、再生ヘッドより後のキーを、選択したフレーム数だけ移動します。前のフレームへ動かす場合は、再生ヘッドの1フレーム後で止まります。
- **削減** は、カーブの変化が指定した許容差未満に収まる場合に、キーを除去します。プレビュー中にキーが消えます。**Esc** を押すと復元します。
- **参照へ** は、参照フレームの値に近づけます。**参照を設定** は、そのフレームを保存します。**増幅** は、その参照を基準に動きの大きさを変えます。

タイミングオフセットなどのアクション全体に対するツールは、選択キー以外にも影響します。アクション全体を変更する前に、マウスを重ねたときの説明とシーンのオプションを確認してください。

### 既定の行

各行には、決まった既定のツールセットがあります。以下は、作業順に沿った、左から右への操作項目の一覧です。

- **すべて:** 最初はブレイクダウンスライダーで、25、50、75%の目盛りがあります。次に、-1f/+1f の微調整アイコンとタイミング倍率のポップアウトが並びます。続いて「滑らかにする」スライダーがあり、その後にコピー、貼り付け、選択中の項目をミラー反転、オブジェクトをベイク、トレイルのアイコンが、この順に並びます。トレイルの目のアイコンは、ワールド空間のモーショントレイルを表示または非表示にします。

![「すべて」の行、左側の詳細。上の全体図で、検索と設定の位置を確認できます。現在のローカライズ版の実画面。Anim Assist 12.11.2、Bforartists 5.2.3（API 5.3.0 Alpha）、撮影日 2026-11-20、表示言語 ja_JP。](images/ja/12.10.0-all-row-left.png)

### 行に表示する内容を変更する

1. 行の右端にある **設定** をクリックします。

2. **行** で、**すべて**、**ブロッキング**、**スプライン**、**仕上げ**、**納品** のいずれかを選択します。

3. 分類の見出しをクリックして、そのツールを開きます。

4. 各ツールの **表示** モードを選択します。

5. アイコンがあるツールでは、**ラベルまたはアイコン** を選択します。

6. インラインスライダーでは、代わりに2つ目の欄で **幅** を設定します。

7. 分類内でツールを動かすには、**上下の矢印** をクリックします。

8. アニメーションツール設定を開くには、そのツールの **歯車** をクリックします。

9. パネルの外をクリックするか、**Esc** を押して閉じます。

通常のツールには、非表示とボタンの表示モードがあります。非表示は、ツールを行から除去します。スライダーには、ポップアウトスライダーとインラインスライダーもあります。

**ツールバー設定** は、現在の行で開きます。編集中は **行** の選択で、別の行をプレビューできます。各分類の見出しには、表示中のツール数があります。作業段階を開くと、最初はその作業段階の主要な分類が開きます。名前で絞り込むには、分類の上の **ツールを検索** を使います。

変更は、すぐに表示されます。パネルの外のクリックや Esc で閉じても、変更は保持されます。パネルに OK ボタンはありません。**変更を元に戻す** は、すべての行を、パネルを開いたときの状態に戻します。どの行にも、どのツールでも配置できます。別の分類のツールを追加すると、その分類のボタンも行に追加されます。

アイコン表示は、キータイプ、ハンドルタイプ、選択の拡張、-1f/+1f、中割り、分配、スプラインに変換、ステップ補間に変換、参照を設定、コピー、貼り付けに対応します。選択中の項目をミラー反転、アクティブをミラー反転、反対側を選択、入れ替え、オブジェクトをベイク、4種類のプロキシ、トレイルにも対応します。他のツールは名前を表示します。

歯車、または行のツールの右クリックで **アニメーションツール設定** を開きます。このパネルは、表示、範囲、既定値、幅、精度、ドラッグ感度、スナップ、プリセット、**プリセットを目盛りで表示** を設定します。**カスタム範囲／オーバーシュート** は、ツールの制限内で独自の範囲を指定できます。

各作業段階は、それぞれの表示、ラベル、プリセット、目盛りを保存します。他の値は、全行で共有します。マスク、対象、ブレイクダウンの基準点は、シーン設定に保存します。**シーンツールのオプション** は、その設定を開きます。

| スライダーの幅 | 80～240論理ピクセル。狭い行では、描画するトラックが短くなることがあります。 |
| 精度 | 小数点以下0～4桁。 |
| 感度 | ポップアウトスライダーの範囲全体に対して10～2,000ピクセル。 |
| プリセット一覧 | 許可された範囲内の有限な値を、最大12個。 |
| ブレイクダウンのカスタム範囲 | -100%～200%。 |
| タイミング倍率のカスタム範囲 | 最小1%。 |
| リップルのカスタム範囲 | -500～500フレーム。 |
| 削減のカスタム範囲 | 許容差の単位で0～1。 |

表示される標準範囲は、許可されたカスタム範囲より狭い場合があります。これらのツールバー設定の制限は、制作リグに推奨する許容差を示すものではありません。

### レイアウトを保存、読み込み、リセットする

レイアウトは、「すべて」と4つの作業段階の全行を含みます。

| 操作項目 | 結果 |
|---|---|
| **名前を付けて保存** | 現在のレイアウトに名前を付けて保存します。 |
| **読み込み** | 保存済みのレイアウトを復元します。 |
| **保存済みレイアウトを更新** | 保存済みのレイアウトを、現在の行で置き換えます。 |
| **名前を変更** と **削除** | 保存済みレイアウトの名前を変更、または削除します。 |
| **推奨** | 固定の組み込みレイアウトを示します。 |
| **ブロッキング を初期設定に戻す** | その作業段階の既定のツールセットを復元します。操作名は、編集中の行に合わせて変わります。 |
| **推奨レイアウトを復元** | 「すべて」と全作業段階を復元します。保存済みレイアウトは、そのまま使用できます。 |

レイアウトは、アドオンのプリファレンスに保存します。すべてのタイムラインに適用されます。

プリファレンスを自動保存しない場合は、ツールバー設定の **プリファレンスを保存** をクリックします。これで、再起動後も変更を保持します。

保存済みレイアウト名は、1～64文字です。ライブラリは、最大100個の保存済みレイアウトに対応します。レイアウトの読み込みは、作業中の配置を置き換えます。変更した配置を置き換える前に、未保存の変更に関する操作項目を確認してください。

各作業段階は、決まった既定のツールセットから始まります。「すべて」にツールを追加しても、作業段階には追加されません。必要な各作業段階へ、別々に追加してください。アドオンのプリファレンスに、作業段階の操作項目はありません。各ワークスペースでは、行の作業段階ボタンを使います。

上の **ツールバー設定** の図は、保存済みレイアウトの操作項目を示します。同じパネルで、行の設定とレイアウトの管理を行います。

### マウスを重ねたときの説明とショートカット

操作項目の説明を見るには、約0.5秒間ポインターを重ねます。**マウスを重ねたときの説明** は、ヘルプの量を設定します。場所は、編集 > プリファレンス > アドオン > Anim Assist > 一般です。

マウスを重ねたときのヘルプ、作業段階の選択肢、スライダーのポップアウトは、ツールバーボタンの上に表示されます。タイムラインは、ポインターの下に Anim Assist のツールチップを1つ表示します。ツールバーのヘルプは、列の下にあるシーンストリップギズモより優先します。

- **詳細:** ツールの機能、対象範囲、必要条件、使い方を説明します。
- **短い:** 名前と1行の説明を表示します。灰色のツールでは、その理由も表示します。
- **オフ:** 列に Anim Assist のマウスを重ねたときの説明を表示しません。Anim Assist のパネルやメニュー内の標準 Bforartists ボタンでは、引き続きツール名を表示します。Bforartists は、そこに必ず説明の行を表示します。設定欄は、それぞれの1行のツールチップを保持します。

すべてのツールチップを無効にするには、**編集 > プリファレンス > インターフェイス > ツールチップ** を使います。

マウスを重ねたときの説明には、キーの割り当てが存在する場合だけ、ショートカットを表示します。

- **ショートカット:** その Anim Assist ツール自体に割り当てたキーです。行のツールに、既定のショートカットはありません。ここにショートカットを表示するには、**編集 > プリファレンス > キーマップ** で割り当てます。
- **Bforartists のキー:** 同じ機能の標準コマンドを実行するキーです。ドープシートの既定では、コピーが **Ctrl C**、貼り付けが **Ctrl V** です。**A** は全キーを選択します。**Ctrl Numpad +** は、選択を両側に拡張します。**R** はキーのタイミングを拡大縮小します。**W** はキーを時間方向に移動します。標準コマンドは、Anim Assist のツールと動作が異なることがあります。標準の貼り付けは、コピーした時刻ではなく、再生ヘッドを使います。

![「滑らかにする」にマウスを重ねたときの詳細な説明。選択中のキーを、その前後のキーの平均値に近づけます。選択された編集可能なカーブ内の選択キーが対象です。エディターでカーブが選択されていない場合は、アクティブオブジェクトのアクション内の選択キーを使います。ドラッグでプレビューし、ボタンを放すと適用します。Esc でキャンセルし、右クリックでツール設定を開きます。現在のローカライズ版の実画面。Anim Assist 12.11.2、Bforartists 5.2.3（API 5.3.0 Alpha）、撮影日 2026-11-20、表示言語 ja_JP。](images/ja/12.10.0-hover-explanation.png)

## ドープシート: ポーズとキーのタイミング

概要には、表示中の所有者、編集可能なカーブ、選択中のキーの数を表示します。すべて／なしの選択操作もあります。**ブロッキングと中割り** は、最初から開いています。他のグループは、**タイミング、キーとチャンネル、ポーズと一致、ベイクと仕上げ、クイックシェルフ** です。

1. アニメーションのあるオブジェクト、またはポーズボーンを選択します。

2. アクションのチャンネルを表示します。

3. 編集するキーを選択します。

4. ブレイクダウンの割合、中割り、ドラッグのツールには、**ブロッキングと中割り** を使います。

5. マスク、プリセット、サンプリングの選択肢には、**ブロッキングと中割り** のオプションを展開します。

6. 間隔、オフセット、リップルには、**タイミング** を使います。

7. 選択、キーの管理、メタデータには、**キーとチャンネル** を使います。

8. 一致とミラー反転には、**ポーズと一致** を使います。

9. ベイクと診断のツールには、**ベイクと仕上げ** を使います。

ハンドルの左右を選択するには、グラフエディターを使います。ドープシートでも、高度なハンドルタイプは使用できます。マクロの作成とセットアップは、プロパティのシーンにあります。

### ブレイクダウンの基準点

キーのないフレームでは、前後のキーがブレンドの基準点になります。たとえば、値が0と10なら、50%で5になります。

再生ヘッドの位置にすでにキーがある場合、そのキーが前の基準点になります。現在の値が5、次の値が10なら、50%で7.5になります。操作を繰り返すと、既存のキーがさらに変わることがあります。

ブレイクダウンを適用する前に、再生ヘッド、キー、マスクを確認してください。

## グラフエディター: カーブの整形

**カーブを整形** は、直接の整形、補間、ハンドルの操作を表示して、最初から開いています。グループは、**選択とチャンネル、カーブを整形、タイミングを調整、クリーンアップ、ポーズとベイク、クイックシェルフ** です。**選択とチャンネル** には、ハンドルの選択があります。**クリーンアップ** には、キーの管理と診断があります。**ポーズとベイク** には、一致、ミラー反転、ブレイクダウン、ベイクがあります。その中で折りたたまれている **ブレイクダウンのオプション** は、ブレイクダウンのサンプリングを設定します。カーブ全般の補間設定ではありません。

1. 表示中で編集可能なアクションキーを選択します。

2. 整形または補間の操作を適用します。

3. 結果のカーブとビューポートを確認します。

選択キーの補間は、選択済み、編集可能、表示中という条件を満たすキーだけに影響します。キー管理のタイミング操作は、エディターでの表示状態とチャンネルのロックに従います。**キーを移動** と **フレームを挿入** は、すぐに実行します。値を調整するには、標準の **最後の操作を調整** を使います。

アクションの選択補助は、**オブジェクトのアクション** に対応します。対象範囲が空でも、アクティブアクション全体から選択することはありません。所有者から切り離されてピン留めされたアクションや、オブジェクト以外のソースは除外します。サイドバーに、これらの除外の説明があります。アクション全体に対するツールを使う前に、その説明を確認してください。

![グラフエディターのカーブ整形ツール。表示中のカーブは、ほぼ値0の水平な形です。概要には、表示中の所有者1件、選択中のキー6個、編集可能なカーブ3本が表示されています。展開した「カーブを整形」には、整形、補間、ハンドルの操作があります。カーブを編集した結果を示す図ではありません。現在のローカライズ版の実画面。Anim Assist 12.11.2、Bforartists 5.2.3（API 5.3.0 Alpha）、撮影日 2026-11-20、表示言語 ja_JP。](images/ja/12.8.0-graph-tools.png)

## ドライバー: 応答を確認して整える

ドライバーのツールには、グラフエディターを **ドライバー** モードに切り替えます。**Anim Assist** のサイドバーとヘッダーメニューに、ドライバー専用の4つのセクションを表示します。アクションカーブに戻すと、上記のアクショングループに戻ります。ドライバーモードでは、アクションキーのツールの代わりに、ドライバーチャンネルを使います。

<a id="driver--target"></a>

### ドライバーと対象

このセクションは、選択中で表示中のドライバー数を示します。アクティブなドライバーには、**所有者**、**プロパティ**、**現在の値** も表示します。該当する場合は、**配列インデックス** も表示します。プロパティを解決できない場合は、警告します。

1. チャンネル一覧で、表示中のドライバーチャンネルを選択します。

2. **ドライバーと対象** で、所有者と駆動先プロパティを確認します。

3. **選択部分を表示** をクリックして、選択したカーブが収まる表示にします。

4. ドライバーの表示全体を見るには、**全体を表示** をクリックします。

**すべてのチャンネル** と **なし** は、チャンネルの選択を変更します。**所有者を選択** は、ドライバーを所有するオブジェクトをアクティブにします。他の選択オブジェクトは、選択を保持します。所有者は、現在のビューレイヤーに属し、表示中のオブジェクトとして選択可能である必要があります。他のデータブロック上のドライバーでは、このオブジェクト選択操作は使えません。

所有者が編集可能なら、**ミュート中** と **ロック中** で、アクティブなドライバーの標準チャンネル設定を変更できます。選択中で表示中のドライバーが1つなら、ロック後も確認できます。解除するには、**ロック中** を無効にします。選択チャンネルが複数あり、アクティブなドライバーが曖昧な場合は、目的のチャンネルを明示的に選択してください。

選択が空でも、4つのセクションはすべて表示され、案内を示します。ドライバーは作成しません。

これらのセクションを使う前に:

1. Bforartists の標準の手順でドライバーを作成します。

2. そのドライバーを接続します。

![選択中のドライバーと応答の操作項目。所有者は Empty、プロパティは scale、配列インデックスは0で、現在の値は1です。チャンネルのロックは解除されています。応答点が選択されていないため、「補間」と「ハンドル」は淡色で表示されています。省略表示された選択欄の名称は「モディファイアーを追加（アクティブなドライバー）」です。アクティブで編集可能なドライバーにモディファイアーを追加するための欄で、この図では追加も応答カーブの編集も行っていません。現在のローカライズ版の実画面。Anim Assist 12.11.2、Bforartists 5.2.3（API 5.3.0 Alpha）、撮影日 2026-11-21、表示言語 ja_JP。](images/ja/12.11.0-selected-driver.png)

### 変数と式

このセクションは、変数の数を示します。スクリプト式のドライバーには **式** を表示します。他のドライバータイプには **種類** を表示します。標準の **ドライバー** タブには、編集可能な変数と式の全設定があります。

1. 目的のドライバーチャンネルのロックを解除します。

2. そのチャンネルをクリックし、標準機能で編集可能なアクティブドライバーにします。

3. **変数と式** を開きます。

4. **ドライバー設定を開く** をクリックします。

5. 標準の **ドライバー** タブで、変数、対象、ドライバータイプ、式を編集します。

6. 応答操作と診断には、**Anim Assist** に戻ります。

このボタンは、標準のサイドバーカテゴリーを開きます。設定ダイアログを別に複製して開くものではありません。ロック中のドライバーは、標準設定が編集可能にならなくても、確認用として表示を維持できます。標準のサイドバータブは、順序が変わる場合があります。**ドライバー**、**モディファイアー**、**Anim Assist** を名前で識別してください。

### 応答カーブ

横軸はドライバー入力、縦軸は駆動出力です。応答点は、入力と出力を対応させます。アニメーション時刻を使うアクションキーとは異なります。

1. 編集する、表示中のドライバーチャンネルを選択します。

2. そのチャンネルのロックを解除します。

3. 所有者が編集可能なことを確認します。

4. 点単位で変更するには、応答点またはハンドルの左右を選択します。

5. **応答カーブ** で **補間** または **ハンドル** を選択します。

6. 結果の応答と駆動先プロパティを確認します。

| 操作項目 | 対象範囲と結果 |
|---|---|
| **補間** | 選択中で表示中、かつ編集可能なドライバーチャンネル内の、選択した応答点を変更します。選択肢は、一定、リニア、ベジェです。 |
| **ハンドル** | 同じチャンネル内の、選択した側のハンドルを変更します。制御点を選択している場合は、両側のハンドルを変更します。 |
| **外挿** | 選択中で表示中、かつ編集可能なドライバーチャンネルの、両端より外の範囲を変更します。一定は出力を保持し、リニアは端の傾きを延長します。 |
| **モディファイアーを追加（アクティブなドライバー）** | 選んだ応答モディファイアーを、アクティブで編集可能なドライバーだけに追加します。選択した全チャンネルには適用しません。 |
| **モディファイアー設定を開く** | アクティブなドライバーの、標準の **モディファイアー** タブを開きます。 |

点の操作には、選択した点またはハンドルが必要です。外挿には、選択済みの編集可能なチャンネルが必要です。モディファイアーの操作には、所有者が編集可能で、ロックされていないアクティブドライバーが必要です。標準設定を開く場合も、標準機能でアクティブになっている、編集可能なドライバーが必要です。操作項目が無効なら、マウスを重ねて必要条件を確認してください。

補間、ハンドル、外挿、モディファイアーの作成は、標準の **元に戻す** と **最後の操作を調整** に対応します。これらの操作は、指定されたドライバーだけに影響します。アクションキーや無関係なドライバーは除外します。動作検証は、すべての標準モディファイアータイプを個別に検証したものではありません。

### 診断情報

3. **選択中のドライバーを確認** をクリックします。

4. 結果のポップアップを読みます。

5. 報告された対象、パス、ボーン、式を、対応する標準設定で修正します。

## NLA: クリップの配置と補正のブレンド

**配置とタイミング** と **ブレンドと補正** は、最初から開いています。**アクションとトラック、ベイクと仕上げ、クイックシェルフ** は、閉じた状態から始まります。概要には、所有者、アクティブクリップ、ソースアクション、選択クリップ数、シーン範囲、ソース範囲を表示します。シーンのフレームは、クリップの位置を示します。ソースのフレームは、クリップ内で使うアクションの区間を示します。

<a id="arrange-clips"></a>

### クリップを配置する

1. 変更するアクションクリップを選択します。

2. 基準にするクリップの本体をクリックして、アクティブにします。

3. 基準クリップが選択されたままか確認します。

4. 微調整には **-1f/+1f**、標準の移動には **選択中のクリップを移動** をクリックします。

5. アクティブな選択クリップに揃えるには、**Align Starts to Active Clip / Align Ends to Active Clip** を使います。

6. 基準クリップの開始位置から連続して並べるには、**クリップを順に並べる** を使います。

7. **最後の操作を調整** で、ステップまたは並べる間隔を変更します。

8. アクティブクリップのスケール、繰り返し、反転、シーン開始／終了には、**タイミング設定** を展開します。

タイミングは、シーンのフレームを使います。ロックされたクリップや重なりのある一括操作は、一部だけ変更せずに拒否します。ソース編集中は、配置を一時停止します。これらのツールは、トランジション、メタ、サウンドのストリップを編集できません。

![NLA の登録済み補正パネルのポップオーバー。補正クリップは「合成」ブレンドと、アニメーション付きの影響度を使います。フレーム12では影響度0.500にキーがあり、0%、50%、100%の操作項目が表示されています。英語の「Blend Options」は「ブレンドのオプション」を意味する現在のソースの未翻訳ラベルです。NLA エディター全体や影響度の変化を示す図ではありません。現在のローカライズ版の実画面。Anim Assist 12.11.2、Bforartists 5.2.3（API 5.3.0 Alpha）、撮影日 2026-11-20、表示言語 ja_JP。](images/ja/12.8.0-nla-arrange.png)

アクティブクリップの操作を使う前に、概要にそのクリップの所有者、クリップ、アクションが表示されているか確認してください。

### ソースを編集して共有を管理する

**アクションを編集** は、標準の NLA の調整モードに入ります。**ドープシートを開く／グラフエディターを開く** は、適切なピン留めされていないエディターを再利用するか、現在の領域を切り替えます。標準の調整モードは、移動、拡大縮小、繰り返し、反転したクリップのソース時刻を対応させます。

編集後に配置へ戻るには:

1. エディター選択から NLA に戻ります。

2. **編集を終了** をクリックします。

共有アクションを編集すると、他のクリップにも影響することがあります。概要には、共有の警告と、除外したソースを表示します。ミュートとソロは、評価に影響します。

| 操作項目 | 結果 |
|---|---|
| **選択中のクリップを独立させる** | 選択したクリップのソースアクションを分離します。 |
| **独立して複製** | アクションをコピーします。 |
| **リンク複製** | アクションを共有します。 |
| **選択中のトラックを上へ移動／下へ移動** | トラックの順序を変更します。クリップを別のトラックへ移動するものではありません。 |

**Push Down Active Action/Stash Active Action** は、アクティブな所有者に割り当てられたアクションを操作します。押し下げには、NLA 評価の有効化が必要です。クリップが未選択の場合、編集可能なアクティブオブジェクトに対して、概要に **既存のアクションをクリップとして追加** を表示します。

![アクションとトラックのポップオーバー。Manual Source トラックのクリップが選択され、複製と「選択中のクリップを独立させる」が表示されています。「Push Down Active Action」はアクティブアクションをNLAトラックに押し下げる操作、「Stash Active Action」はアクティブアクションを退避する操作を意味します。これらは現在のソースで英語のまま表示され、この場面では無効です。現在のローカライズ版の実画面。Anim Assist 12.11.2、Bforartists 5.2.3（API 5.3.0 Alpha）、撮影日 2026-11-20、表示言語 ja_JP。](images/ja/12.11.1-nla-actions.png)

### トランスフォーム補正を追加する

1. 対応するソースアクションクリップを1つ選択します。

2. **新しいトランスフォーム補正** をクリックします。

3. 新しい補正クリップを選択します。

4. **補正を編集** をクリックします。

5. 標準の調整モードで、トランスフォームのキーを編集します。

6. 編集後は **編集を終了** をクリックします。

7. 変更しないチャンネルは、位置0、回転0／単位回転、スケール1の中立値に保ちます。

8. 再生ヘッドの位置で **0%、50%、100%** のいずれかをクリックし、アクティブクリップの影響度にキーを挿入します。

標準の **合成** ブレンドは、ソースの動きに補正を重ねます。他の影響度を使うには、**最後の操作を調整** に入力します。影響度が0なら、補正は動きに影響しません。

作成時は、ソースの上に、独立した補正アクションとトラックを追加します。補正は、オブジェクトとポーズボーンのトランスフォームに対応します。コンストレイントやドライバーを使うリグ、解決できないボーン、トランスフォーム以外のソースチャンネルがある場合は、作成を阻止し、理由を説明します。この補正は、プロパティのシーンにある一般的なアニメーションレイヤーツールとは別です。

ブレンドとアニメーション付きの影響度は、標準のストリップ設定です。アニメーション付きの影響度が無効なら、サイドバーは自動ブレンドのエンベロープであることを示します。**Blend Options** には、自動ブレンド、ブレンドイン／アウト、外挿があります。影響度ボタンは、標準の影響度キーを作成します。ソースアクションのポーズキーは作成しません。

上の **NLA の配置と補正の操作項目** の図は、補正トラック、**補正を編集**、**合成** ブレンド、影響度ボタンを示します。

### ソースのスタックを保持してベイクする

1. ベイクする所有者のクリップを選択します。

2. **ベイクと仕上げ** を開きます。

3. 表示された所有者とシーン範囲を確認します。

4. **新規アクションにベイク** をクリックします。

5. 必要なら、**最後の操作を調整** で範囲とステップを調整します。

6. 出力名と範囲を確認します。

7. ベイクを有効にする前に、再び適用されるアクティブなコンストレイントをミュートまたは除去します。

8. **最新のベイクを使用（NLA オフ）** を選択します。

ベイクは、評価済みのオブジェクト／ポーズのトランスフォームを新しいアクションに書き込み、保持します。新しいアクションは、最初は **未割り当て** です。元のアクション、クリップ、親、コンストレイントは残ります。ベイクの有効化は、別の操作です。**最新のベイクを使用（NLA オフ）** は、結果を割り当て、ソーススタックの評価を無効にします。

比較用にソースのシーンを保存してください。名前を変更しても、出力の所有者は変わりません。別のオブジェクトが古い名前を引き継いでも、その出力は受け取れません。**空のトラックを除去** は、空のトラックを別の操作で除去します。

NLA のクイックシェルフのショートカットは、ソースの独立化、アクティブソースの編集、所有者のベイクを行います。ストリップに対して、一般的なキー編集マクロは実行しません。

### ロケーター、プロキシ、ベイクセッション

1. **リグ > プロキシとベイク** を開きます。

2. 目的のオブジェクトを選択します。

3. ロケーター、または移動、向き、ワールド空間、親空間のプロキシを選択します。

4. 選んだベイクコマンドの範囲を設定します。

5. ベイクのステップを設定します。

6. ベイクするチャンネルを選択します。

7. ベイクコマンドを実行します。

8. ベイクした動きを確認します。

9. ベイク結果を確認してから、セッションの後片付けを使います。

ロケーターの操作項目は、対象、選択対象の平均位置、カーソルにロケーターを作成します。ロケーターと対象の間で、親子関係、コンストレイント、一致、ベイクも行います。対になった操作項目を使う前に、矢印の向きを確認してください。

**スマートベイク** は、トランスフォームのベイクとキーの削減を組み合わせます。**キーを削減** は、許容差に従って既存のキーを簡略化します。使用できる範囲は、シーン、アクション、カスタム、選択キー、プレビューです。これらの一般的なベイクコマンドは、ソースを保持する NLA の **新規アクションにベイク** の手順とは異なります。

**ワンクリックでプロキシとベイク** は、ベイク前に、専用のプロキシセッションへワールド空間の動きを記録します。**セッションをベイクしてプロキシを除去** は、そのセッションを後片付けします。**すべてのプロキシセッションを除去** は、より広い範囲に影響します。既存の検証記録は、親やコンストレイントがあるすべての場合や、すべての制作リグを認証するものではありません。補助オブジェクトを除去する前に、結果を比較してください。

### アニメーションレイヤー

1. **アニメーション全体 > アニメーションレイヤー** を開きます。

2. レイヤーシステムを有効にします。

3. 現在のアニメーションに **ベースレイヤーを作成** をクリックします。

4. 作業用レイヤーを追加します。

5. 作業用レイヤーを選択します。

6. ブレンドモードを選択します。

7. ウェイトを設定します。

8. ボーンの割り当てを設定します。

9. キーを挿入する前に、目的の作業用レイヤーを選択します。

10. レイヤーのソロ、ミュート、ロックでプレビューします。

割り当て一覧が空の場合は、すべてのボーンを含みます。ポーズモードでは、表示パネルに、ボーン割り当て用の **割り当て**、**除去**、**選択** があります。各レイヤー行には、ウェイト、ソロ、ミュート、ロック、自動キーがあります。

### リップシンク

1. **顔 > リップシンク** を開きます。

2. リップシンクを有効にします。

3. **+** でリップシンクレイヤーを追加します。

4. レイヤーを選択します。

5. **音声** に **WAV** ファイルを関連付けます。

6. 対象に **シェイプキー**、**ボーン**、**両方** のいずれかを選択します。

7. メッシュまたはアーマチュアの対象を選択します。

8. 選択したビジームライブラリの **シェイプキーの割り当て** または **ボーンリグの接続** を設定します。

9. 接続項目の対象名を確認します。

10. 予備動作（音声より先行するフレーム数）、フレームオフセット、解析バックエンドを確認します。

11. **ベイク** をクリックします。

12. 口の動きを確認します。

**再ベイク** の前に、**選択中のキーをロック** で、選択した手作業の編集を保持します。

**ライブプレビュー／ベイク済み** は、レイヤーの状態を示します。シェイプキー出力には、接続済みシェイプキーのあるメッシュが必要です。ボーン出力には、有効なアニメーションレイヤー、アーマチュア、接続設定が必要です。**自動入力** は、接続項目を用意します。**ビジームキャプチャ > 記録** は、カスタムポーズを保存します。

必要なプレビューまたはベイク済みの手順に合わせて、状態の操作項目を使います。

振幅解析には、外部の音素解析実行ファイルは不要です。任意の Rhubarb 解析には、設定済みの **Rhubarb のパス** が必要です。出力に頼る前に、バックエンドの代替処理とレイヤー欠落の報告を確認してください。スピーカーストリップがある場合、スピーカーオーバーレイはドープシート／タイムラインに音声を表示します。

サイドバーの **消去** は、自動出力を除去し、手動編集としてマークした内容を保持します。**再ベイク** も、手動で上書きした内容を保持します。**手動キーを強調表示** は、保護した編集を示します。音声を変更すると、レイヤーは再生成が必要な状態になります。再ベイクする前に、報告された WAV、対象、レイヤーの問題を解決してください。

## トラブルシューティングと検証の限界

キー操作で何も起きない場合:

1. アクティブなエディターを確認します。

2. 編集可能な選択キーと、表示中のチャンネルを確認します。

3. ロック、所有者、アクションを確認します。

4. アクションデータとエディターのフィルターを確認します。

ツールバーが見えるだけでは、操作でキーを挿入したことは証明できません。メッシュ／オブジェクトの通常のキー挿入には、引き続き標準のキーフレーム挿入を使います。

問題の報告には、アドオンのバージョン、Bforartists のビルド、正確なコマンド、再現できる小さなシーンを含めてください。

NLA の操作が使えない場合:

1. トラックのロックと、ミュート／ソロによる除外を確認します。

2. アクションの欠落、NLA 評価の無効化、調整モードの使用中ではないか確認します。

3. クリップを配置する前に、**編集を終了** をクリックします。

4. 補正を作成する場合は、未対応のリグ／チャンネルの説明を読みます。

タイミングの変更やベイクの後は:

1. 動きを確認します。

2. 必要なら、標準の「元に戻す」を使います。

3. シーンを保存します。

4. 結果に頼る前に、シーンを開き直します。

ドライバー設定が使えない場合は、ロックされていないドライバーチャンネルを選択し、標準機能でアクティブにします。ロック中のドライバーも、確認やロック解除のために表示を維持できます。複数の選択ドライバーからアクティブな対象を明確に決められない場合、ツールは1つを勝手に選びません。点の編集操作には、選択した応答点が必要です。

[12.11.1 リリースノート](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.11.1/RELEASE-NOTES.md)は、タイムラインの「元に戻す」の振り分け修正を説明します。[12.11.0 の検証記録](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.11.0/qualification.md)は、Bforartists 5.2.0 での対象を絞ったドライバーテストと、標準カーソルの観察を記録しています。チャンネルの対象範囲、標準設定への移動、モディファイアーの「元に戻す／やり直す」を含みます。レイアウト登録と、アニメーションエディターの11の回帰シナリオも記録しています。これらは以前のテスト結果です。マニュアル更新では、これらのテストを再実行していません。
