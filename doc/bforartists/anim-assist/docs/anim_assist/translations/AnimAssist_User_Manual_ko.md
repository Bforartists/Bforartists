# Anim Assist 12.11.2 후보 버전 사용 안내서

이 안내서는 로컬에서만 제공되는 미공개 Anim Assist 12.11.2 후보 버전을 다룹니다. 리비전 `7ec664d`의 사운드 스트립 설정 수정이 포함되어 있습니다. 공개 다운로드 버전은 여전히 12.11.1입니다. 2026년 11월 20일 검토에서는 소스와 문서를 확인했습니다.

릴리스 정보는 [현재 변경 기록](../../../../../../scripts/addons_core/B4_anim_assist/CHANGELOG.md)과 [문서 색인](../README.md)을 참조하세요.

각 스크린샷은 관련 설명 옆에 배치되어 있습니다. 각 그림 설명에는 캡처 버전 또는 기록된 검증 날짜가 표시됩니다. 이전 스크린샷은 컨트롤의 위치를 보여 줍니다. 새 인수 테스트의 결과를 기록한 것은 아닙니다.

영문 원본 안내서의 패널 그림 대부분은 Blender 5.4 Alpha 기반의 제공된 Bforartists 5.2.3 빌드에서 실행한 Anim Assist 12.11.1을 보여 줍니다. 여기에 Blender 5.3 Alpha 기반의 공식 Bforartists 5.2.3에서 캡처한 12.11.2 후보 버전의 립싱크 그림이 포함되어 있습니다. 이 한국어판은 로컬의 미공개 12.11.2 후보 버전을 새로 캡처한 기본 UI 스크린샷을 사용하며, 각 그림 설명에 캡처 환경과 검증 범위의 한계를 명시합니다. 기본 패널 팝오버에서 등록된 컨트롤을 명확히 볼 수 있습니다. 도구를 사용하려면 아래 설명에 따라 해당 편집기의 도구 영역을 여세요.

포즈와 타이밍에는 도프 시트를 사용하세요. 액션 곡선이나 드라이버에는 그래프 에디터를 사용하세요. 클립과 보정에는 NLA Editor를 사용하세요. 도움말 컨트롤에서 각 도구의 설명을 확인할 수 있습니다. 이 안내서는 한국어 컨트롤 이름을 사용합니다. 아직 대조가 필요한 일부 컨트롤과 호스트 항목의 이름은 영어로 남겨 두었습니다.

### 독립형 애드온 설치

1. [공개된 12.11.1 애드온 ZIP](https://raw.githubusercontent.com/Axleonex/B4Artists_Toolkit/main/releases/b4_anim_assist_v12.11.1.zip)을 다운로드하세요.

2. Bforartists에서 **편집 > 환경 설정 > 애드온 > 디스크에서 설치**를 여세요.

3. ZIP을 선택하세요.

4. **Anim Assist**를 활성화하세요.

5. 업데이트 후 Bforartists를 다시 시작하세요.

독립형 패키지 이름은 `B4_anim_assist`입니다. 설치할 때 ZIP의 압축을 풀지 마세요.

다음 그림은 제공된 빌드에 포함된 항목을 보여 줍니다. 독립형 사본을 설치하려면 위의 ZIP 설치 절차를 따르세요.

### 제안된 내장 통합 사용

제공된 커스텀/네이티브 테스트 빌드에는 Anim Assist가 포함되어 있습니다. 초기 환경설정에서 애드온이 활성화됩니다. 이 통합안에는 별도의 ZIP 설치가 필요하지 않습니다. 이 설명은 공식 Bforartists 릴리스에 Anim Assist가 포함되어 있음을 의미하지 않습니다.

1. 제공된 커스텀 빌드를 시작하세요.

2. 아래에 설명된 편집기 경로를 여세요.

3. 환경설정을 보려면 **편집 > 환경 설정 > 애드온 > Anim Assist**를 여세요.

번들 통합 위에 독립형 사본을 추가로 설치하지 마세요.

위의 환경설정 그림은 번들 항목을 보여 줍니다. 아래의 **장면 도구 영역** 및 **최초 실행 설정** 그림에서 설정 컨트롤의 위치를 확인할 수 있습니다.

### 편집기별 도구 영역 찾기

이전 실행 검증에서는 OpenGL을 사용하는 Blender 5.3.0 Alpha 기반의 기본 Bforartists 5.2.0, 빌드 `0a1ca45552db`를 사용했습니다. 이 과거 증거는 해당 호스트에 적용됩니다. 일반 Blender는 지원하지 않습니다. 이 결과가 다른 모든 호스트 빌드를 검증하는 것은 아닙니다.

- **타임라인:** Anim Assist 도구 행은 캔버스 하단에 표시됩니다. 아래의 **타임라인: 하단 도구 행**을 참조하세요. 재생 및 키프레임 컨트롤은 기본 헤더에 그대로 있습니다.
- **도프 시트, 그래프 에디터 및 NLA Editor:** 사이드바에 **Anim Assist** 탭이 있습니다. 기본 탭과의 상대적인 위치는 달라질 수 있습니다. 헤더의 **Anim Assist** 메뉴에서도 도구를 열 수 있습니다.
- **드라이버:** 그래프 에디터의 **드라이버** 모드에서는 **Anim Assist** 사이드바 탭과 헤더 메뉴가 드라이버 작업에 맞게 바뀝니다.
- **씬 프로퍼티스 > Anim Assist:** 캐릭터 설정, 전체 애니메이션 도구, 매크로, 설정 및 도움말이 있습니다. 3D 뷰포트 사이드바에는 Anim Assist 탭이 없습니다.

사이드바 도구를 열려면 다음과 같이 하세요.

1. 포인터를 도프 시트, 그래프 에디터 또는 NLA Editor 안으로 이동하세요.

2. N을 누르세요.

3. **Anim Assist** 탭을 선택하세요.

드라이버 작업을 하려면 그래프 에디터를 **드라이버** 모드로 전환하세요.

**씬 프로퍼티스 > Anim Assist > 설정(리그당 한 번) > 최초 실행 설정 실행**은 일반 퀵 셸프를 만듭니다. 설정에서는 작업공간도 추가할 수 있습니다. 선택 사항인 **Shift Alt D** 파이 메뉴는 처음에는 비활성화되어 있습니다. 활성화하거나 단축키를 바꾸려면 **설정**을 사용하세요.

## 타임라인: 하단 도구 행

도구 행은 타임라인 하단의 기본 가로 스크롤바 위에 표시됩니다. 헤더, 영역 또는 작업공간 분할을 추가하지 않습니다. 재생 및 키 입력 컨트롤은 기본 헤더에 그대로 있습니다. 행을 표시하거나 숨기려면 **타임라인 > 뷰 > Anim Assist 도구 행 표시**를 사용하세요.

버튼은 전체 높이와 그에 맞는 클릭 영역을 유지합니다. 크기를 조절해도 스크롤바 위에 공간을 확보합니다. 최소 높이보다 낮은 위치에서 구분선을 놓으면 타임라인이 도구 행에 필요한 높이를 복원합니다. 도구 모음은 기본 재생 헤드 및 키 선택 컨트롤보다 먼저 행의 클릭을 처리합니다. 키를 확인할 수 있도록 행 위에 충분한 높이를 남겨 두세요.

행에는 왼쪽부터 다음 컨트롤이 있습니다.

| 컨트롤 | 기능 |
|---|---|
| **단계 버튼** (예: 작은 화살표가 있는 **전체**) | 현재 단계를 표시하고 단계 목록을 엽니다. |
| **도구군 버튼** (트윈, 타이밍, 커브, 키, 포즈, 베이크, 동작) | 색상으로 구분된 이름을 누르면 해당 도구군의 전체 목록이 열립니다. 행에서는 각 도구군 이름 뒤에 소속 도구가 배치됩니다. |
| **도구** | 버튼, 아이콘 및 슬라이더로 도구를 실행합니다. 포인터를 올리면 각 도구의 설명을 볼 수 있습니다. |
| **+N** | 행에 들어가지 않는 N개 도구의 목록을 엽니다. |
| **도구 찾기** (돋보기) | 전체 96개 도구를 검색하거나 나열합니다. 각 결과에는 도구 실행 및 고정 컨트롤이 있습니다. |
| **설정** | 각 행을 구성하는 도구 모음 설정을 엽니다. |

1. 단계 버튼, 도구군 버튼 또는 **+N**을 클릭하여 목록을 여세요.

2. 항목을 클릭하여 사용하세요.

포인터를 다른 편집기 위로 이동해도 목록은 열린 상태를 유지합니다. 다른 도구군 버튼을 클릭하면 해당 도구군의 목록으로 바뀝니다.

목록을 닫으려면 같은 버튼을 다시 클릭하거나 다른 곳을 클릭하거나 **Esc**를 누르세요.

### 단계 선택

각 단계에는 애니메이션의 한 작업 단계에 필요한 도구가 있습니다.

- **전체:** 모든 도구군의 도구를 모아 보여 줍니다.
- **블로킹:** 포즈 블로킹을 위한 트윈 및 키 도구입니다.

- **스플라인:** 스플라인 작업과 호 궤적 확인을 위한 커브 및 동작 도구입니다.

- **다듬기:** 간격과 대칭을 다듬는 타이밍 및 포즈 도구입니다.

- **납품 준비:** 마무리와 내보내기를 위한 베이크 도구입니다.

단계를 바꾸려면 다음과 같이 하세요.

1. 행 왼쪽의 단계 버튼을 클릭하세요.

2. 그 위에 열린 목록에서 단계를 클릭하세요.

단계를 선택하면 목록이 닫힙니다. 타임라인의 높이가 낮으면 다섯 선택지가 사용 가능한 캔버스 안에서 한 행으로 표시됩니다.

**타임라인 > 뷰 > Anim Assist 작업 단계**에서도 단계를 선택할 수 있습니다.

휠로 단계를 이동하려면 다음과 같이 하세요.

1. 단계 버튼 위에서 **Ctrl**을 누른 상태로 유지하세요.

2. 휠을 스크롤하세요.

저장된 파일에서는 작업공간마다 각자의 단계가 유지됩니다.

### 도구 사용

버튼이나 아이콘을 클릭하면 도구가 실행됩니다. 키 유형 아이콘은 현재 테마의 도프 시트 키 색상을 사용합니다. 브레이크다운 마름모는 작고 익스트림 마름모는 큽니다. 핸들 아이콘은 그래프 에디터의 핸들 색상을 사용합니다.

1. 아이콘 위에 포인터를 올려 이름을 확인하세요.

2. 도구가 회색으로 표시되면 포인터를 올려 선택된 키 등 필요한 조건을 확인하세요.

3. 사용 가능한 버튼이나 아이콘을 클릭하여 도구를 실행하세요.

**인라인 슬라이더**는 행 안에 계속 표시됩니다. 드래그하지 않고 클릭만 하면 아무것도 바뀌지 않습니다.

1. 트랙을 드래그하여 변경 사항을 미리 보세요.

2. 포인터 버튼을 놓아 변경 사항을 적용하세요.

드래그 중 **Esc**를 누르거나 마우스 오른쪽 버튼을 클릭하면 취소됩니다. 취소하면 원래 키가 복원됩니다.

- 더 세밀하게 움직이려면 드래그 중 **Shift**를 누르세요.
- 도구의 증분 단위에 맞추려면 드래그 중 **Ctrl**을 누르세요.

드래그 중 정확한 값을 입력하려면 다음과 같이 하세요.

1. 숫자를 입력하세요.

2. **Enter**를 눌러 적용하세요.

**눈금**은 슬라이더 트랙에 표시된 프리셋입니다. 드래그하면 가까운 눈금에 스냅됩니다. 프리셋의 정확한 값을 적용하려면 해당 눈금을 클릭하세요.

인라인 슬라이더 오른쪽의 숫자를 클릭하면 정확한 값을 입력하는 필드가 열립니다. 도구의 기본값을 적용하려면 **R**을 누르세요.

**팝아웃 슬라이더**는 행에 이름으로 표시됩니다. 이름을 드래그할 때와 클릭할 때 서로 다른 팝아웃 모드가 열립니다.

임시 팝아웃을 사용하려면 다음과 같이 하세요.

1. 이름을 드래그하여 슬라이더를 여세요.

2. 포인터 버튼을 놓아 변경 사항을 적용하세요.

팝아웃을 열린 상태로 유지하려면 다음과 같이 하세요.

1. 이름을 한 번 클릭하세요.

2. 트랙을 드래그하여 변경 사항을 미리 보세요.

3. 두 번 클릭하거나 다른 곳을 클릭하여 변경 사항을 적용하세요.

팝아웃의 변경 사항을 취소하려면 **Esc**를 누르세요.

도구의 **애니메이션 도구 설정**을 열려면 도구를 마우스 오른쪽 버튼으로 클릭하세요.

숫자 슬라이더 10개는 브레이크다운, 부드럽게, 인접 항목, 참조 쪽으로, 이징, 증폭, 타이밍 스케일, 타이밍 오프셋, 리플 및 줄이기입니다.

- **브레이크다운**은 이전 포즈와 다음 포즈 사이를 블렌딩합니다. 0% 미만 또는 100% 초과 값은 두 포즈 바깥으로 확장합니다.
- **타이밍 스케일**은 키 간격을 바꿉니다. 100% 미만에서는 키가 가까워지고 재생이 빨라집니다. 100% 초과에서는 키가 멀어지고 재생이 느려집니다. **타이밍 오프셋**은 활성 오브젝트의 액션을 시간축에서 이동합니다.
- **리플**은 재생 헤드 뒤의 키를 선택한 프레임 수만큼 이동합니다. 앞쪽 프레임으로 이동할 때는 재생 헤드 다음 한 프레임에서 멈춥니다.
- **줄이기**는 곡선의 변화가 선택한 허용 오차 미만으로 유지되는 경우 키를 제거합니다. 미리보기 중 키가 사라집니다. **Esc**를 누르면 복원됩니다.
- **참조 쪽으로**는 기준 프레임 쪽으로 블렌딩합니다. **참조 설정**은 해당 프레임을 저장합니다. **증폭**은 그 기준을 중심으로 모션의 크기를 조절합니다.

타이밍 오프셋처럼 액션 전체에 적용되는 도구는 선택한 키 이외의 항목에도 영향을 줍니다. 전체 액션을 바꾸기 전에 마우스 오버 설명과 장면 옵션을 확인하세요.

### 도구 찾기와 더 보기

### 행에 표시할 항목 변경

1. 행 오른쪽의 **설정**을 클릭하세요.

2. **행**에서 **전체**, **블로킹**, **스플라인**, **다듬기** 또는 **납품 준비**를 선택하세요.

3. 도구군 헤더를 클릭하여 도구를 여세요.

4. 각 도구의 **표시** 모드를 선택하세요.

5. 아이콘이 있는 도구에서는 **레이블 / 아이콘**을 선택하세요.

6. 인라인 슬라이더에서는 대신 두 번째 필드의 **너비**를 설정하세요.

7. 도구군 안에서 도구를 이동하려면 **위아래 화살표**를 클릭하세요.

8. 도구의 애니메이션 도구 설정을 열려면 **톱니바퀴**를 클릭하세요.

9. 패널 밖을 클릭하거나 **Esc**를 눌러 닫으세요.

일반 도구에는 숨김 및 버튼 표시 모드가 있습니다. 숨김은 행에서 도구를 숨깁니다. 슬라이더에는 팝아웃 슬라이더 및 줄 안의 슬라이더 모드도 있습니다.

**도구 모음 설정**은 현재 행의 설정으로 열립니다. **행** 선택기를 사용하면 편집 중 다른 행을 미리 볼 수 있습니다. 각 도구군 헤더에는 표시 중인 도구 수가 나옵니다. 단계를 처음 열면 해당 단계의 기본 도구군이 펼쳐집니다. 이름으로 도구를 필터링하려면 도구군 위의 **도구 찾기**를 사용하세요.

변경 사항은 즉시 표시됩니다. 패널 밖을 클릭하거나 Esc로 닫아도 변경 사항은 유지됩니다. 이 패널에는 OK 버튼이 없습니다. **변경 사항 되돌리기**는 모든 행을 패널을 열었을 때의 상태로 복원합니다. 어느 행에나 모든 도구를 넣을 수 있습니다. 다른 도구군의 도구를 추가하면 그 도구군의 버튼도 행에 추가됩니다.

아이콘 표시는 키 유형, 핸들 유형, 선택 확장, -1f/+1f, 중간 키, 분배, 스플라인으로, 계단형으로, 참조 설정, 복사 및 붙여넣기를 지원합니다. 선택 항목 대칭, 활성 항목 대칭, 반대쪽 선택, 교환, 오브젝트 베이크, 네 가지 프록시 유형 및 동작 잔상도 지원합니다. 그 밖의 도구는 이름으로 표시됩니다.

톱니바퀴를 클릭하거나 행의 도구를 마우스 오른쪽 버튼으로 클릭하면 **애니메이션 도구 설정**이 열립니다. 이 패널에서는 표시 방식, 범위, 기본값, 너비, 정밀도, 드래그 민감도, 스냅, 프리셋 및 **프리셋을 눈금으로 표시**를 설정합니다. **사용자 지정 범위 / 오버슈트**에서는 도구의 제한 안에서 사용자 지정 범위를 설정할 수 있습니다.

각 단계는 표시 방식, 이름 표시, 프리셋 및 눈금을 따로 저장합니다. 나머지 수치는 모든 행에서 공유합니다. 장면 설정에는 마스크, 대상 및 브레이크다운 기준점이 저장됩니다. **씬 도구 옵션**으로 이 설정을 열 수 있습니다.

| 설정 | 제한 |

| 정밀도 | 소수점 이하 0~4자리. |
| 민감도 | 팝아웃 슬라이더 전체 범위에 걸쳐 10~2,000픽셀. |

| 브레이크다운 사용자 지정 범위 | -100%~200%. |
| 타이밍 스케일 사용자 지정 범위 | 최소 1%. |

| 줄이기 사용자 지정 범위 | 허용 오차 단위 0~1. |

### 레이아웃 저장, 불러오기 및 초기화

레이아웃에는 전체와 네 단계의 모든 행이 포함됩니다.

| 컨트롤 | 결과 |
|---|---|
| **다른 이름으로 저장** | 현재 레이아웃에 이름을 지정하고 저장합니다. |
| **불러오기** | 저장된 레이아웃을 불러옵니다. |
| **저장한 레이아웃 갱신** | 현재 행으로 저장된 레이아웃을 교체합니다. |
| **이름 바꾸기** 및 **삭제** | 저장된 레이아웃의 이름을 바꾸거나 삭제합니다. |
| **추천** | 고정된 내장 레이아웃을 나타냅니다. |
| **블로킹을 기본값으로 초기화** | 해당 단계의 기본 구성을 복원합니다. 컨트롤 이름은 편집 중인 행에 맞게 바뀝니다. |
| **추천 레이아웃 복원** | 전체와 모든 단계를 복원합니다. 저장된 레이아웃은 계속 사용할 수 있습니다. |

레이아웃은 애드온 환경설정에 저장됩니다. 모든 타임라인에 적용됩니다.

환경설정이 자동으로 저장되지 않으면 도구 모음 설정에서 **환경 설정 저장**을 클릭하세요. 그러면 다시 시작한 뒤에도 변경 사항이 유지됩니다.

저장된 레이아웃 이름은 1~64자여야 합니다. 라이브러리에는 최대 100개 레이아웃을 저장할 수 있습니다. 레이아웃을 불러오면 현재 작업 배치가 교체됩니다. 수정한 배치를 바꾸기 전에 저장되지 않은 변경 사항에 관한 컨트롤을 확인하세요.

단계는 고정된 기본 구성으로 시작합니다. 전체에 도구를 추가해도 다른 단계에 추가되지는 않습니다. 필요한 각 단계에 도구를 따로 추가하세요. 애드온 환경설정에는 단계 컨트롤이 없습니다. 각 작업공간에서는 행의 단계 버튼을 사용합니다.

위의 **도구 모음 설정** 그림은 저장된 레이아웃 컨트롤을 보여 줍니다. 같은 패널에서 행 구성과 레이아웃 관리를 할 수 있습니다.

### 마우스 오버 설명과 단축키

컨트롤의 설명을 보려면 포인터를 약 0.5초 동안 올려 두세요. **포인터 설명**에서 도움말의 분량을 조절합니다. 위치는 편집 > 환경 설정 > 애드온 > Anim Assist > 일반입니다.

마우스 오버 도움말, 단계 선택지 및 슬라이더 팝아웃은 도구 모음 버튼 위에 표시됩니다. 타임라인은 포인터 아래에 Anim Assist 툴팁 하나를 표시합니다. 도구 모음 도움말은 행 아래의 Scene Strip Gizmo보다 우선합니다.

- **전체:** 도구의 기능, 범위, 요구 조건 및 사용법을 설명합니다.
- **짧게:** 이름과 한 줄 설명을 표시합니다. 회색으로 표시된 도구에서는 이유도 표시합니다.
- **끄기:** 행에 Anim Assist 마우스 오버 설명을 표시하지 않습니다. Anim Assist 패널과 메뉴 안의 기본 Bforartists 버튼에는 여전히 도구 이름이 표시됩니다. Bforartists는 그 위치에 항상 설명 한 줄을 출력합니다. 설정 필드에는 각자의 한 줄 툴팁이 유지됩니다.

모든 툴팁을 끄려면 **편집 > 환경 설정 > 인터페이스 > 도움말**을 사용하세요.

마우스 오버 설명은 키가 지정되어 있을 때만 단축키를 표시합니다.

- **단축키:** 해당 Anim Assist 도구 자체에 지정된 키입니다. 행의 도구에는 기본 단축키가 없습니다. 여기에 단축키를 표시하려면 **편집 > 환경 설정 > 키맵**에서 지정하세요.
- **Bforartists key:** 같은 기능의 기본 명령을 실행하는 키입니다. 도프 시트 기본값에는 복사의 **Ctrl C**와 붙여넣기의 **Ctrl V**가 있습니다. **A**는 모든 키를 선택합니다. <strong>Ctrl Numpad +</strong>는 양쪽으로 선택을 확장합니다. **R**은 키 타이밍의 비율을 조절합니다. **W**는 키를 시간축에서 이동합니다. 기본 명령은 Anim Assist 도구와 다르게 동작할 수 있습니다. 기본 붙여넣기는 복사된 시간 대신 재생 헤드를 사용합니다.

## 도프 시트: 포즈와 키 타이밍

요약에는 보이는 소유자, 편집 가능한 곡선 및 선택한 키의 수가 표시됩니다. 전체/없음 선택 컨트롤도 있습니다. **블로킹 및 트윈**은 처음부터 펼쳐져 있습니다. 나머지 그룹은 **타이밍, 키 및 채널, 포즈 및 맞춤, 베이크 및 마무리 및 퀵 셸프**입니다.

1. 애니메이션이 있는 오브젝트나 포즈 본을 선택하세요.

2. 액션 채널을 표시하세요.

3. 편집할 키를 선택하세요.

4. 브레이크다운 비율, 중간 포즈 및 드래그 도구에는 **블로킹 및 트윈**을 사용하세요.

5. 마스크, 프리셋 및 샘플링 선택을 설정하려면 **블로킹 및 트윈** 옵션을 펼치세요.

6. 간격, 오프셋 및 리플에는 **타이밍**을 사용하세요.

7. 선택, 키 관리 및 메타데이터에는 **키 및 채널**을 사용하세요.

8. 맞추기와 미러링에는 **포즈 및 맞춤**을 사용하세요.

9. 베이크 및 진단 도구에는 **베이크 및 마무리**를 사용하세요.

핸들의 한쪽을 선택하려면 그래프 에디터를 사용하세요. 도프 시트는 고급 핸들 유형을 유지합니다. 매크로 작성과 초기 설정은 씬 프로퍼티스에 있습니다.

### 브레이크다운 기준점

빈 프레임에서는 양옆의 키가 블렌딩의 기준점이 됩니다. 예를 들어 값이 0과 10이면 50%에서 5가 됩니다.

재생 헤드 위치에 이미 키가 있으면 그 키가 이전 기준점이 됩니다. 현재 값이 5이고 다음 값이 10이면 50%에서 7.5가 됩니다. 작업을 반복하면 기존 키가 다시 바뀔 수 있습니다.

브레이크다운을 적용하기 전에 재생 헤드, 키 및 마스크를 확인하세요.

위의 도프 시트 그림에는 브레이크다운 작업과 옵션이 표시됩니다. 각 숫자 예제는 서로 다른 재생 헤드 및 키 배치를 설명합니다.

## 그래프 에디터: 곡선 모양 다듬기

**곡선 형태 조정**은 직접 모양 조절, 보간 및 핸들 작업을 펼친 상태로 시작합니다. 그룹은 **선택 및 채널, 곡선 형태 조정, 시간 재조정, 정리, 포즈 및 베이크 및 퀵 셸프**입니다. **선택 및 채널**에는 핸들 선택이 있습니다. **정리**에는 키 관리와 진단이 있습니다. **포즈 및 베이크**에는 맞추기, 미러링, 브레이크다운 및 베이크가 있습니다. 접혀 있는 **브레이크다운 옵션**은 브레이크다운 샘플링을 설정합니다. 일반 곡선 보간을 설정하지는 않습니다.

1. 보이는 편집 가능한 액션 키를 선택하세요.

2. 모양 조절 또는 보간 작업을 적용하세요.

3. 결과 곡선과 뷰포트를 확인하세요.

선택한 키 보간은 선택되어 있고 편집 가능하며 보이는 키에만 영향을 줍니다. 키 관리자의 타이밍 명령은 편집기 표시 상태와 채널 잠금을 따릅니다. **키 이동**과 **프레임 삽입**은 즉시 실행됩니다. 값을 조정하려면 기본 **마지막 작업을 조정**을 사용하세요.

액션 선택 보조 기능은 **오브젝트 액션**을 지원합니다. 범위가 비어 있어도 활성 액션 전체에서 선택하지 않습니다. 연결이 끊긴 고정 액션과 오브젝트가 아닌 소스는 제외합니다. 사이드바에 제외 이유가 설명됩니다. 액션 전체에 적용되는 도구를 사용하기 전에 설명을 확인하세요.

## 드라이버: 드라이버 응답 확인과 조절

드라이버 도구를 사용하려면 그래프 에디터를 **드라이버** 모드로 전환하세요. **Anim Assist** 사이드바와 헤더 메뉴에 네 개의 드라이버 전용 섹션이 표시됩니다. 액션 곡선으로 돌아가면 위에서 설명한 액션 그룹이 복원됩니다. 드라이버 모드는 액션 키 도구 대신 드라이버 채널을 사용합니다.

<a id="driver--target"></a>

### 드라이버 및 대상

이 섹션에는 선택한 보이는 드라이버의 수가 표시됩니다. 활성 드라이버가 있으면 **소유자**, **속성**, **현재 값**도 표시됩니다. 해당되는 경우 **배열 인덱스**가 표시됩니다. 속성을 확인할 수 없으면 경고가 나옵니다.

1. 채널 목록에서 보이는 드라이버 채널을 선택하세요.

2. **드라이버 및 대상**에서 소유자와 제어되는 속성을 확인하세요.

3. **선택 항목에 맞춰 보기**를 클릭하여 선택한 곡선이 화면에 들어오도록 맞추세요.

4. 드라이버 뷰 전체를 보려면 **전체에 맞춰 보기**를 클릭하세요.

**모든 채널**과 **없음**은 채널 선택을 바꿉니다. **소유자 선택**은 드라이버를 소유한 오브젝트를 활성화합니다. 다른 선택된 오브젝트는 선택 상태를 유지합니다. 소유자는 현재 뷰 레이어에 속해야 하며 보이는 오브젝트로서 선택이 허용되어야 합니다. 다른 데이터블록의 드라이버에서는 이 오브젝트 선택 작업을 사용할 수 없습니다.

소유자가 편집 가능하면 **음소거됨**과 **잠김**으로 활성 드라이버의 기본 채널 설정을 바꿀 수 있습니다. 보이는 드라이버 하나만 선택되어 있으면 잠근 뒤에도 확인할 수 있습니다. 잠금을 해제하려면 **잠김**을 끄세요. 여러 채널이 선택되어 활성 드라이버가 불분명하면 원하는 채널을 명시적으로 선택하세요.

선택이 비어 있어도 네 섹션 모두 표시되고 안내가 나옵니다. 드라이버를 만들지는 않습니다.

이 섹션들을 사용하기 전에 다음과 같이 하세요.

1. Bforartists의 기본 드라이버 작업 절차로 드라이버를 만드세요.

2. 해당 드라이버를 연결하세요.

![잠금이 해제된 Empty 오브젝트의 X 스케일 드라이버 scale&#91;0&#93;을 선택한 상태. 변수 1개와 표현식 var + 1.0이 사용되며 입력 0에 대한 출력은 1입니다. 응답 포인트는 선택되지 않아 보간과 핸들 컨트롤은 비활성화되어 있습니다. 응답 포인트를 편집한 결과를 보여 주는 것은 아닙니다. 공식 Bforartists 5.2.3 배포본에서 실행한 Anim Assist 12.11.2 후보 버전이며, 호스트 API 기록은 5.3.0 Alpha입니다. 2026-11-21 UTC 캡처.](images/ko/12.11.0-selected-driver.png)

### 변수 및 표현식

이 섹션에는 변수 수가 표시됩니다. 스크립트 드라이버에는 **표현식**이 표시됩니다. 다른 드라이버 유형에는 **유형**이 표시됩니다. 기본 **드라이버** 탭에 변수와 표현식을 편집하는 전체 설정이 있습니다.

1. 원하는 드라이버 채널의 잠금을 해제하세요.

2. 해당 채널을 클릭하여 기본 활성 편집 가능 드라이버로 만드세요.

3. **변수 및 표현식**을 여세요.

4. **드라이버 설정 열기**를 클릭하세요.

5. 기본 **드라이버** 탭에서 변수, 대상, 드라이버 유형 또는 표현식을 편집하세요.

6. 응답 작업과 진단을 하려면 **Anim Assist**로 돌아오세요.

이 버튼은 기본 사이드바 범주를 엽니다. 설정 대화상자의 별도 사본을 열지는 않습니다. 잠긴 드라이버는 기본 설정을 편집할 수 없는 상태에서도 계속 확인할 수 있습니다. 기본 사이드바 탭의 순서는 달라질 수 있습니다. **드라이버**, **모디파이어**, **Anim Assist**를 이름으로 구분하세요.

### 응답 곡선

가로축은 드라이버 입력을 나타냅니다. 세로축은 제어되는 출력을 나타냅니다. 응답 포인트는 입력을 출력에 대응시킵니다. 애니메이션 시간을 사용하는 액션 키와는 다릅니다.

1. 편집할 보이는 드라이버 채널을 선택하세요.

2. 해당 채널의 잠금을 해제하세요.

3. 소유자가 편집 가능한지 확인하세요.

4. 포인트 단위로 변경하려면 응답 포인트 또는 핸들의 한쪽을 선택하세요.

5. **응답 곡선**에서 **보간** 또는 **핸들**을 선택하세요.

6. 결과 응답과 제어되는 속성을 확인하세요.

| 컨트롤 | 범위와 결과 |
|---|---|
| **보간** | 선택한 보이는 편집 가능 드라이버 채널에서 선택한 응답 포인트를 바꿉니다. 선택지는 상수, 선형, Bezier입니다. |
| **핸들** | 해당 채널에서 선택한 핸들 쪽을 바꿉니다. 제어 포인트가 선택되어 있으면 양쪽 핸들을 모두 바꿉니다. |
| **외삽** | 선택한 보이는 편집 가능 드라이버 채널의 끝점 범위 바깥 동작을 바꿉니다. 상수는 출력값을 유지합니다. 선형은 끝점의 기울기를 연장합니다. |
| **모디파이어 추가 (활성 드라이버)** | 선택한 응답 모디파이어를 활성 편집 가능 드라이버에만 추가합니다. 선택한 모든 채널에 적용하지는 않습니다. |
| **모디파이어 설정 열기** | 활성 드라이버의 기본 **모디파이어** 탭을 엽니다. |

포인트 작업에는 선택한 포인트나 핸들이 필요합니다. 외삽에는 선택한 편집 가능 채널이 필요합니다. 모디파이어 작업에는 편집 가능한 소유자가 있는, 잠금 해제된 활성 드라이버가 필요합니다. 기본 설정을 열 때도 기본 활성 상태의 편집 가능한 드라이버가 필요합니다. 컨트롤이 비활성화되어 있으면 포인터를 올려 필요한 조건을 확인하세요.

보간, 핸들, 외삽 및 모디파이어 생성은 기본 **실행 취소**와 **마지막 작업을 조정**을 지원합니다. 이 작업은 지정된 드라이버에만 영향을 줍니다. 액션 키는 수정하지 않으며, 관련 없는 드라이버도 제외합니다. 실행 검증에서 모든 기본 모디파이어 유형을 각각 검증한 것은 아닙니다.

### 진단

1. 확인할 보이는 드라이버 채널을 선택하세요.

2. **진단**을 여세요.

3. **선택된 드라이버 점검**을 클릭하세요.

4. 결과 팝업을 읽으세요.

5. 해당 기본 설정에서 보고된 대상, 경로, 본 또는 표현식을 수정하세요.

6. 의존성을 수정한 후 **종속성 업데이트**를 클릭하세요.

**선택된 드라이버 점검**은 평가 유효성, 누락된 대상, 확인할 수 없는 속성 경로 및 누락된 본을 검사합니다. 링크된/읽기 전용 소유자, 잠긴 채널 및 음소거된 드라이버도 보고합니다. 속성 대상에서 대체값이 활성화되어 있으면 해당 대상의 경로를 확인할 수 없어도 경로 실패로 보고하지 않습니다.

검사는 선택한 보이는 드라이버만 확인합니다. 파일 전체를 검사하지 않습니다. 모든 표현식이 의도한 모션을 만든다는 것을 증명하지도 않습니다. **종속성 업데이트**는 선택한 드라이버의 소유자를 새로 고치고 뷰 레이어를 다시 평가합니다. 표현식 수정, 대상 재연결, 응답 포인트 변경 또는 드라이버 삭제는 하지 않습니다.

## NLA: 클립 배치와 보정 블렌딩

**배치 및 타이밍**과 **혼합 및 보정**은 펼친 상태로 시작합니다. **액션 및 트랙, 베이크 및 마무리 및 퀵 셸프**는 접힌 상태로 시작합니다. 요약에는 소유자, 활성 클립, 소스 액션, 선택한 클립 수, 장면 범위 및 소스 범위가 표시됩니다. 장면 프레임은 클립의 위치를 나타냅니다. 소스 프레임은 클립 안의 액션 구간을 나타냅니다.

### 클립 배치

1. 바꿀 액션 클립을 선택하세요.

2. 기준 클립의 본체를 클릭하여 활성화하세요.

3. 기준 클립이 선택된 상태인지 확인하세요.

4. 조금씩 이동하려면 **-1f/+1f**를 클릭하고, 기본 이동을 사용하려면 **선택된 클립 이동**을 클릭하세요.

5. 선택한 활성 클립에 맞춰 클립을 정렬하려면 **Align Starts/Ends**를 사용하세요.

6. 기준 클립의 시작부터 클립을 연속으로 배치하려면 **클립 연속 배치**를 사용하세요.

7. **마지막 작업을 조정**에서 증분 또는 연속 배치 간격을 바꾸세요.

8. 활성 클립의 비율, 반복, 반전 및 장면 시작/끝을 설정하려면 **타이밍 옵션**을 펼치세요.

타이밍은 장면 프레임을 사용합니다. 도구는 잠겼거나 서로 겹치는 일괄 작업을 부분 변경 없이 거부합니다. 소스를 편집하는 동안에는 배치 작업이 중지됩니다. 이 도구는 전환, 메타 또는 사운드 스트립을 편집할 수 없습니다.

![선택한 Toolkit_Offer_Animated_Cube Correction의 블렌딩 및 보정 기본 패널 팝오버. 결합 블렌딩과 애니메이션 영향도가 켜져 있으며 프레임 12에 키가 있는 영향도 0.500이 표시됩니다. 영어로 남은 “Blend Options”는 블렌딩 설정을 뜻하는 원문 대체 표시입니다. 이 그림은 팝오버를 보여 주며 NLA 편집기 전체 개요는 아닙니다. 공식 Bforartists 5.2.3 배포본에서 실행한 Anim Assist 12.11.2 후보 버전이며, 호스트 API 기록은 5.3.0 Alpha입니다. 2026-11-20 UTC 캡처.](images/ko/12.8.0-nla-arrange.png)

### 소스 편집과 공유 관리

**액션 편집**은 기본 NLA Tweak Mode로 들어갑니다. **도프 시트 열기/그래프 에디터 열기**는 적절한 고정 해제 편집기를 재사용하거나 현재 영역을 전환합니다. 기본 Tweak Mode는 이동, 비율 조절, 반복 및 반전된 클립의 소스 시간을 매핑합니다.

편집 후 배치 작업으로 돌아가려면 다음과 같이 하세요.

1. 편집기 선택기에서 **비선형 애니메이션**을 선택해 NLA로 돌아가세요.

2. **편집 종료**를 클릭하세요.

공유 액션을 편집하면 다른 클립에도 영향을 줄 수 있습니다. 요약은 공유를 경고하고 제외된 소스를 보고합니다. 음소거와 솔로는 평가에 영향을 줍니다.

| 컨트롤 | 결과 |
|---|---|
| **선택된 클립을 독립 복사본으로 만들기** | 선택한 클립의 소스 액션을 각각 분리합니다. |
| **독립 복제** | 액션을 복사합니다. |
| **연결 복제** | 액션을 공유합니다. |
| **선택된 트랙 위로 이동/선택된 트랙 아래로 이동** | 트랙 순서를 바꿉니다. 클립을 트랙 사이로 이동하지는 않습니다. |

**Push Down Active Action/Stash Active Action**은 활성 소유자에 할당된 액션에 작용합니다. Push Down에는 NLA 평가가 활성화되어 있어야 합니다. 선택한 클립이 없으면 요약은 편집 가능한 활성 오브젝트에 대해 **기존 액션 클립 추가**를 제공합니다.

### 변환 보정 추가

1. 지원되는 소스 액션 클립 하나를 선택하세요.

2. **새 변환 보정**을 클릭하세요.

3. 새 보정 클립을 선택하세요.

4. **보정 편집**을 클릭하세요.

5. 기본 Tweak Mode에서 변환 키를 편집하세요.

6. 편집 후 **편집 종료**를 클릭하세요.

7. 수정하지 않은 채널은 중립값으로 유지하세요. 위치는 0, 회전은 0/항등 회전, 크기는 1입니다.

8. 재생 헤드 위치에서 <strong>0%, 50% 또는 100%</strong>를 클릭하여 활성 클립의 영향도에 키를 넣으세요.

기본 **결합** 블렌딩은 소스 모션 위에 보정을 적용합니다. 다른 영향도 값을 사용하려면 **마지막 작업을 조정**에 입력하세요. 영향도가 0이면 보정은 모션에 기여하지 않습니다.

생성하면 소스 위에 독립된 보정 액션과 트랙이 추가됩니다. 보정은 오브젝트와 포즈 본의 변환을 지원합니다. 제약 조건/드라이버가 적용된 리그, 확인할 수 없는 본 및 변환이 아닌 소스 채널에서는 생성을 차단하고 이유를 설명합니다. 이 보정은 씬 프로퍼티스의 일반 애니메이션 레이어 도구와 별개입니다.

혼합과 영향도 애니메이션은 기본 스트립 설정입니다. 영향도 애니메이션이 꺼져 있으면 사이드바는 자동 블렌딩 엔벌로프를 표시합니다. **Blend Options**에는 자동 혼합, 블렌드 인/아웃 및 외삽이 표시됩니다. 영향도 버튼은 기본 영향도 키를 만듭니다. 소스 액션에 포즈 키를 만들지는 않습니다.

위의 **NLA 배치 및 보정 컨트롤** 그림에는 보정 트랙, **보정 편집**, **결합** 블렌딩 및 영향도 버튼이 표시됩니다.

### 소스 스택을 유지하면서 베이크

1. 베이크할 소유자의 클립을 선택하세요.

2. **베이크 및 마무리**를 여세요.

3. 표시된 소유자와 장면 범위를 확인하세요.

4. **새 액션으로 베이크**를 클릭하세요.

5. 필요하면 **마지막 작업을 조정**에서 범위와 증분을 조정하세요.

6. 출력 이름과 범위를 확인하세요.

7. 베이크 결과를 활성화하기 전에 중복 적용될 활성 제약 조건을 음소거하거나 제거하세요.

8. <strong>최신 베이크 사용(NLA 끔)</strong>을 선택하세요.

베이크는 평가된 오브젝트/포즈 변환을 새 액션에 기록하고 보존합니다. 새 액션은 처음에는 **할당되지 않은** 상태로 남습니다. 원래 액션, 클립, 부모 및 제약 조건은 유지됩니다. 베이크 결과의 활성화는 별도 작업입니다. <strong>최신 베이크 사용(NLA 끔)</strong>은 결과를 할당하고 소스 스택 평가를 끕니다.

비교할 수 있도록 소스 장면을 저장하세요. 이름을 바꿔도 출력 소유권은 바뀌지 않습니다. 이전 이름을 사용하게 된 다른 오브젝트는 해당 출력을 받을 수 없습니다. **빈 트랙 제거**는 빈 트랙을 별도로 제거합니다.

NLA 퀵 셸프 단축 작업은 소스를 고유하게 만들고, 활성 소스를 편집하고, 소유자를 베이크합니다. 스트립에 일반 키 편집 매크로를 실행하지는 않습니다.

![소스가 보존된 NLA 베이크의 기본 패널 팝오버. Toolkit_Offer_Animated_Cube NLA Bake 출력은 프레임 1~24를 증분 1로 포함하며, 이 캡처 시점에는 오브젝트에 할당되지 않은 채 보존되어 있습니다. 원래 소스와 보정 트랙은 유지되어 있습니다. 이 그림은 최신 베이크를 사용하여 활성화한 상태를 입증하지 않습니다. 공식 Bforartists 5.2.3 배포본에서 실행한 Anim Assist 12.11.2 후보 버전이며, 호스트 API 기록은 5.3.0 Alpha입니다. 2026-11-20 UTC 캡처.](images/ko/12.11.1-nla-retained-bake.png)

### 로케이터, 프록시 및 베이크 세션

1. **리그 > 프록시 및 베이크**를 여세요.

2. 원하는 오브젝트를 선택하세요.

3. 로케이터 또는 이동, 방향, 월드 공간, 부모 공간 프록시를 선택하세요.

4. 선택한 베이크 명령의 베이크 범위를 설정하세요.

**한 번 클릭으로 프록시 및 베이크**는 베이크 전에 자체 프록시 세션에 월드 모션을 기록합니다. **세션 베이크 및 프록시 제거**는 해당 세션을 정리합니다. **모든 프록시 세션 제거**는 더 넓은 범위에 영향을 줍니다. 기존 검증이 부모가 설정된 경우, 제약 조건이 있는 경우 또는 모든 실무 리그 사례를 인증하는 것은 아닙니다. 보조 요소를 제거하기 전에 결과를 비교하세요.

4. 레이어를 선택하세요.

6. 대상으로 **셰이프 키**, **본** 또는 **둘 다**를 선택하세요.

7. 메시 또는 아마츄어 대상을 선택하세요.

8. 선택한 비짐 라이브러리에 맞게 **셰이프 키 연결 설정** 또는 **본 리그 연결**을 설정하세요.

9. 연결 항목의 대상 이름을 확인하세요.

10. 선행 처리, 프레임 오프셋 및 분석 백엔드를 확인하세요.

11. **베이크**를 클릭하세요.

12. 입 모션을 확인하세요.

**다시 베이크** 전에 **선택된 키 잠금**을 사용하여 선택한 수동 작업을 보존하세요.

**실시간 미리 보기/베이크 완료**는 레이어 상태를 보여 줍니다. 셰이프 키 출력에는 셰이프 키가 연결된 메시가 필요합니다. 본 출력에는 유효한 애니메이션 레이어, 아마츄어 및 연결 설정이 필요합니다. **자동 채우기**는 연결 항목을 채웁니다. **비짐 캡처 > 캡처**는 사용자 지정 포즈를 저장합니다.

필요한 미리보기 또는 베이크 작업에 맞게 상태 컨트롤을 사용하세요.

진폭 분석에는 외부 음소 실행 파일이 필요하지 않습니다. 선택 사항인 Rhubarb 분석에는 **Rhubarb 경로** 설정이 필요합니다. 출력에 의존하기 전에 백엔드 대체 처리 및 누락된 레이어 보고를 읽으세요. 스피커 스트립이 있으면 스피커 오버레이가 도프 시트/타임라인에 오디오를 표시합니다.

사이드바의 **비우기**는 자동 출력을 제거하고 표시된 수동 작업은 유지합니다. **다시 베이크**도 수동 오버라이드를 유지합니다. **수동 키 강조**는 보호된 편집을 표시합니다. 오디오를 바꾸면 레이어가 최신 상태가 아닌 것으로 표시됩니다. 다시 베이크하기 전에 보고된 WAV, 대상 및 레이어 문제를 해결하세요.

## 문제 해결과 검증 범위

키 작업을 실행해도 아무 변화가 없으면 다음을 확인하세요.

1. 활성 편집기를 확인하세요.

2. 선택한 편집 가능 키와 보이는 채널을 확인하세요.

3. 잠금, 소유자 및 액션을 확인하세요.

4. 액션 데이터와 편집기 필터를 확인하세요.

도구 모음이 보인다는 사실만으로 키가 삽입되었음을 증명할 수는 없습니다. 메시/오브젝트에 키를 넣는 일반적인 작업에는 기본 **키 프레임을 삽입** 명령을 사용합니다.

문제를 보고할 때는 애드온 버전, Bforartists 빌드, 정확한 명령 및 작고 재현 가능한 장면을 포함하세요.

NLA 작업을 사용할 수 없으면 다음을 확인하세요.

1. 트랙 잠금과 음소거/솔로로 인한 제외를 확인하세요.

2. 누락된 액션, 꺼진 NLA 평가 또는 활성 Tweak Mode가 있는지 확인하세요.

3. 클립을 배치하기 전에 **편집 종료**를 클릭하세요.

4. 보정을 생성할 때는 지원하지 않는 리그/채널에 대한 설명을 읽으세요.

타이밍 변경이나 베이크 후에는 다음과 같이 하세요.

1. 모션을 확인하세요.

2. 필요하면 기본 실행 취소를 사용하세요.

3. 장면을 저장하세요.

4. 결과에 의존하기 전에 다시 여세요.

드라이버 설정을 사용할 수 없으면 잠금 해제된 드라이버 채널을 선택하여 기본 활성 채널로 만드세요. 잠긴 드라이버는 확인하고 잠금을 해제할 수 있도록 계속 표시될 수 있습니다. 선택한 여러 드라이버 중 명확한 활성 대상이 없으면 도구가 임의로 하나를 고르지 않습니다. 포인트 편집 작업에는 선택한 응답 포인트가 필요합니다.

[12.11.1 릴리스 노트](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.11.1/RELEASE-NOTES.md)는 타임라인 실행 취소 전달 수정을 설명합니다. [12.11.0 검증 기록](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.11.0/qualification.md)에는 Bforartists 5.2.0에서 수행한 대상별 드라이버 테스트와 기본 커서 조작 관찰이 기록되어 있습니다. 여기에는 채널 범위, 기본 설정 이동 및 모디파이어 실행 취소/다시 실행이 포함됩니다. 레이아웃 등록과 애니메이션 편집기 회귀 시나리오 11개도 기록되어 있습니다. 이 결과는 이전 테스트에서 나온 것입니다. 이번 안내서 업데이트에서는 해당 테스트를 반복하지 않았습니다.

[12.10.0 검증 기록](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.10.0/qualification.md)은 단계별 도구 구성을 다룹니다. [12.9.1 검증 기록](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.9.1/qualification.md)은 단계 탭 수정을 다룹니다. [12.8.0 검증 기록](https://github.com/Axleonex/B4Artists_Toolkit/blob/a8b6b12d4f9ae7b2cd00c14af9f2f90301420c7a/docs/anim_assist/releases/12.8.0/qualification.md)에는 기본 조작 그룹 16개, 실행 취소/다시 실행 및 작업공간 다시 불러오기가 기록되어 있습니다. 패널 등록 98개와 타임라인 레이아웃 회귀 검사 5개도 기록되어 있습니다. 증거에는 메시 키 삽입과 220, 280, 360px 너비의 사이드바 캡처가 포함됩니다.

이 테스트가 모든 오퍼레이터, 모디파이어, 실무 리그 또는 호스트 빌드를 인증하는 것은 아닙니다. 이전 슬라이더 및 립싱크 증거는 과거 기록으로 유지됩니다. 11월 20일 문서 검토는 현재 소스, 링크 및 PDF 표시를 확인합니다. 공식 STE 사전 인증을 제공하지는 않습니다.

12.11.2 후보 버전의 **립싱크 설정**은 Blender 5.3 Alpha 기반 공식 Bforartists 5.2.3에서 완료되었습니다. 사운드 스트립을 생성했습니다. 새 그림은 대상 연결과 베이크 전의 결과 레이어를 보여 줍니다. 베이크된 입 모션을 입증하지는 않습니다.

설정 중 **compiled without Audaspace support**가 보고되면 오디오를 지원하는 Bforartists 빌드를 사용하세요. 사운드 스트립을 만들지 않고도 설정이 완료될 수 있습니다. Blender 5.4 Alpha 기반의 제공된 커스텀 빌드에서 이러한 결과가 나왔습니다.

범위와 선택 요약의 위치를 찾으려면 **도프 시트**, **그래프 에디터** 및 **선택한 드라이버** 그림을 사용하세요.
